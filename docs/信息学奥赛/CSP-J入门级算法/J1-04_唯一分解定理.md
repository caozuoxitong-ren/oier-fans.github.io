# 唯一分解定理（算术基本定理）

## 一、算术基本定理

### 1\. 定理内容

**算术基本定理**，又称**唯一分解定理**：每个大于 1 的自然数，要么本身是质数，要么可以唯一地写成若干个质数的乘积（不考虑顺序）。

**形式化表述：** 对于任意正整数 $N > 1$，存在唯一的质因数分解形式

$$
N = p_{1}^{a_{1}} \times p_{2}^{a_{2}} \times \dots \times p_{k}^{a_{k}}
$$

其中 $p_1 < p_2 < \dots < p_k$ 为互不相同的质数，$a_i$ 为正整数。这种表示**存在**且**唯一**。

**举例：**

$$
6936 = 2^3 \times 3 \times 17^2
$$

$$
1200 = 2^4 \times 3 \times 5^2
$$

$$
5207 = 41 \times 127
$$

$$
19 = 19 \quad (\text{质数本身就是分解结果})
$$

### 2\. 定理的两个部分

算术基本定理的内容由两部分构成：

| 部分 | 含义 | 说明 |
| --- | --- | --- |
| **存在性** | 任意 $N > 1$ 都**能**分解为质数之积 | 质数是"积木"，任何大于 1 的数都能用质数拼出来 |
| **唯一性** | 不考虑顺序时，分解方式**只有一种** | 同一个数的质因数分解结果是确定的，不会有两种不同答案 |

> **关键理解：** "唯一"指的是质因数的**种类**和**每个质因数的指数**唯一确定，与书写顺序无关。例如 $12 = 2^2 \times 3$ 和 $12 = 3 \times 2^2$ 是同一种分解。

### 3\. 为什么枚举到的因子必是质因子

在分解质因数的代码中，我们从小到大枚举 $i$，一旦 $i$ 能整除 $N$ 就认为 $i$ 是**质因子**。为什么不用专门判断 $i$ 是不是质数？

**原因：** 枚举是从小到大进行的。当枚举到 $i$ 时，$N$ 中所有比 $i$ 小的质因子已经被"除干净"了。如果 $i$ 是合数，它一定能被某个比它小的质数整除，而那个质数已经从 $N$ 中除掉了，所以合数 $i$ 不可能再整除当前的 $N$。能整除当前 $N$ 的 $i$，一定是质数。

> **一句话记忆：** 从小到大除，小的质因子先被除干净，剩下的合数因子"拼不出来"，所以能整除的一定是质数。

## 二、分解质因数的方法

### 1\. 暴力枚举法

**思路：** $N$ 的质因子一定在 $[2, N]$ 之间，枚举 2 到 $N$ 的每个数 $i$，若 $i$ 能整除 $N$，则 $i$ 是质因子，连续除以 $i$ 直到 $N$ 不再含因子 $i$，同时记录个数。

**时间复杂度：** $O(N)$

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int num;
    cin >> num;

    // 分解质因数
    int a[100] = {}, cnt[100] = {}, len = 0;
    for(int i = 2; i <= num; i++){           // 枚举 2 到 num
        if(num % i == 0){                    // i 能整除 num
            a[++len] = i;                    // 记录质因子
            while(num % i == 0)              // 把 i 全部除干净
                cnt[len]++, num /= i;
        }
    }

    // 输出
    for(int i = 1; i <= len; i++){
        cout << a[i] << " " << cnt[i] << endl;
    }
    return 0;
}
```

### 2\. 优化法（利用 $\sqrt{N}$ 结论）

**关键结论：** 任意正整数 $N$ **至多有一个**大于 $\sqrt{N}$ 的质因子。

**证明（反证法）：** 假设 $N$ 有两个不同的质因子 $a$ 和 $b$，且 $a > \sqrt{N}$，$b > \sqrt{N}$。

-   因为 $a$ 和 $b$ 都是 $N$ 的质因子且互质，所以 $ab \mid N$，即 $ab \leq N$　　①
-   但 $a > \sqrt{N}$，$b > \sqrt{N}$，所以 $ab > \sqrt{N} \times \sqrt{N} = N$　　②

①和②矛盾，假设不成立。因此 $N$ 不可能有两个都大于 $\sqrt{N}$ 的质因子，至多只有一个。

> **推论：** 枚举到 $\sqrt{N}$ 就够了。如果除完之后 $N > 1$，说明剩下的这个 $N$ 就是那个唯一的大于 $\sqrt{N}$ 的质因子。

**时间复杂度：** $O(\sqrt{N})$

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int num;
    cin >> num;

    // 分解质因数
    int a[100] = {}, cnt[100] = {}, len = 0;
    for(int i = 2; i <= num / i; i++){      // 只枚举到 sqrt(num)
        if(num % i == 0){
            a[++len] = i;
            while(num % i == 0)
                cnt[len]++, num /= i;
        }
    }
    if(num > 1) a[++len] = num, cnt[len] = 1; // 剩下的大于 sqrt 的质因子

    // 输出
    for(int i = 1; i <= len; i++){
        cout << a[i] << " " << cnt[i] << endl;
    }
    return 0;
}
```

### 3\. 两种方法对比

| 对比项 | 暴力枚举法 | 优化法 |
| --- | --- | --- |
| 枚举范围 | $[2, N]$ | $[2, \sqrt{N}]$ |
| 时间复杂度 | $O(N)$ | $O(\sqrt{N})$ |
| 循环条件 | `i <= num` | `i <= num/i` |
| 收尾处理 | 不需要 | 需判断 `num > 1` |
| 适用场景 | 理解原理 | 实际比赛必用 |

> **易错点：** 循环条件写成 `i * i <= num` 也能用，但当 $N$ 接近 `int` 上限时 `i * i` 可能溢出。用 `i <= num / i` 更安全，不会溢出。

## 三、约数个数定理

### 1\. 定理内容

由算术基本定理，正整数 $N > 1$ 分解为

$$
N = p_{1}^{a_{1}} \times p_{2}^{a_{2}} \times \dots \times p_{k}^{a_{k}}
$$

则 $N$ 的正约数个数为

$$
d(N) = (a_{1}+1)(a_{2}+1) \dots (a_{k}+1) = \prod_{i=1}^{k}(a_{i}+1)
$$

### 2\. 证明

对于第 $i$ 个质因子 $p_i^{a_i}$，它的正约数有 $p_i^0, p_i^1, p_i^2, \dots, p_i^{a_i}$，共 $a_i + 1$ 个。

$N$ 的任意一个约数，对每个质因子 $p_i$ 都可以选 $p_i^0$ 到 $p_i^{a_i}$ 中的某一项，共 $a_i + 1$ 种选择。根据**乘法原理**，$k$ 个质因子的选择互相独立，所以约数总数为

$$
d(N) = \prod_{i=1}^{k}(a_{i}+1)
$$

> **一句话理解：** 每个质因子的指数从 0 取到 $a_i$，有 $a_i + 1$ 种取法，各质因子取法相乘就是约数总数。

### 3\. 举例

**例 1：** $60 = 2^2 \times 3^1 \times 5^1$，质因子 2、3、5 的指数分别为 2、1、1，所以 60 的约数个数为

$$
d(60) = (2+1) \times (1+1) \times (1+1) = 3 \times 2 \times 2 = 12
$$

12 个约数分别为：$1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60$。

**例 2：** $360 = 2^3 \times 3^2 \times 5^1$，约数个数

$$
d(360) = (3+1) \times (2+1) \times (1+1) = 4 \times 3 \times 2 = 24
$$

### 4\. 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int num;
    cin >> num;

    // 求约数个数
    int ans = 1;
    for(int i = 2; i <= num / i; i++){
        if(num % i == 0){
            int cnt = 0;                        // 统计质因子 i 的指数
            while(num % i == 0) cnt++, num /= i;
            ans *= (cnt + 1);                   // 乘以 (指数+1)
        }
    }
    if(num > 1) ans *= 2;                       // 剩下的质因子指数为 1，贡献(1+1)=2

    cout << ans << endl;
    return 0;
}
```

**关键点：**

| 代码 | 作用 |
| --- | --- |
| `int ans = 1` | 答案初始化为 1（乘法的单位元） |
| `int cnt = 0` | 统计当前质因子的指数 |
| `ans *= (cnt + 1)` | 套用公式，每个质因子贡献 $(指数+1)$ |
| `if(num > 1) ans *= 2` | 剩下的大于 $\sqrt{N}$ 的质因子指数为 1，贡献 $(1+1) = 2$ |

## 四、约数和定理

### 1\. 定理内容

由算术基本定理，正整数 $N > 1$ 分解为

$$
N = p_{1}^{a_{1}} \times p_{2}^{a_{2}} \times \dots \times p_{k}^{a_{k}}
$$

则 $N$ 的所有正约数之和为

$$
S(N) = \prod_{i=1}^{k} \frac{p_i^{a_i+1} - 1}{p_i - 1}
$$

展开写就是

$$
S(N) = (p_1^0 + p_1^1 + \dots + p_1^{a_1}) \times (p_2^0 + p_2^1 + \dots + p_2^{a_2}) \times \dots \times (p_k^0 + p_k^1 + \dots + p_k^{a_k})
$$

### 2\. 证明

**第一步：** 对第 $i$ 个质因子 $p_i^{a_i}$，它的约数有 $p_i^0, p_i^1, \dots, p_i^{a_i}$，这些约数之和为

$$
S_i = p_i^0 + p_i^1 + \dots + p_i^{a_i}
$$

这是一个等比数列求和，首项为 1，公比为 $p_i$，项数为 $a_i + 1$。

**第二步：** 用等比数列求和公式化简。记

$$
S_i = 1 + p_i + p_i^2 + \dots + p_i^{a_i} \quad \text{①}
$$

两边同乘公比 $p_i$：

$$
p_i \times S_i = p_i + p_i^2 + \dots + p_i^{a_i} + p_i^{a_i+1} \quad \text{②}
$$

②式减去①式：

$$
(p_i - 1) \times S_i = p_i^{a_i+1} - 1
$$

所以

$$
S_i = \frac{p_i^{a_i+1} - 1}{p_i - 1}
$$

**第三步：** $N$ 的每个约数都是从每个质因子 $p_i$ 的约数中选一个相乘得到的。所有约数的和就是各组约数和的乘积（乘法原理）：

$$
S(N) = \prod_{i=1}^{k} S_i = \prod_{i=1}^{k} \frac{p_i^{a_i+1} - 1}{p_i - 1}
$$

> **一句话理解：** 每个质因子贡献一组约数之和 $S_i$，各组之间用乘法原理组合，总约数和 = 各组约数和之积。

### 3\. 举例

**例 1：** $60 = 2^2 \times 3^1 \times 5^1$

$$
S(60) = \frac{2^3 - 1}{2 - 1} \times \frac{3^2 - 1}{3 - 1} \times \frac{5^2 - 1}{5 - 1} = \frac{7}{1} \times \frac{8}{2} \times \frac{24}{4} = 7 \times 4 \times 6 = 168
$$

验证：$1+2+3+4+5+6+10+12+15+20+30+60 = 168$ ✓

**例 2：** $12 = 2^2 \times 3^1$

$$
S(12) = \frac{2^3-1}{2-1} \times \frac{3^2-1}{3-1} = \frac{7}{1} \times \frac{8}{2} = 7 \times 4 = 28
$$

验证：$1+2+3+4+6+12 = 28$ ✓

### 4\. 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int num;
    cin >> num;

    // 求约数和
    long long ans = 1;
    for(int i = 2; i <= num / i; i++){
        if(num % i == 0){
            int cnt = 0;
            while(num % i == 0) cnt++, num /= i;
            // 计算 S_i = p^0 + p^1 + ... + p^cnt（直接累加，避免除法）
            long long sum = 0, pk = 1;
            for(int j = 0; j <= cnt; j++){
                sum += pk;
                pk *= i;
            }
            ans *= sum;
        }
    }
    if(num > 1){                              // 剩下的质因子指数为 1
        ans *= (1 + num);
    }

    cout << ans << endl;
    return 0;
}
```

> **注意：** 约数和可能很大，`ans` 必须用 `long long`，否则会溢出。上面代码用直接累加 $p^0 + p^1 + \dots + p^{a_i}$ 的方式计算 $S_i$，避免除法，更稳妥。

## 五、三个定理的关系

| 定理 | 作用 | 公式 |
| --- | --- | --- |
| 唯一分解定理 | 把 $N$ 拆成质数之积 | $N = \prod p_i^{a_i}$ |
| 约数个数定理 | 求 $N$ 有多少个约数 | $d(N) = \prod (a_i + 1)$ |
| 约数和定理 | 求 $N$ 所有约数之和 | $S(N) = \prod \frac{p_i^{a_i+1}-1}{p_i-1}$ |

> **逻辑链条：** 唯一分解定理是"根"，约数个数定理和约数和定理都建立在它之上。先有分解 $N = \prod p_i^{a_i}$，才能套公式求约数个数和约数和。

## 六、常见错误与注意事项

| 编号 | 错误 | 后果 | 改正 |
| --- | --- | --- | --- |
| E1 | 循环条件写 `i * i <= num` | $N$ 接近 `int` 上限时 `i*i` 溢出 | 写 `i <= num / i` |
| E2 | 忘记处理 `num > 1` 的剩余质因子 | 漏掉最大的那个质因子 | 循环后加 `if(num > 1)` 判断 |
| E3 | 约数和用 `int` 存 | 结果溢出，答案错误 | 用 `long long` |
| E4 | 约数个数公式写成 $\prod a_i$ | 漏了 $+1$ | 公式是 $\prod (a_i + 1)$ |
| E5 | 把 1 当质数 | 分解结果多一个因子 | 1 既不是质数也不是合数，从 2 开始枚举 |
| E6 | 列举约数时把非约数算进去 | 验证不通过 | 逐个用 $N \div d$ 检查是否整除 |
| E7 | 分解时没把质因子除干净 | 指数统计错误 | 用 `while` 而非 `if` 连续除 |

## 七、方法、套路与策略小结

### 1\. 分解质因数的套路

-   **定范围：** 枚举范围是 $[2, \sqrt{N}]$，不是 $[2, N]$。
-   **除干净：** 每个质因子用 `while` 循环除到不能整除为止，统计指数。
-   **查剩余：** 循环结束后若 $N > 1$，剩下的就是那个唯一的大于 $\sqrt{N}$ 的质因子。
-   **防溢出：** 循环条件用 `i <= num / i`，不用 `i * i <= num`。

### 2\. 求约数个数/约数和的套路

-   **先分解：** 先做质因数分解，得到每个 $p_i$ 和 $a_i$。
-   **套公式：** 约数个数套 $\prod (a_i + 1)$，约数和套 $\prod \frac{p_i^{a_i+1}-1}{p_i-1}$。
-   **防溢出：** 约数和用 `long long`，中间结果也注意范围。
-   **收尾处理：** 别忘了 `if(num > 1)` 的剩余质因子，指数为 1。

### 3\. 信奥策略意识

-   **复杂度意识：** $O(\sqrt{N})$ 的分解是数论题的基础工具，$N \leq 10^{12}$ 时 $\sqrt{N} \leq 10^6$，1 秒内能过。
-   **数据范围意识：** 约数个数和约数和都可能很大，根据题目数据范围选择 `int` 或 `long long`，必要时取模。
-   **验证习惯：** 算完约数个数后，可以列举验证；算完约数和后，可以暴力求和对照小数据验证。
-   **公式记忆：** 三个公式一脉相承，记住分解形式 $N = \prod p_i^{a_i}$，其余两个公式自然推导出来，不用死记。
