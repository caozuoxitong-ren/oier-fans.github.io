# 第 08 课 素数筛

筛法用于在一个范围内批量判断素数，或者批量生成素数表。与逐个数进行素数判断相比，筛法会利用“合数一定含有质因数”的性质，把合数统一标记出来。

特别注意：

```text
0 和 1 都不是素数。
```

---

## 一、朴素筛

### 1\. 原理

从 `2` 到 `n` 依次处理每个数 `i`，把 `i` 的所有两倍及以上倍数标记为合数：

$$
2i,\ 3i,\ 4i,\ \cdots
$$

例如处理 `i = 3` 时，标记：

```text
6、9、12、15、18、……
```

处理 `i = 4` 时，虽然 `4` 本身已经是合数，但仍然会再次标记：

```text
8、12、16、20、……
```

因此，朴素筛会重复标记很多合数。

### 2\. 代码实现

```cpp
//朴素筛 O(nlogn)
//思想：标记一个数的2倍及以上的倍数
const int N=1e7+5;
bool p[N];
void naive_sieve(int maxn){
	p[1]=true;
	for(int i=2;i<=maxn;i++){
		for(int j=i+i;j<=maxn;j+=i){
			p[j]=true;
		}
	}
} 
```

### 3\. 时间复杂度

处理 `i` 时，大约标记 $\frac{n}{i}$ 个数，因此总操作次数为：

$$
\sum_{i=2}^{n}\frac{n}{i}
=n\sum_{i=2}^{n}\frac1i
=O(n\log n)
$$

所以：

| 项目 | 复杂度 |
| --- | --- |
| 时间复杂度 | $O(n\log n)$ |
| 空间复杂度 | $O(n)$ |

朴素筛适合用来理解筛法的基本过程，但在数据较大时会有较多重复操作。

---

## 二、埃拉托斯特尼筛法

### 1\. 原理

埃氏筛只使用已经确认的素数进行筛选，而不再标记合数的倍数，因为合数的倍数（如6的倍数）必然已经被其质因子（2和3）标记过了。

处理 `i` 时：

-   如果 `i` 已经被标记为合数，跳过；
-   如果 `i` 仍然是素数，就标记它的两倍及以上倍数。

例如：

```text
处理 2：筛掉 4、6、8、10、……
处理 3：筛掉 6、9、12、15、……
处理 5：筛掉 10、15、20、25、……
```

合数 `i` 不再作为筛数，因此比朴素筛少了许多重复操作。

### 2\. 为什么可以从 $p^2$ 开始

设当前处理的素数为 $p$。

小于 $p^2$ 的 `p` 的倍数，例如：

$$
2p,\ 3p,\ \cdots,\ (p-1)p
$$

都已经在处理更小的素数时被筛掉了。

例如处理 `p = 5` 时：

-   `2 × 5 = 10` 已经被 `2` 筛掉；
-   `3 × 5 = 15` 已经被 `3` 筛掉；
-   `4 × 5 = 20` 已经被 `2` 筛掉。

因此，处理 `p` 时可以直接从 `p^2` 开始：

$$
p^2,\ p^2+p,\ p^2+2p,\ \cdots
$$

### 3\. 代码实现

```cpp
//埃氏筛 O(nlog(logn))
//思想：只标记素数的2倍及以上的倍数 
const int N=1e7+5;
bool p[N];
void eratosthenes_sieve(int maxn){
	p[1]=true;
	for(long long i=2;i<=maxn;i++){//避免下面 i*i溢出，用 long long
		if(p[i]==false){
            //for(long long j=i+i;j<=maxn;j+=i){
			for(long long j=i*i;j<=maxn;j+=i){//优化，从 i*i 开始标记
				p[j]=true;
			}
		}
		
	}
} 
```

### 4\. 时间复杂度

埃氏筛的总标记次数为：

$$
\frac{n}{2}+\frac{n}{3}+\frac{n}{5}+\frac{n}{7}+\cdots
$$

其中只对素数求和。可以证明总时间复杂度为：

$$
O(n\log\log n)
$$

空间复杂度为：

$$
O(n)
$$

## 三、欧拉筛

### 1\. 原理

欧拉筛也叫线性筛、线筛。它的目标是：

> 每个合数只被筛选一次，而且由它的最小质因子筛选。

设当前处理的数为 `i`，依次枚举已经得到的素数 `prime[j]`，标记：

$$
i\times prime[j] 
$$

### 2\. 为什么每个合数只被筛一次

设合数 `x` 的最小质因子为 `prime[j]`，可以写成：

$$
x=i\times prime[j]
$$

其中 `i = x / prime[j]`。

当欧拉筛处理到 `i`，并枚举到最小质因子 `prime[j]` 时，`x` 被标记。

如果继续枚举比 `prime[j]` 更大的质数 `prime[j+1]`，得到的 `i*prime[j+1]` 的最小质因子不会是 `prime[[j+1]]`，因为至少我们知道 `prime[j]` 就要比`prime[j+1]` 更小。所以这些数应当留给其他步骤处理。因此，当 `prime[j]` 整除 `i` 时立即停止：

```cpp
if (i % prime[j] == 0) {
    break;
}
```

也可以这样理解：

-   `prime[j]` 小于 `i` 的最小质因子时，可以继续生成；
-   一旦 `prime[j]` 是 `i` 的最小质因子，标记掉 `i * prime[j]` 后，如果继续生成就会产生重复筛选；
-   所以遇到 `i % prime[j] == 0` 时必须 `break`。

### 3\. 代码实现

```cpp
//欧拉筛（线性筛，线筛） O(n) 
//思想：每个合数只被最小质因子标记一次 
const int N=1e7+5;
bool p[N];
int prime[N],len=0;//记录素数 
void euler_sieve(int maxn){
	p[1]=true;
	for(int i=2;i<=maxn;i++){
		if(p[i]==false) prime[++len]=i;
		for(int j=1;j<=len && prime[j]<=maxn/i;j++){
			p[prime[j]*i]=true;
			if(i%prime[j]==0) break;
		}
	}
} 
```

### 4\. 时间复杂度

每个合数只被标记一次，每个素数只被加入一次，因此：

| 项目 | 复杂度 |
| --- | --- |
| 时间复杂度 | $O(n)$ |
| 空间复杂度 | $O(n)$ |

欧拉筛在理论时间复杂度上优于埃氏筛，适合需要在线性范围内处理大量数据的题目。

## 四、区间筛

### 1\. 使用场景

当要求查询区间 $[L,R]$ 内的素数，而 `R` 很大、不能直接开 `R+1` 大小的数组时，可以使用区间筛。

区间筛适用于：

$$
1\leq L\leq R,\qquad \text{但} R-L\text{ 的跨度较小}
$$

例如：

```text
L = 10^12
R = 10^12 + 10^6
```

此时不能开一个大小为 `10^12` 的数组，但只需要处理：

$$
R-L+1\leq 10^6+1
$$

个数即可。

### 2\. 核心思想

先用普通埃氏筛求出所有不超过 $\sqrt R$ 的素数，对每个基础素数 `p`，标记它在 `[L,R]` 中的倍数。可以基于埃氏筛实现。

### 3\. 代码实现

```cpp
const int N=1e6+5;
bool p1[N];//标记[1,sqrt(R)]内的素数
bool p2[N];//标记[L,R]内的素数，标记x的时候使用p2[x-L]
void range_sieve(long long L,long long R){
	
	p1[1]=true;
	if(L==1) p2[0]=true;
	
	for(long long i=2;i<=R/i;i++){
		if(p1[i]==false){
			//标记[2,sqrt(R)]内的素数
			for(long long j=i*i;j<=R/j;j+=i){
				p1[j]=true;
			}
			//标记[L,R]内的素数
			long long start=(L+i-1)/i*i;// >=L的i的最小倍数
			for(long long j=start;j<=R;j+=i){
				p2[j-L]=true;
			}
		}
	}
}
```

### 5\. 区间筛的正确性

如果区间中的整数 `x` 被标记，说明存在基础素数 `p`：

$$
p\mid x,\qquad p\leq\sqrt R
$$

所以 `x` 有非平凡因子，是合数。

如果 `x` 是合数，那么它一定有一个不超过 $\sqrt x$ 的质因子。因为 $x\leq R$，所以这个质因子不超过 $\sqrt R$，会被基础素数筛选到。因此所有合数都会被标记。

没有被标记且大于 `1` 的数就是素数。

### 6\. 时间与空间复杂度

令：

$$
W=R-L+1
$$

首先筛出不超过 $\sqrt R$ 的素数，再标记区间中的合数。

| 项目 | 复杂度 |
| --- | --- |
| 基础筛时间 | $O(\sqrt R\log\log R)$ |
| 区间标记时间 | 约为 $O(W\log\log R)$ |
| 总空间复杂度 | $O((\sqrt R+W)\log\log R)$ |

当 `R` 很大但 `W` 可控时，区间筛可以把内存消耗从 `O(R)` 降低到 `O(W)`。

## 五、应用举例：查询区间[L,R]中的素数个数

### 1\. 直接统计

筛法结束后，遍历 `p`，统计区间[L,R]中的素数的个数：

```cpp
int cnt = 0;
for (int i = L; i <= R; i++) {
    if (p[i]==false) {
        cnt++;
    }
}
```

时间复杂度为 $O(R-L)$。

### 2\. 多次查询使用前缀和

如果有多次询问，每次询问区间 `[L,R]` 内有多少个素数，可利用**前缀和**思想，先求素数标记的前缀和数组，转化为区间查询问题：

$$
\operatorname{preSum}[i]
=\operatorname{preSum}[i-1]
+[\text{i 是素数}]
$$

查询 `[L,R]` 时：

$$
\text{答案}=\operatorname{preSum}[R]-\operatorname{preSum}[L-1]
$$

## 六、筛法方法对比

| 筛法 | 核心做法 | 时间复杂度 | 空间复杂度 | 适用场景 |
| --- | --- | --- | --- | --- |
| 朴素筛 | 所有 `i` 都筛 `2i、3i、……` | $O(n\log n)$ | $O(n)$ | 理解筛法原理 |
| 埃氏筛 | 只用素数筛，从 `p*p` 开始 | $O(n\log\log n)$ | $O(n)$ | 求 `1..n` 内所有素数 |
| 欧拉筛 | 每个合数只由最小质因子筛一次 | $O(n)$ | $O(n)$ | 线性预处理、求最小质因子 |
| 区间筛 | 只标记 `[L,R]`，基础素数筛到 $\sqrt R$ | $O(\sqrt R\log\log R+W\log\log R)$ | $O(\sqrt R+W)$ | `R` 很大、`R-L` 较小 |

其中：

$$
W=R-L+1
$$
