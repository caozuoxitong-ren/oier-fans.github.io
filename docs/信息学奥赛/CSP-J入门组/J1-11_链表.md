## 四、什么是链表——从数组的局限说起

### 引入：数组的弱点

第 8 课学过，数组用**连续**的内存空间存数据。要在数组中间插入一个元素，后面的所有元素都要往后挪一位：

```
插入前: [10, 20, 30, 40, 50]
在 20 后插入 25 → 30, 40, 50 全部后移
插入后: [10, 20, 25, 30, 40, 50]

```

如果数组有 10 万个元素，在头部插入就要搬动 10 万个元素——太慢了。

### 链表的核心思想

链表不用连续空间。每个元素独立分配内存，用**指针**记录"下一个元素在哪"。就像寻宝游戏：每个线索告诉你下一个线索的位置，你顺着线索一个个找下去。

```
节点1 → 节点2 → 节点3 → nullptr(结束)

```

每个"节点"包含两部分：

-   **数据域**：存实际的数据（如一个整数）
-   **指针域**：存下一个节点的地址

这样，插入新节点时只需修改指针的指向，不用搬动任何数据：

```
插入前: 节点1 → 节点2 → 节点3
在节点1后插入新节点:
  新节点先指向节点2，节点1再指向新节点
插入后: 节点1 → 新节点 → 节点2 → 节点3

```

> **要点**：链表的核心是"用指针串联独立的节点"。插入删除只需改指针，O(1) 搞定。代价是失去了随机访问能力——要找第 i 个元素，只能从头顺着指针走 i 步。

## 五、单链表的手写实现

### 5.1 定义节点：struct 与指针

手写链表需要两个新概念：**结构体**（`struct`）和**指针**（`*`）。

-   **struct**：把多个变量打包在一起。链表节点需要"一个数据 + 一个指针"，用 struct 封装。
-   **指针**：存一个地址。`Node* next` 表示 `next` 这个变量存的是"另一个 Node 的内存地址"。

```cpp
// 定义链表节点
struct Node {
    int data;      // 数据域：存一个整数
    Node* next;    // 指针域：指向下一个节点
};

```

> **要点**：`Node*` 读作"指向 Node 的指针"。`next` 不存数据本身，而是存"下一个节点在哪条街哪个号"——一个地址。

### 5.2 创建节点：new 与 -\>

用 `new` 在内存中分配一个新节点，用 `->` 访问指针指向的成员：

```cpp
Node* a = new Node;   // 在堆内存中创建一个节点，a 存它的地址
a->data = 10;         // 通过 -> 给 data 赋值
a->next = nullptr;    // next 设为 nullptr（空指针，表示"后面没有了"）

```

> **要点**：`->` 是"指针访问成员"的运算符。`a->data` 等价于 `(*a).data`，读作"a 指向的节点的 data"。`nullptr` 是 C++ 的空指针关键字，表示"不指向任何东西"。

### 5.3 连接节点与遍历

把三个节点连成链表，再用循环遍历：

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

int main() {
    // 创建三个节点
    Node* a = new Node;  a->data = 10;
    Node* b = new Node;  b->data = 20;
    Node* c = new Node;  c->data = 30;

    // 连接: a → b → c → nullptr
    a->next = b;
    b->next = c;
    c->next = nullptr;

    // head 指针指向第一个节点（链表的"入口"）
    Node* head = a;

    // 遍历：从 head 出发，顺着 next 一直走到 nullptr
    for (Node* p = head; p != nullptr; p = p->next) {
        cout << p->data << ' ';
    }
    cout << '\n';
    // 输出: 10 20 30

    return 0;
}

```

> **要点**：遍历链表的标准写法是 `for (Node* p = head; p != nullptr; p = p->next)`。`p = p->next` 让指针走到下一个节点，`p == nullptr` 时说明走到末尾了。

### 5.4 头插法：在头部插入新节点

在链表头部插入新节点，只需两步：

```cpp
// 在 head 指向的链表头部插入值为 5 的新节点
Node* newNode = new Node;
newNode->data = 5;
newNode->next = head;   // 第一步：新节点指向原来的头
head = newNode;          // 第二步：head 更新为新节点

```

图示：

```
插入前: head → [10] → [20] → [30] → nullptr
newNode = [5]
第一步: [5] → [10] → [20] → [30] → nullptr  (newNode 接上原链表)
第二步: head → [5] → [10] → [20] → [30] → nullptr  (head 指向新节点)

```

### 5.5 在指定节点后插入

在节点 `p` 后面插入新节点，注意"先连后断"：

```cpp
// 在 p 后面插入值为 15 的新节点
Node* newNode = new Node;
newNode->data = 15;
newNode->next = p->next;   // 第一步：新节点先接上 p 的后继
p->next = newNode;          // 第二步：p 再指向新节点

```

> **易错点**：顺序不能反！如果先写 `p->next = newNode`，则 `p` 原来的后继节点就"丢了"（没有任何指针指向它），链表从那里断裂。口诀：**先连后断**——先把新节点连上后面的，再让前面的指向新节点。

### 5.6 删除指定节点后的节点

删除 `p` 后面的节点，要先用临时指针记住它，再断开链接，最后释放内存：

```cpp
// 删除 p 后面的节点
Node* tmp = p->next;      // 第一步：记住要删除的节点
p->next = tmp->next;      // 第二步：p 跳过被删节点，直接指向下下个
delete tmp;                // 第三步：释放内存

```

> **易错点**：不能先 `delete` 再断开——删除后 `tmp` 的内容已无效，`tmp->next` 就成了"访问已释放内存"的错误。必须先断开链接，再 `delete`。

## 六、双向链表的手写实现

### 6.1 为什么需要双向

单链表只能往后走，不能往前。如果要从某个节点找它的前驱，只能从头遍历，O(n)。双向链表每个节点多一个 `prev` 指针指向前一个节点，前后都能走。

### 6.2 节点定义

```cpp
struct Node {
    int data;
    Node* prev;    // 指向前一个节点
    Node* next;    // 指向下一个节点
};

```

### 6.3 创建与连接

```cpp
Node* a = new Node;  a->data = 10;
Node* b = new Node;  b->data = 20;
Node* c = new Node;  c->data = 30;

// 双向连接: a ↔ b ↔ c
a->prev = nullptr;  a->next = b;
b->prev = a;         b->next = c;
c->prev = b;         c->next = nullptr;

Node* head = a;   // 头指针
Node* tail = c;   // 尾指针（双向链表常同时维护头尾）

```

### 6.4 双向链表的后插操作

在 `p` 后面插入新节点 `newNode`，需要修改 4 个指针：

```cpp
Node* newNode = new Node;
newNode->data = 15;

newNode->next = p->next;    // 新节点的 next 接上 p 的后继
newNode->prev = p;           // 新节点的 prev 指向 p
if (p->next != nullptr) {    // 如果 p 后面原本有节点
    p->next->prev = newNode; // 那个节点的 prev 改指向新节点
}
p->next = newNode;           // p 的 next 指向新节点

```

> **要点**：双向链表插入要改 4 个指针，删除要改 2 个指针。比单链表复杂，但双向遍历更灵活。C++ STL 的 `list` 底层就是双向链表。

## 七、STL list 入门

### 7.1 什么是 STL

STL（Standard Template Library，标准模板库）是 C++ 自带的一套现成数据结构和算法库。它提供了链表（`list`）、动态数组（`vector`）、栈（`stack`）、队列（`queue`）等常用容器，不用自己手写，直接 `#include` 就能用。

### 7.2 使用 list 的基本框架

```cpp
#include <iostream>
#include <list>           // 引入 list 头文件
using namespace std;

int main() {
    list<int> lst;        // 声明一个存 int 的链表
    // list<int> 相当于"一个装 int 的双向链表"
    return 0;
}

```

> **要点**：`list<int>` 中的 `<int>` 是模板参数，表示链表里存的是 `int` 类型。想存 `double` 就写 `list<double>`，想存 `char` 就写 `list<char>`。STL `list` 底层就是双向链表，我们手写的那些指针操作，STL 已经帮我们封装好了。

## 八、STL list 常用函数

### 8.1 函数速查表

| 函数 | 作用 | 时间复杂度 |
| --- | --- | --- |
| `push_back(x)` | 在尾部添加元素 x | O(1) |
| `push_front(x)` | 在头部添加元素 x | O(1) |
| `pop_back()` | 删除尾部元素 | O(1) |
| `pop_front()` | 删除头部元素 | O(1) |
| `front()` | 访问头部元素（不删除） | O(1) |
| `back()` | 访问尾部元素（不删除） | O(1) |
| `size()` | 返回元素个数 | O(1) |
| `empty()` | 判断是否为空（空返回 true） | O(1) |
| `clear()` | 清空所有元素 | O(n) |
| `insert(it, x)` | 在迭代器 it 处插入 x | O(1) |
| `erase(it)` | 删除迭代器 it 处的元素 | O(1) |

### 8.2 增删查改完整示例

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> lst;

    // 尾部添加
    lst.push_back(10);
    lst.push_back(20);
    lst.push_back(30);
    // 链表: 10 → 20 → 30

    // 头部添加
    lst.push_front(5);
    // 链表: 5 → 10 → 20 → 30

    // 查看头尾和大小
    cout << "头: " << lst.front() << '\n';   // 5
    cout << "尾: " << lst.back() << '\n';    // 30
    cout << "个数: " << lst.size() << '\n';  // 4

    // 删除头尾
    lst.pop_front();   // 删 5
    lst.pop_back();    // 删 30
    // 链表: 10 → 20

    cout << "删后个数: " << lst.size() << '\n';  // 2

    // 清空
    lst.clear();
    cout << "清空后是否为空: " << lst.empty() << '\n';  // 1 (true)

    return 0;
}

```

> **易错点**：对空链表调用 `front()`、`back()`、`pop_front()`、`pop_back()` 是未定义行为（程序可能崩溃）。调用前先用 `empty()` 检查。

## 九、STL list 的遍历与迭代器

### 9.1 迭代器入门

迭代器（iterator）是 STL 中类似"指针"的东西，用来指向容器中的某个元素。`list` 不支持 `[]` 下标访问，遍历必须用迭代器。

```cpp
list<int> lst;
lst.push_back(10);
lst.push_back(20);
lst.push_back(30);

// 用迭代器遍历
for (list<int>::iterator it = lst.begin(); it != lst.end(); ++it) {
    cout << *it << ' ';    // *it 取出 it 指向的值
}
cout << '\n';
// 输出: 10 20 30

```

-   `lst.begin()`：返回指向第一个元素的迭代器
-   `lst.end()`：返回指向"最后一个元素之后"的迭代器（哨兵位置，不指向真实元素）
-   `*it`：取出迭代器指向的值（解引用）
-   `++it`：迭代器前进一步

### 9.2 用 auto 简化

`list<int>::iterator` 太长，C++11 的 `auto` 关键字可以自动推导类型：

```cpp
for (auto it = lst.begin(); it != lst.end(); ++it) {
    cout << *it << ' ';
}

```

### 9.3 range-based for 循环（最简单）

C++11 还提供了 range-based for 循环，遍历容器最简洁：

```cpp
for (int x : lst) {     // 每次取出一个元素赋给 x
    cout << x << ' ';
}

```

> **要点**：三种遍历方式效果相同。日常写题推荐 range-based for（最简洁）；需要在遍历中插入/删除元素时，必须用迭代器（range-based for 内部用迭代器，但删除会使迭代器失效，不能边遍历边删）。

### 9.4 insert 与 erase 的正确用法

```cpp
list<int> lst;
lst.push_back(10);
lst.push_back(20);
lst.push_back(30);
// 链表: 10 → 20 → 30

auto it = lst.begin();
++it;                    // it 指向 20

lst.insert(it, 15);     // 在 20 前面插入 15 → 10 → 15 → 20 → 30
// 注意: insert 后 it 仍指向 20（list 迭代器不失效）

it = lst.erase(it);     // 删除 20，it 接收返回值，指向 30
// 链表: 10 → 15 → 30
// 注意: erase 后 it 作废！必须用返回值更新

```

> **易错点**：`erase` 会使被删元素的迭代器失效。`erase` 会返回指向下一个有效元素的迭代器，必须用 `it = lst.erase(it)` 接收。如果写 `lst.erase(it)` 后继续用 `it`，程序行为未定义。

## 十、常见题型汇总

### 10.1 约瑟夫问题（STL list 的经典应用）

**题意**：n 个人围成一圈，从第 1 个人开始报数，数到 m 的人出列，下一个人重新从 1 开始报数，直到所有人出列。输出出列顺序。

**分析**：这是一个环形结构，需要频繁删除当前元素并从下一个继续。STL `list` 的 `erase` 配合迭代器循环移动，天然适合。

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    list<int> lst;
    for (int i = 1; i <= n; i++) {
        lst.push_back(i);
    }

    auto it = lst.begin();
    while (!lst.empty()) {
        // 数 m-1 个人，it 停在第 m 个人
        for (int i = 1; i < m; i++) {
            ++it;
            if (it == lst.end()) it = lst.begin();  // 到末尾绕回头部
        }
        cout << *it << ' ';
        it = lst.erase(it);      // 删除当前，it 指向下一个人
        if (it == lst.end()) it = lst.begin();  // 删到末尾绕回
    }
    cout << '\n';

    return 0;
}

```

输入: `5 3` 输出: `3 1 5 2 4`

> **要点**：`list` 的 `erase` 返回下一个迭代器，正好接上"下一个人重新报数"的逻辑。环形通过 `it == lst.end()` 时绕回 `lst.begin()` 实现。

### 10.2 队列安排（数组模拟双向链表）

**题意**（洛谷 P1160）：N 个同学排成一列。1 号先入列，2~N 号依次插入到某同学的左边或右边。之后去掉 M 个同学，输出最终队列。

**分析**：N 最大 10 万，频繁在序列中间插入删除。用 STL `list` 每次找位置要 O(N)，总 O(N²) 会超时。信奥竞赛的标准解法是**数组模拟双向链表**——用 `l[i]` 和 `r[i]` 数组记录 i 号同学的左右邻居，所有操作 O(1)。

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N=1e5+5;
int n,m;
int L[N],R[N]; 

int main(){
	cin>>n;
	//0号哨兵
	L[0]=0,R[0]=0;
	//1号同学入列
	L[1]=0,R[1]=0;
	L[0]=1,R[0]=1;
	//2-n入列
	for(int i=2;i<=n;i++){
		int k,p;
		cin>>k>>p;
		//先连后断 
		if(p==0){//插入到k的左边 
			L[i]=L[k],R[i]=k;
			R[L[k]]=i,L[k]=i; 
		}else{//插入到k的右边 
			L[i]=k,R[i]=R[k];
			L[R[k]]=i,R[k]=i;
		}
	}
	//删除m个同学
	cin>>m;
	while(m--){
		int x;
		cin>>x;
		// 若 x 已被删除，则跳过 
		if(R[x]==-1) continue;
		// 删除 x: 左右邻居互相连起来
		R[L[x]]=R[x],L[R[x]]=L[x];
		L[x]=R[x]=-1;//标记为废弃指针 
	}
	// 从哨兵 0 的右边开始, 顺着 R[] 输出
	int cur=R[0];
	while(cur!=0) cout<<cur<<" ",cur=R[cur]; 
	return 0;
}

```

> **要点**：数组模拟链表是信奥竞赛的核心技巧。把"指针"换成"数组下标"，`next` 换成 `r[i]`，`prev` 换成 `l[i]`。优点：不用 `new`/`delete`，速度快，代码短。哨兵节点 `0` 简化边界处理。

### 10.3 单向链表操作（数组模拟单链表）

**题意**（洛谷 B3631）：维护一张表（初始只有元素 1），支持三种操作：在 x 后插入 y、查询 x 后面的数、删除 x 后面的数。

**分析**：所有值唯一且在 1~10⁶ 范围内。直接用 `nxt[x]` 表示"x 后面的数"，数组下标就是值本身，所有操作 O(1)。

```cpp
#include <iostream>
using namespace std;

const int MAXV = 1000005;
int nxt[MAXV];  // nxt[x] = x 后面的数, 0 表示没有

int main() {
    int q;
    cin >> q;
    nxt[1] = 0;  // 初始只有 1, 后面没有

    while (q--) {
        int op, x;
        cin >> op >> x;
        if (op == 1) {            // 在 x 后插入 y
            int y;
            cin >> y;
            nxt[y] = nxt[x];      // y 接上 x 的后继
            nxt[x] = y;           // x 指向 y
        } else if (op == 2) {     // 查询 x 后面的数
            cout << nxt[x] << '\n';
        } else {                  // 删除 x 后面的数
            nxt[x] = nxt[nxt[x]]; // x 的下一个变成下下个
        }
    }
    return 0;
}

```

> **要点**：当数据值域不大且唯一时，用"值当数组下标"的数组模拟单链表，代码极简。插入三步、删除一步，全是 O(1)。

## 十一、常见错误与注意事项

| 编号 | 错误 | 后果 | 改正 |
| --- | --- | --- | --- |
| E1 | 节点的 `next` 未初始化为 `nullptr` | 指向随机地址，遍历越界崩溃 | `new` 后立即设 `next = nullptr` |
| E2 | 插入时先改前驱指针再接后继 | 后续节点丢失，链表断裂 | 遵循"先连后断"：新节点先接后继，前驱再指新节点 |
| E3 | 删除节点时先 `delete` 再断链接 | 访问已释放内存，未定义行为 | 先断开链接，再 `delete` |
| E4 | `new` 了节点但从不 `delete` | 内存泄漏，长跑程序内存涨 | 删除时配对 `delete`；或用数组模拟避免 |
| E5 | 对空 `list` 调用 `front()`/`pop_back()` | 未定义行为，可能崩溃 | 先用 `empty()` 检查 |
| E6 | 用 `lst[i]` 访问 `list` 元素 | 编译错误，`list` 不支持随机访问 | 用迭代器或 range-based for 遍历 |
| E7 | `erase(it)` 后继续使用 `it` | 迭代器失效，未定义行为 | 用 `it = lst.erase(it)` 接收返回值 |
| E8 | 忘记 `#include <list>` | 编译错误，`list` 未定义 | 文件开头加 `#include <list>` |
| E9 | range-based for 中删除元素 | 迭代器失效，行为未定义 | 需要边遍历边删时改用迭代器循环 |
| E10 | 数组模拟链表忘记初始化哨兵 | `r[0]`/`l[0]` 为 0，链表为空或死循环 | 初始化时设好 `r[0]` 和 `l[0]` 指向第一个真实节点 |

> **补充说明——迭代器失效规则**：`list` 的迭代器在 `insert` 后**不会失效**（包括指向被插位置的迭代器）；`erase` 只使**被删元素**的迭代器失效，其他迭代器不受影响。这与 `vector` 不同（`vector` 的 `insert`/`erase` 可能使所有迭代器失效）。这是 `list` 底层链表结构决定的——节点独立分配，互不影响。

## 十二、方法、套路与策略小结

### 12.1 链表插入三步套路

无论单链表还是双向链表，插入新节点都遵循固定套路：

1.  **建**：`new` 创建新节点，设好数据域
2.  **连**：新节点的指针先接上后继（和前驱）
3.  **断**：前驱节点的指针改指向新节点

口诀：**先连后断**。先把新的连上去，再让旧的指向新的。

### 12.2 数组 vs 链表决策表

| 对比维度 | 数组 | 链表 |
| --- | --- | --- |
| 随机访问 `a[i]` | O(1)，极快 | O(n)，只能从头走 |
| 头部插入/删除 | O(n)，要搬元素 | O(1)，改指针即可 |
| 中间插入/删除 | O(n)，要搬元素 | O(1)，改指针即可（已知位置） |
| 内存 | 连续，紧凑 | 离散，每节点多存指针 |
| 适用场景 | 需要随机访问、少插删 | 频繁插删、不需随机访问 |

### 12.3 手写 vs STL list 决策表

| 场景 | 推荐选择 | 原因 |
| --- | --- | --- |
| 学习理解链表原理 | 手写指针版 | 直观理解节点与指针 |
| 竞赛需要 O(1) 插删且值域小 | 数组模拟 | 最快，无内存管理负担 |
| 竞赛需要通用链表 | STL `list` | 现成函数，代码短 |
| 需要随机访问 | 都不用，用 `vector` 或数组 | 链表不擅长随机访问 |

### 12.4 策略意识

-   **性能意识**：竞赛中数组模拟链表比指针版更快（连续内存访问、无 `new` 开销）。能用数组模拟就别用指针。
-   **规范意识**：手写指针链表必须 `new`/`delete` 配对；STL `list` 用迭代器操作时注意失效规则。
-   **策略意识**：看到"频繁在中间插入删除"就想到链表；看到"需要随机访问"就想到数组。选对数据结构，题目就解决了一半。

### 自编题：list 基本操作练习

**题面**：读入 n 个整数，依次用 `push_back` 加入 `list`。然后执行：① 用 `push_front` 在头部加 0；② 用 `pop_back` 删除尾部；③ 输出当前链表所有元素、头部元素、尾部元素和元素个数。

**输入格式**：第一行 n；第二行 n 个整数。

**输入示例**：

```
4
10 20 30 40

```

**输出示例**：

```
0 10 20 30
头: 0
尾: 30
个数: 4

```

**参考答案**：

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    int n;
    cin >> n;
    list<int> lst;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        lst.push_back(x);
    }
    lst.push_front(0);
    lst.pop_back();
    for (int x : lst) {
        cout << x << ' ';
    }
    cout << '\n';
    cout << "头: " << lst.front() << '\n';
    cout << "尾: " << lst.back() << '\n';
    cout << "个数: " << lst.size() << '\n';
    return 0;
}

```

```cpp
const int MAXN = 100005;
int l[MAXN], r[MAXN];  // l[i]=左邻居, r[i]=右邻居, 0 为哨兵

// 初始化（只有 1 号节点）
r[0] = 1; l[0] = 1; r[1] = 0; l[1] = 0;

// 在 x 右边插入 k
r[k] = r[x]; l[k] = x; l[r[x]] = k; r[x] = k;

// 在 x 左边插入 k
l[k] = l[x]; r[k] = x; r[l[x]] = k; l[x] = k;

// 删除 x
r[l[x]] = r[x]; l[r[x]] = l[x];

// 遍历输出（从哨兵右边开始）
for (int p = r[0]; p != 0; p = r[p]) {
    cout << p << ' ';
}
```
