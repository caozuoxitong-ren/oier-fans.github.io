## 三、教学重点与难点

### 1\. 教学重点

-   变量命名规则：字母/数字/下划线、不能数字开头、不能是关键字、区分大小写。
-   四种基本类型 `int`/`long long`、`float`/`double`、`char`、`bool` 各自存放什么、用什么写法给值。
-   变量定义语法 `类型 变量名;`，赋值 `=`，初始化 `int a = 10;`。
-   cin 输入语法 `cin >> 变量;`，与 cout 方向相反（`>>` 向右流入变量）。
-   算术运算五则，尤其整数除法 `7/2=3` 与求余 `7%2=1`。
-   用 `sizeof(类型)` 查看类型占用的字节数，理解"1 字节 = 8 位"。
-   隐式转换的方向（低精度→高精度）与强制转换的写法 `(int)x`、`static_cast<int>(x)`。

### 2\. 教学难点

-   理解"变量是装数据的盒子"，类型决定盒子能装什么。
-   `=` 是赋值（把右边的值放进左边的变量），不是数学里的"等于"。
-   整数除整数得整数（直接丢小数，不是四舍五入），是本课最大坑。
-   `%` 求余只能用于整数，不能用于 double。
-   cin 的 `>>` 与 cout 的 `<<` 方向容易记混。
-   隐式转换中"赋值时高精度→低精度会截断"（如 `int a = 3.14` 得 3 而非 4）。
-   强制转换只作用于紧跟着的一个表达式：`(double)a / b` ≠ `(double)(a / b)`。

## 四、为什么需要变量

### 1\. 第一课的局限

第一课我们用 cout 输出的是"写死"的内容：

```cpp
cout << "3 + 4 = " << 3 + 4 << endl;   // 永远只算 3+4

```

如果题目要算 `5 + 8`、`100 + 200`，难道每次都改代码？当然不行。我们需要一种东西，能**在程序运行时临时存放数据**，还能反复使用、反复计算——这就是**变量**。

### 2\. 变量带来的改变

有了变量，程序可以"先读入数据，再计算，最后输出"：

```cpp
int a, b;            // 准备两个"盒子"装整数
cin >> a >> b;       // 从键盘读入 a 和 b
cout << a + b;       // 输出它们的和

```

这样一份代码，输入 `3 4` 就输出 `7`，输入 `100 200` 就输出 `300`——程序变得通用了。这就是变量的价值。

## 五、变量是什么

**变量是内存里的一块空间，用来存放数据。** 你可以把它想象成一个"贴了标签的盒子"：

-   **盒子** = 内存里的一块空间
-   **标签（变量名）** = 你给这块空间起的名字
-   **内容（变量的值）** = 盒子里装的数据
-   **盒子的形状（数据类型）** = 决定能装什么类型的数据

```
┌─────────────┐
│   a = 10    │   ← 变量名 a，值是 10，类型 int（装整数）
└─────────────┘

```

关键特点：

-   变量的值**可以改变**（所以叫"变"量）：`a = 10;` 之后可以 `a = 20;`，新值覆盖旧值。
-   变量**必须先定义再使用**：没定义过的变量名不能用。

## 六、变量名规范与注意事项

### 1\. 命名规则（必须遵守，否则编译错误）

| 规则 | 说明 | 合法示例 | 非法示例 |
| --- | --- | --- | --- |
| 只能由字母、数字、下划线组成 | 不能有空格、不能有其他符号 | `score`、`a1`、`_tmp` | `s core`、`a-b`、`a#` |
| 不能以数字开头 | 第一个字符必须是字母或下划线 | `a1`、`_x` | `1a`、`2nd` |
| 不能是 C++ 关键字 | 关键字是语言保留的词 | `num`、`sum` | `int`、`return`、`main` |
| 区分大小写 | `a` 和 `A` 是两个不同变量 | `a` 与 `A` 不同 | — |

### 2\. 常见 C++ 关键字（先记这几个，别拿来当变量名）

`int`、`double`、`char`、`bool`、`return`、`if`、`else`、`for`、`while`、`main`（main 不是关键字但保留作主函数名，别用）。

### 3\. 命名建议（好习惯，不强制）

-   **见名知意**：`score` 比 `s` 好，`age` 比 `a` 好。竞赛题变量多时可短，如 `a`、`b`、`n`。
-   **风格统一**：要么用驼峰 `studentScore`，要么用下划线 `student_score`，别混用。
-   **别太长**：`the_score_of_the_student` 太啰嗦，`score` 就够。

### 4\. 注意事项

-   变量名不能重复定义（同一作用域内）：`int a; int a;` 会报错。
-   不要用拼音缩写到自己也看不懂：`cj` 是成绩还是差价？写 `score` 更清楚。
-   大小写敏感是双刃剑：`Sum` 和 `sum` 是两个变量，别手滑。

## 七、数据类型与四种基本类型

### 1\. 为什么要有类型

不同数据占的空间不同、能做的运算不同。比如：

-   整数 `3` 和 `4` 能做 `3 % 4`（求余）；
-   小数 `3.14` 不能做 `%`；
-   字符 `'A'` 本质存的是 ASCII 码（整数），所以也能做加减运算（如 `'a'-32` 转大写）。

所以定义变量时，必须**先告诉计算机这个变量是什么类型**。

### 2\. 四种基本数据类型

| 类型 | 关键字 | 存放内容 | 占用空间 | 取值范围（参考） | 给值写法 |
| --- | --- | --- | --- | --- | --- |
| 整型 | `int` | 整数 | 4 字节 | 约 ±21 亿（−2147483648 ~ 2147483647） | `10`、`-5` |
| 整型 | `long long` | 整数 | 8 字节 | 约 ±9.2×10¹⁸（−9223372036854775808 ~ 9223372036854775807） | `1000000000`、`5LL` |
| 浮点型 | `float` | 小数 | 4 字节 | 约 ±3.4×10³⁸，有效数字 6~7 位 | `3.14f`、`-0.5f` |
| 浮点型 | `double` | 小数 | 8 字节 | 约 ±1.7×10³⁰⁸，有效数字 15~16 位 | `3.14`、`-0.5` |
| 字符型 | `char` | 单个字符 | 1 字节 | 实际存 ASCII 码（0~127） | `'A'`、`'9'` |
| 布尔型 | `bool` | 真或假 | 1 字节 | `true`(1) / `false`(0) | `true`、`false` |

### 3\. 各类型详解

**① 整型 `int` 与 `long long`**

-   `int`：存整数，4 字节，范围约 ±21 亿，是最常用的整型。
-   `long long`：存整数，8 字节，范围约 ±9.2×10¹⁸。当数据或结果可能超过 21 亿时（如人数、大数求和），必须用 `long long`，否则会溢出得到错误结果。
-   写法：直接写数字，不加引号；`long long` 字面量可加 `LL` 后缀。

```cpp
int age = 12;
int score = 100;
long long big = 1000000000000LL;   // 超过 21 亿，用 long long

```

**② 浮点型 `float` 与 `double`**

-   `float`：存小数，4 字节，有效数字 6~7 位，精度较低。
-   `double`：存小数，8 字节，有效数字 15~16 位，精度高。
-   信奥里**小数一律用 `double`**，不用 `float`（精度不够容易出错）。
-   注意：`double` 存小数有精度误差，`0.1 + 0.2` 可能不精确等于 `0.3`，后续会讲。

```cpp
float f = 3.14f;        // float 字面量加 f 后缀
double pi = 3.14159;
double temp = 36.5;

```

**③ 字符型 `char`**

-   存**单个**字符，用**单引号** `' '` 括起来。
-   字符本质存的是 ASCII 码：`'A'` 实际存的是 65，`'a'` 是 97，`'0'` 是 48。
-   单引号里只能放一个字符：`'A'` 对，`'AB'` 错。

```cpp
char ch = 'A';
char op = '+';

```

**④ 布尔型 `bool`**

-   只有两个值：`true`（真，等于 1）和 `false`（假，等于 0）。
-   常用来表示"是/否"，如"是否及格"。

```cpp
bool pass = true;
bool isEnd = false;

```

### 4\. 类型选择口诀

**整数用 int（可能超 21 亿用 long long），小数用 double，单个字符用 char，是非判断用 bool。**

### 5\. 用 sizeof 查看类型或变量占用的字节数

上面的类型表列出了每种类型"占几个字节"，这些数字怎么来的？C++ 提供了一个运算符 **`sizeof`**，可以查看某个类型或变量占多少字节。

**语法：** `sizeof(类型)` 或 `sizeof(变量)`，括号不能省。

```cpp
cout << sizeof(int) << endl;        // 4
cout << sizeof(long long) << endl;  // 8
cout << sizeof(double) << endl;     // 8
cout << sizeof(char) << endl;       // 1
cout << sizeof(bool) << endl;       // 1

int a = 10;
cout << sizeof(a) << endl;          // 4（和 sizeof(int) 一样，看的是变量类型）

```

**几个要点：**

-   `sizeof` 是**关键字**，不是函数，它是一个**编译期运算符**——程序还没运行，编译器就已经算出结果填进去了。
-   `sizeof(变量)` 和 `sizeof(变量的类型)` 结果相同：它查的是"这个类型占多大"，跟变量里存的值无关。`sizeof(a)` 不关心 a 是 10 还是 9999，只关心 a 是 `int`。
-   `sizeof(char)` 按标准**恒为 1**，这是 C++ 的规定。
-   `sizeof` 返回的是**字节数**，不是位数。1 字节 = 8 位，所以 `sizeof(int)=4` 表示 int 占 32 位。
-   不同类型的大小可能随编译器/平台不同而变化，但信奥评测机（64 位 Linux + g++）上：`int=4`、`long long=8`、`double=8`、`float=4`、`char=1`、`bool=1`，与上表一致。

> **用途：** 写代码时如果记不清某个类型占多大、会不会溢出，可以用 `sizeof` 临时打印一下确认。但平时做题不必每次都查，记住"int=4 字节约 21 亿、long long=8 字节约 9.2×10¹⁸"即可。

## 八、变量的定义、赋值与初始化

### 1\. 定义变量

语法：`类型 变量名;`

```cpp
int a;            // 定义一个整型变量 a
double x;         // 定义一个浮点变量 x
char ch;          // 定义一个字符变量 ch
bool flag;        // 定义一个布尔变量 flag

```

可以一次定义多个同类型变量，用逗号隔开：

```cpp
int a, b, c;      // 一次定义三个整型变量

```

### 2\. 赋值（=）

`=` 是**赋值运算符**：把右边的值放进左边的变量。

```cpp
a = 10;           // 把 10 放进 a
a = 20;           // 把 a 的值改成 20（旧值 10 被覆盖）
b = a;            // 把 a 的值复制给 b（此时 b 也是 20）

```

> **关键理解：** `=` 不是"等于"，是"把右边的放进左边"。所以 `a = a + 1;` 是合法的——意思是"把 a 加 1 后再放回 a"。

### 3\. 初始化（定义时直接给值）

定义的同时给值，叫初始化：

```cpp
int a = 10;            // 定义 a 并初始化为 10
double pi = 3.14;      // 定义 pi 并初始化为 3.14
char ch = 'A';         // 定义 ch 并初始化为 'A'
int b = 3, c = 4;      // 定义多个并分别初始化

```

> **重要：** 变量**未赋值就读取**，得到的是"垃圾值"（内存里残留的随机数）。养成"定义即初始化"的好习惯。

### 4\. 三种写法对照

| 写法 | 含义 | 推荐度 |
| --- | --- | --- |
| `int a;` | 只定义，未给值 | 注意垃圾值 |
| `int a = 10;` | 定义并初始化 | 推荐 |
| `int a; a = 10;` | 先定义，再赋值 | 可以，分两步 |

## 九、用 cin 输入变量的值

### 1\. 基本语法

cin 是"标准输入流"对象，`>>` 叫**提取运算符**。

**读法：** 把 `>>` 左边 cin（键盘）的数据，提取到右边的变量里。

```cpp
cin >> 变量名;

```

注意方向：`>>` 向右，数据从键盘流向变量。

### 2\. 输入一个变量

```cpp
int a;
cin >> a;         // 从键盘读入一个整数放进 a

```

运行时在键盘输入 `10` 回车，a 就变成 10。

### 3\. 输入多个变量

用多个 `>>` 串起来，输入时用空格或回车分隔：

```cpp
int a, b;
cin >> a >> b;    // 读入两个整数

```

输入 `3 4` 或 `3↵4`（↵表示回车）都可以，a 得 3，b 得 4。

### 4\. 不同类型的输入

```cpp
int n;  cin >> n;        // 输入整数：10
double x; cin >> x;      // 输入小数：3.14
char ch; cin >> ch;      // 输入单个字符：A

```

> **注意：** `cin >> ch` 读字符时会**跳过空格和回车**，直接读下一个非空白字符。

### 5\. cin 与 cout 方向对比

| 对象 | 运算符 | 方向 | 记忆 |
| --- | --- | --- | --- |
| cout | `<<` | 内容流向屏幕（向左） | "送出去" |
| cin | `>>` | 数据流向变量（向右） | "读进来" |

口诀：**cout 用 `<<` 往外送，cin 用 `>>` 往里读。**

## 十、用 cout 输出变量

### 1\. 输出变量的值

变量名不加引号，cout 输出的是变量里的值，不是变量名：

```cpp
int a = 10;
cout << a;        // 输出: 10（输出 a 的值，不是字母 a）

```

### 2\. 变量与字符串混合输出

和第一课一样，用 `<<` 串起来：

```cpp
int a = 10, b = 20;
cout << "a = " << a << ", b = " << b << endl;
// 输出: a = 10, b = 20

```

### 3\. 输出参与算式的变量

变量可以直接参与运算后输出：

```cpp
int a = 3, b = 4;
cout << "a + b = " << a + b << endl;   // 输出: a + b = 7
cout << "a * b = " << a * b << endl;   // 输出: a * b = 12

```

### 4\. 完整示例：读入两数输出和

```cpp
#include <iostream>
using namespace std;
int main(){
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}

```

输入 `3 4`，输出 `7`。这就是洛谷 P1001（A+B Problem）的核心代码。

## 十一、算术运算

### 1\. 五个基本算术运算符

| 运算符 | 含义 | 示例 | 结果 | 适用类型 |
| --- | --- | --- | --- | --- |
| `+` | 加 | `3 + 4` | `7` | 整数、小数 |
| `-` | 减 | `10 - 3` | `7` | 整数、小数 |
| `*` | 乘 | `6 * 7` | `42` | 整数、小数 |
| `/` | 除 | `15 / 4` | `3`（见下） | 整数、小数 |
| `%` | 取余（取模） | `15 % 4` | `3` | **仅整数** |

### 2\. 整数除法（重点坑点）

**两个整数相除，结果还是整数，小数部分直接丢弃（不是四舍五入）。**

```cpp
cout << 15 / 4;      // 输出 3，不是 3.75
cout << 7 / 2;       // 输出 3，不是 3.5
cout << 1 / 2;       // 输出 0

```

**怎么得到小数？** 只要有一个是小数（浮点），就按小数算：

```cpp
cout << 15.0 / 4;    // 输出 3.75
cout << 7 / 2.0;     // 输出 3.5
cout << 1.0 / 2;     // 输出 0.5

```

> **规律：** 整数 ÷ 整数 = 整数（丢小数）；只要有一边是小数 = 小数。变量同理：`int a=7; cout << a/2;` 输出 3；`double x=7; cout << x/2;` 输出 3.5。背后的原理是**数据类型转换**（见下一节）。

### 3\. 取余运算 `%`

`%` 求的是除法的**余数**。`15 % 4` 读作"**15 取余 4**"，或"**15 除以 4 的余数**"（两种读法都对，课堂可任选一种统一使用）。

```cpp
cout << 15 % 4;      // 15÷4=3余1，输出 1
cout << 7 % 2;       // 7÷2=3余1，输出 1
cout << 10 % 5;      // 10÷5=2余0，输出 0

```

> **重要：** `%` 只能用于整数，不能用于小数。`3.14 % 2` 会编译错误。

**求余的常见用途：**

-   判断奇偶：`n % 2 == 0` 是偶数，`n % 2 == 1` 是奇数。
-   取个位：`n % 10` 得到 n 的个位数字（如 `123 % 10 = 3`）。
-   取十位：`n / 10 % 10`（如 `123 / 10 = 12`，`12 % 10 = 2`）。

### 4\. 运算优先级

和数学一样：**先乘除求余，后加减**，有括号先算括号。

```cpp
cout << 2 + 3 * 4;       // 输出 14，不是 20（先算 3*4=12，再 2+12）
cout << (2 + 3) * 4;     // 输出 20（括号改变顺序）
cout << 10 - 2 * 3;      // 输出 4（先 2*3=6，再 10-6）

```

> **建议：** 拿不准优先级时，**加括号**，既不会错，也更好读。

### 5\. 字符与整数的运算（拓展）

char 本质存的是 ASCII 码，所以可以和整数运算：

```cpp
char ch = 'a';           // 'a' 的 ASCII 码是 97
cout << char(ch - 32);   // 97-32=65，即 'A'，输出 A（小写转大写）

```

小写转大写的规律：小写字母比对应大写字母大 32。`'a'-'A'` = 32。这是洛谷 P5704（字母转换）的原理。这里的 `char(ch - 32)` 就用到了**强制类型转换**，下一节详细讲。

### 6\. 复合赋值与自增（拓展，信奥常用）

| 写法 | 等价于 | 含义 |
| --- | --- | --- |
| `a += 5` | `a = a + 5` | 加 5 后赋回 |
| `a -= 2` | `a = a - 2` | 减 2 后赋回 |
| `a *= 3` | `a = a * 3` | 乘 3 后赋回 |
| `a++` | `a = a + 1` | 自增 1 |
| `a--` | `a = a - 1` | 自减 1 |

```cpp
int a = 10;
a += 5;        // a 变成 15
a++;           // a 变成 16

```

## 十二、数据类型转换

上一节讲到"整数除整数得整数，只要有一边是小数就得小数"——这背后就是**数据类型转换**在起作用。当不同类型的数据混合在一起（运算或赋值）时，C++ 有一套规则来处理类型不匹配的问题。

### 1\. 两种转换方式总览

| 类别 | 名称 | 谁来做 | 写法 |
| --- | --- | --- | --- |
| 隐式转换 | 自动类型转换 | 编译器自动完成 | 不需要额外写 |
| 显式转换 | 强制类型转换 | 程序员手动指定 | `(int)x`、`int(x)`、`static_cast<int>(x)` |

### 2\. 隐式类型转换（自动转换）

隐式转换是编译器**自动完成**的类型转换，不需要程序员写额外代码。有三种常见场景：

**① 算术转换——混合运算时，低精度自动转高精度**

当不同类型的数据做算术运算时，编译器会先把低精度的一方**自动提升**为高精度，再运算。转换方向（低→高）：

```
bool → char → int → long long → float → double

```

最常见的情况是 int 和 double 混合运算：

```cpp
int a = 3;
double b = 0.14;
cout << a + b;     // 输出 3.14（a 自动转为 double，再和 b 相加）

```

| 表达式 | 转换过程 | 结果 | 结果类型 |
| --- | --- | --- | --- |
| `3 + 0.14` | int 3 → double 3.0 | 3.14 | double |
| `7 / 2.0` | int 7 → double 7.0 | 3.5 | double |
| `'A' + 1` | char 'A'(65) → int 65 | 66 | int |

> **这就是"整数除法加 .0 变小数"的原理**：`7 / 2.0` 中，`2.0` 是 double，编译器把 `7` 也自动转为 double，按小数除法算，得 3.5。

**② 赋值转换——赋值时，右边类型自动转为左边类型**

赋值运算 `=` 会把右边值的类型**自动转为**左边变量的类型。如果右边精度高于左边，会**截断**（丢失信息）。

```cpp
int a = 3.14;       // 3.14 是 double，赋给 int 变量，小数部分截断，a = 3
double x = 5;       // 5 是 int，赋给 double 变量，x = 5.0
char ch = 65;       // 65 是 int，赋给 char 变量，ch = 'A'（ASCII 65）
bool flag = 0;      // 0 是 int，赋给 bool 变量，flag = false

```

| 赋值语句 | 右边类型 | 左边类型 | 转换结果 | 说明 |
| --- | --- | --- | --- | --- |
| `int a = 3.14;` | double | int | a = 3 | 小数部分直接丢弃（截断，非四舍五入） |
| `int a = 3.99;` | double | int | a = 3 | 即使小数部分是 .99 也截断为 3 |
| `double x = 5;` | int | double | x = 5.0 | 整数转小数，不丢信息 |
| `char ch = 65;` | int | char | ch = 'A' | 存 ASCII 码对应的字符 |
| `bool b = 5;` | int | bool | b = true | 非 0 整数转 bool 为 true，0 转 false |

> **易错点：** `int a = 3.99;` 得 3，不是 4！赋值转换是**截断**（直接丢小数部分），不是四舍五入。要四舍五入需用强制转换配合技巧（见第 4 小节）。

**③ 整型提升——bool/char 参与运算时自动提升为 int**

bool、char、short 在算术表达式中会**自动提升**为 int 再运算：

```cpp
char ch = 'A';        // ASCII 65
cout << ch + 1;       // 66（char 提升为 int 后运算，结果是 int）
cout << 'a' - 'A';    // 32（两个 char 都提升为 int 后相减）
bool t = true;        // true = 1
cout << t + 10;       // 11（bool 提升为 int 1 后相加）

```

> **理解要点：** char 本质存的是 ASCII 码（整数），所以参与算术运算时自然按整数算。整型提升让 char 能像整数一样做加减——这就是上一节"字符与整数运算"的底层原理。

### 3\. 强制类型转换（显式转换）

强制类型转换是程序员**主动写出来**的类型转换，明确告诉编译器"把这个值转成什么类型"。

**三种写法：**

```cpp
double x = 3.14;

// 写法一：C 风格——(类型)值
int a = (int)x;              // a = 3

// 写法二：函数风格——类型(值)
int b = int(x);              // b = 3

// 写法三：C++ 风格——static_cast<类型>(值)
int c = static_cast<int>(x); // c = 3

```

| 写法 | 语法 | 示例 | 特点 |
| --- | --- | --- | --- |
| C 风格 | `(类型)表达式` | `(int)3.14` | 最简洁，信奥中最常见 |
| 函数风格 | `类型(表达式)` | `int(3.14)` | 简洁，但只能用于简单类型名 |
| C++ 风格 | `static_cast<类型>(表达式)` | `static_cast<int>(3.14)` | C++ 推荐写法，更安全规范 |

> **本课约定：** 三种写法效果相同，零基础阶段以 **C 风格 `(int)x`** 为主（最简洁），了解 `static_cast<int>(x)` 是 C++ 的推荐写法。后续课程遇到更复杂的场景时再深入。

### 4\. 经典应用与例题

**例题 1：整数除法转小数（最常用）**

两个 int 变量相除，想要小数结果，先把其中一个强制转为 double：

```cpp
int a = 7, b = 2;
cout << (double)a / b;     // 3.5（a 先转 double，b 隐式转 double，按小数除）
cout << 1.0 * a / b;       // 3.5（1.0 是 double，a 隐式提升，效果相同）

```

> **对比：** `a / b` = `7 / 2` = 3（整数除法）；`(double)a / b` = `7.0 / 2` = 3.5（小数除法）。区别就在于转换的时机——**先转换再除**，还是**先除再转换**。

> **易错点：** `(double)(a / b)` ≠ `(double)a / b`！前者先做整数除法 `7/2=3`，再转 double 得 `3.0`；后者先转再除得 `3.5`。**强制转换只作用于紧跟着的那一个表达式**，加括号可以改变作用范围。

**例题 2：截断小数取整**

强制转 int 会直接丢掉小数部分（截断，非四舍五入）：

```cpp
cout << (int)3.14;     // 3
cout << (int)3.99;     // 3（不是 4！截断非四舍五入）
cout << (int)-3.7;     // -3（向零截断：丢小数部分，不是向下取整）

```

**例题 3：四舍五入技巧（正数）**

C++ 没有直接的四舍五入运算符，但可以用"加 0.5 后截断"实现正数四舍五入：

```cpp
double x = 3.6;
cout << (int)(x + 0.5);    // 4（3.6+0.5=4.1，截断得 4）

double y = 3.4;
cout << (int)(y + 0.5);    // 3（3.4+0.5=3.9，截断得 3）

```

| 原值 | +0.5 | 截断取整 | 效果 |
| --- | --- | --- | --- |
| 3.4 | 3.9 | 3 | 向下 |
| 3.6 | 4.1 | 4 | 向上 |
| 3.5 | 4.0 | 4 | 向上（四舍五入） |

> **注意：** 此技巧仅适用于正数。负数的四舍五入需要减 0.5 再截断，入门阶段先掌握正数即可。

**例题 4：char 与 int 互转**

```cpp
char ch = 'a';
cout << (int)ch;             // 97（查看字符的 ASCII 码）
cout << (char)(ch - 32);     // A（小写转大写：97-32=65，转回 char）

```

> **对比两种写法：** `(char)(ch - 32)` 和 `char(ch - 32)` 效果相同，前者是 C 风格，后者是函数风格。上一节"字符与整数运算"中用的 `char(ch - 32)` 就是函数风格的强制转换。

### 5\. 隐式 vs 强制：什么时候用哪个

| 场景 | 用隐式还是强制 | 示例 |
| --- | --- | --- |
| int + double 混合运算 | 隐式（自动完成） | `3 + 0.14` → 3.14 |
| 整数除法要小数结果 | 强制（主动控制） | `(double)a / b` |
| double 赋给 int（截断） | 隐式（自动完成） | `int a = 3.14;` → 3 |
| 四舍五入取整 | 强制（配合技巧） | `(int)(x + 0.5)` |
| 查看字符的 ASCII 码 | 强制 | `(int)ch` |

> **策略意识：** 隐式转换是编译器"偷偷"做的，理解它有助于读懂代码（如为什么 `7/2.0` 得 3.5）。强制转换是程序员"主动"做的，用来精确控制类型（如确保除法得到小数）。**拿不准时，主动写强制转换**，让意图更明确。

## 十三、常见错误与注意事项

| 编号 | 错误 | 后果 | 改正 |
| --- | --- | --- | --- |
| E1 | 变量未定义就使用 | 编译错误 was not declared | 先 `int a;` 再用 |
| E2 | 变量未赋值就读取 | 输出垃圾值（随机数） | 定义即初始化 |
| E3 | 变量名数字开头 | 编译错误 | 改成字母/下划线开头 |
| E4 | 变量名用关键字 | 编译错误 | 换个名字 |
| E5 | 同名变量重复定义 | 编译错误 redefinition | 一个名字只定义一次 |
| E6 | char 用双引号 `"A"` | 类型不匹配（变成字符串） | 字符用单引号 `'A'` |
| E7 | int 用单引号 `'10'` | 类型错误 | 数字不加引号 |
| E8 | 整数除法丢小数 | `7/2` 得 3 而非 3.5 | 改用 `(double)a/b` 或 `1.0*a/b` |
| E9 | double 用 `%` | 编译错误 | 求余只用整数 |
| E10 | cin 用 `<<` / cout 用 `>>` | 方向反，编译错误 | cin 用 `>>`，cout 用 `<<` |
| E11 | 大小写写错（`Int`） | 编译错误 | 关键字全小写 `int` |
| E12 | `int a = 3.99` 以为得 4 | 实际得 3（截断非四舍五入） | 要四舍五入用 `(int)(x+0.5)` |
| E13 | `(double)(a/b)` 写成 `(double)a/b` | 先除再转，已丢精度 | 先转再除：`(double)a / b` |
| E14 | 强制转换忘加括号 | `(int)a / b` 可能歧义 | 明确加括号：`((int)a) / b` 或 `(int)(a/b)` |
| E15 | 把 `sizeof` 返回值当位数 | `sizeof(int)=4` 误以为 32 位 | `sizeof` 返回**字节数**，1 字节 = 8 位，4 字节 = 32 位 |

-   `=` 是赋值，`==` 才是"判断相等"（后续课程会学，先记住别混）。

## 十四、方法、套路与策略小结

### 1\. 顺序结构三步套路

信奥里最基础的题目都是"读入→计算→输出"三步：

-   **第1步 读入：** 先按数据类型定义变量，再用 `cin >>` 把键盘数据读进变量。
-   **第2步 计算：** 用算术运算把读入的数据算出结果（可存入新变量，也可直接输出）。
-   **第3步 输出：** 用 `cout <<` 把结果输出。

### 2\. 类型选择决策

-   题目说"整数"→ `int`；数据或结果可能超过 21 亿 → `long long`
-   题目说"小数/浮点/保留几位"→ `double`
-   题目说"一个字符/字母"→ `char`
-   题目说"是否/判断"→ `bool`

### 3\. 整数除法防坑三问

写除法前先问自己：

1.  两个操作数都是整数吗？
2.  题目要整数结果还是小数结果？
3.  要小数就加 `.0` 或用 double 变量。

### 4\. 类型转换决策表

| 需求 | 写法 | 示例 |
| --- | --- | --- |
| 整数除法要小数结果 | `(double)a / b` 或 `1.0 * a / b` | `7/2` → 3；`(double)7/2` → 3.5 |
| double 截断取整 | `(int)x` 或 `int(x)` | `(int)3.99` → 3 |
| 正数四舍五入 | `(int)(x + 0.5)` | `(int)(3.6+0.5)` → 4 |
| 查看字符 ASCII 码 | `(int)ch` | `(int)'A'` → 65 |
| 整数转字符 | `(char)n` 或 `char(n)` | `(char)65` → 'A' |

### 5\. 信奥策略意识

-   **定义即初始化**：避免垃圾值，减少调试时间。
-   **变量名见名知意**：长题目里 `sum`、`cnt`、`ans` 比单字母好维护。
-   **拿不准加括号**：优先级记不清就加括号，绝不靠猜。
-   **样例验证**：提交前用样例输入跑一遍，逐字符比对输出。
-   **转换意图要明确**：需要小数结果时主动写 `(double)` 或 `1.0 *`，不依赖隐式转换的"巧合"。
