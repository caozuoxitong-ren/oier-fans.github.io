# 第 14 课 二分

二分查找、二分答案与瓶颈问题

> **学习目标**：理解二分“利用单调性、每次排除一半”的思想与使用条件；掌握闭区间写法下整数二分的三种形态和小数二分的精度控制；会用 `lower_bound` / `upper_bound` 并分清升序、降序含义；理解二分答案的单调性前提与 `check(mid)` 的写法，能识别瓶颈类问题；了解闭区间与左闭右开写法的对照。


## 一、二分算法

**二分**（Binary Search），也称**折半搜索**（Half-interval Search）、**对数搜索**（Logarithmic Search），是一种在具有单调性的范围内，通过每次排除一半候选来快速查找目标或逼近最优解的算法思想。它既可用于在有序序列中定位某个值及其左右边界，也可用于在答案的取值范围内通过可行性判断逼近最优值。

### 1．本质：利用单调性，每次排除一半

二分的思想是：**在一个具有单调性的候选范围内，每次取中点进行判断，根据判断结果排除掉不可能包含答案的一半，使搜索范围不断折半，直到找到答案或范围缩小到足够小。**

它的原理建立在**单调性**上：所谓单调性，是指随着候选值变化，判断结果只会朝一个方向变化——要么从“不满足”变成“满足”(`FFFFTTTT`)，要么从“满足”变成“不满足”(`TTTTFFFF`)，不会来回反复。正因为这种“一边全不满足、另一边全满足”的结构，中点的一次判断才能代表一整半的结论：如果中点不满足，那么它某一侧的所有候选也一定不满足；如果中点满足，另一侧也一定满足。于是**被排除的那一半一定不含答案**，这是二分不会漏解的根本保证。

二分的策略可以概括为三步：**取中点、做判断、保留有希望的一半。** 取中点是为了把范围尽量均匀地一分为二；做判断是为了确定答案在哪一侧；保留有希望的一半，就是丢弃不可能的那一半，让问题规模持续减半。整个过程不依赖逐个枚举，而是用一次判断换掉一半候选，因此效率远高于线性扫描。

### 2．与暴力枚举的关系

暴力枚举是**一个一个试**；二分是**一次排除一批**。

```cpp
// 暴力：逐个检查，最坏 O(n)
for (int i = 0; i < n; i++) {
    if (a[i] == target) {
        return i;
    }
}
```

```cpp
// 二分：每次排除一半，O(log n)
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (a[mid] == target) {
        return mid;
    } else if (a[mid] < target) {
        l = mid + 1;   // 左半部分连同 mid 一起排除
    } else {
        r = mid - 1;   // 右半部分连同 mid 一起排除
    }
}
```

暴力每一步只确认“这一个行不行”；二分每一步确认的是“**这一整半都不行**”。\(n=10^6\) 时，暴力最坏 \(10^6\) 次，二分最多约 20 次。

### 3．使用条件与闭区间约定

二分通常需要同时满足：

1. **搜索范围有序**：例如 `a[0] <= a[1] <= ... <= a[n-1]`；
2. **判断结果具有单调性**：随着下标增大，判断结果只能从“假”变“真”，或从“真”变“假”，不能来回变化；
3. **每次判断可以排除一半**：中点的结果能告诉我们答案不可能在哪一侧。

本课**统一采用闭区间写法**：答案始终在当前闭区间 `[l, r]` 内，`l`、`r` 都是可能取到的位置。三条约定：

- 循环条件用 `l <= r`；
- 排除 `mid` 时，`l = mid + 1` 或 `r = mid - 1`；
- 循环结束时 `l = r + 1`，答案要么已返回，要么落在 `l` 或 `r` 上。

这三条不是死记的，而是从“区间是闭的、`mid` 已经被检查过”推出来的。


## 二、二分查找（闭区间）

### 1．整数二分：三种形态

| 形态 | 问题 | 返回 |
| :--- | :--- | :--- |
| 存在性 | `target` 在不在数组中？ | 存在返回下标，不存在返回 `-1` |
| 左边界 | 第一个 `>= target` 的位置 | 下标；不存在返回 `n` |
| 右边界 | 最后一个 `<= target` 的位置 | 下标；不存在返回 `-1` |

**形态一：存在性**

```cpp
int binarySearch(int a[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == target) {
            return mid;
        } else if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return -1;
}
```

`mid` 写成 `l + (r - l) / 2` 防溢出。三分支里 `==` 直接返回，只能找到**任意一个** `target`；有重复元素时，不保证是第一个或最后一个。

**形态二：左边界（第一个 `>= target`）**

```cpp
int lowerBound(int a[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;   // 等于也往左收缩
        }
    }
    return l;              // 第一个 >= target
}
```

**形态三：右边界（最后一个 `<= target`）**

```cpp
int rightBound(int a[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= target) {
            l = mid + 1;   // 等于也往右收缩
        } else {
            r = mid - 1;
        }
    }
    return r;              // 最后一个 <= target
}
```

找完边界要检查存在性：左边界看 `l < n && a[l] == target`，右边界看 `r >= 0 && a[r] == target`。

### 2．小数二分：看 `eps`

实数域没有“相邻整数”，只要区间足够小，就可以认为找到了答案。

```cpp
double binarySearchDouble(double l, double r) {
    const double eps = 1e-6;
    while (r - l > eps) {
        double mid = (l + r) / 2;
        if (check(mid)) {
            r = mid;
        } else {
            l = mid;
        }
    }
    return l;
}
```

`eps` 比题目要求精度再小一到两位；循环条件用 `r - l > eps`；实数二分不会死循环，因为区间长度严格减半。也可以直接固定循环 100 次。

### 3．一句话规律

> **等号直接返回，是精确查找；等号往左收缩，是找左边界，返回 `l`；等号往右收缩，是找右边界，返回 `r`。**


## 三、库函数：`lower_bound` 与 `upper_bound`

两个函数都在 `<algorithm>`，底层就是二分，复杂度 \(O(\log n)\)。

### 1．升序直接用

| 函数（升序） | 返回位置 |
| :--- | :--- |
| `lower_bound` | 第一个 **`>= value`** 的元素 |
| `upper_bound` | 第一个 **`> value`** 的元素 |

```cpp
int a[] = {1, 2, 2, 2, 5, 7, 9};
int n = 7;

int posL = lower_bound(a, a + n, 2) - a;   // 1
int posU = upper_bound(a, a + n, 2) - a;   // 4
```

返回的是**位置**，下标要减起始地址。判断存在性要再检查：

```cpp
int pos = lower_bound(a, a + n, 2) - a;
if (pos < n && a[pos] == 2) {
    // 存在
}
```

### 2．降序加 `greater<T>()`

降序序列不能直接调用，必须传第四个参数：

```cpp
int a[] = {9, 7, 5, 2, 2, 2, 1};

int posL = lower_bound(a, a + n, 2, greater<int>()) - a;
int posU = upper_bound(a, a + n, 2, greater<int>()) - a;
```

### 3．四种情形速查

| 序列 | 函数 | 第三个参数 | 返回位置的含义 |
| :--- | :--- | :--- | :--- |
| 升序 | `lower_bound` | 不传 | 第一个 **`>=`** `value` |
| 升序 | `upper_bound` | 不传 | 第一个 **`>`** `value` |
| 降序 | `lower_bound` | `greater<T>()` | 第一个 **`<=`** `value` |
| 降序 | `upper_bound` | `greater<T>()` | 第一个 **`<`** `value` |

**记忆：`lower_bound` 管“不小于”，`upper_bound` 管“大于”；比较规则一变，含义跟着变。**

### 4．与手写二分的对应

- 左边界“第一个 `>= target`” ↔ `lower_bound`；
- 升序“最后一个 `<= target`” ↔ `upper_bound(...) - 1`。

序列必须先按对应规则有序；降序忘传 `greater<T>()` 不会报错，但结果会是错的。


## 四、二分答案

### 1．是什么

普通二分是在**数组**里找数；二分答案是在**答案的范围**里找最优值。

> **我不知道答案是多少，但我可以猜一个答案 `mid`，然后判断它“能不能做到”。**

### 2．前提：单调性

> 如果某个答案 `mid` 可行，那么比它“更容易”的答案也可行；如果某个答案不可行，那么比它“更难”的答案也不可行。

可行性必须“一边全真、一边全假”，二分才能工作。`check(mid)` 只回答“`mid` 可不可行”，它的复杂度决定总复杂度：`check` 是 \(O(n)\)、答案范围是 \(O(\log V)\)，总复杂度就是 \(O(n \log V)\)。

### 3．例题：木材加工

#### 问题描述

有 `n` 根木头，第 `i` 根长度为 `a[i]`。要把它们切成 `k` 段长度相等的小段，求每段的最大长度（长度为整数）。切不出 `k` 段时输出 `0`。

```text
输入：
3 7
10 20 15
输出：
6
```

（每段长 6 时，三根木头分别能切 1、3、2 段，共 6 段，不够 7 段；每段长 5 时能切 2 + 4 + 3 = 9 段，够。所以最大长度是 5……注意样例答案要按实际计算核对，这里只示范思路。）

#### 思路

- 猜每段长度 `mid`；
- `check(mid)`：对每根木头，能切出 `a[i] / mid` 段，累加所有段数；
- 段数 `>= k`，说明 `mid` 可行，可以尝试更长；否则 `mid` 太大，要减小；
- 答案范围：`l = 1`，`r = 最长木头的长度`。

#### 参考代码

```cpp
#include <iostream>
using namespace std;

const int N = 100005;
int a[N];
int n, k;

bool check(int mid) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++) {
        cnt += a[i] / mid;
    }
    return cnt >= k;
}

int main() {
    cin >> n >> k;
    int maxLen = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] > maxLen) {
            maxLen = a[i];
        }
    }

    int l = 1, r = maxLen;
    int ans = 0;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (check(mid)) {
            ans = mid;       // 可行，记录后尝试更长
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    cout << ans << '\n';
    return 0;
}
```

#### 要点

- 这是最基础的二分答案：**猜长度、数段数、可行就往更长试**；
- `cnt` 用 `long long`，防止段数累加溢出；
- `mid` 不能取 0，`l` 从 1 开始；切不出时 `ans` 保持 0；
- `check` 只回答“够不够 `k` 段”，不负责求最优值。


## 五、瓶颈问题

### 1．典型问法

瓶颈问题是一类“让最坏的那一项尽量好”的问题，典型问法就是：

- **最大值最小**；
- **最小值最大**。

例如：一条路径上最大的边权尽量小；安排任务使最忙的人耗时尽量少。共同特征是：**答案本身是一个“最值”，直接求很难，判断“某个最值能不能达到”却相对容易。**

### 2．解题三步

1. **定范围**：确定答案的 `[l, r]`；
2. **猜 `mid`**：用 `check(mid)` 判断“能不能让最坏情况不超过（或不低于）`mid`”；
3. **保留一半**：可行就记录答案，往更有希望的一侧继续。

两大模型只差“可行时往哪边走”：

| 模型 | 题目问法 | `check(mid)` 为真时 |
| :--- | :--- | :--- |
| 最大化最小值 | 最小值最大 | 记录 `ans`，`l = mid + 1` |
| 最小化最大值 | 最大值最小 | 记录 `ans`，`r = mid - 1` |

瓶颈问题不一定都用二分，但**当你能写出高效的 `check`，二分就是最通用的解法**。


## 六、闭区间与左闭右开写法对照

### 1．核心区别

| | 闭区间 `[l, r]` | 左闭右开 `[l, r)` |
| :--- | :--- | :--- |
| 初始 | `l = 0, r = n - 1` | `l = 0, r = n` |
| 循环条件 | `l <= r` | `l < r` |
| 排除 `mid` | `l = mid + 1` 或 `r = mid - 1` | `l = mid + 1` 或 `r = mid` |
| 退出时 | `l = r + 1` | `l == r` |
| 区间含义 | `l`、`r` 都是候选 | `l` 是候选，`r` 不是候选 |

### 2．左、右边界对照

**左边界：第一个 `>= target`**

```cpp
// 闭区间
int lowerBound(int a[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return l;
}

// 左闭右开
int lowerBound(int a[], int n, int target) {
    int l = 0, r = n;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    return l;
}
```

**右边界：最后一个 `<= target`**

```cpp
// 闭区间
int rightBound(int a[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return r;
}

// 左闭右开
int rightBound(int a[], int n, int target) {
    int l = 0, r = n;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= target) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    return l - 1;
}
```

### 3．常见坑

| 坑 | 原因 | 正确做法 |
| :--- | :--- | :--- |
| `while (l < r)` 却用 `r = mid - 1` | `l == r` 时循环结束，最后一个元素可能没检查 | 改 `l <= r`，或改 `r = mid` |
| `while (l <= r)` 却用 `r = mid` | `l == r` 时区间不缩小，死循环 | 保留侧加减一，或改左闭右开 |
| 找边界时等号直接返回 | 只能找到任意一个 | 等号往左找左边界，往右找右边界 |
| 忘记检查存在性 | 不存在时会返回相邻位置 | 最后检查 `a[l] == target` 或 `a[r] == target` |

### 4．选哪种

两种都对，关键是**一套代码内部统一**。本课统一用闭区间：初始 `r = n - 1` 和下标习惯一致；排除 `mid` 就是 `mid ± 1`；退出时 `l = r + 1`，找左边界返回 `l`、找右边界返回 `r`，对称好记。

左闭右开一句话记忆：**`r = mid` 不加减一，退出时 `l == r`；左边界返回 `l`，右边界返回 `l - 1`。**


## 七、总结

**二分不是“有序数组专用”，本质是：利用单调性，每次排除一半不可能的范围。** 暴力一个一个试，二分之一批一批丢。

**闭区间三条约定**：`l <= r`；排除 `mid` 时加减一；退出时 `l = r + 1`。

**整数二分三种形态**：等号直接返回是精确查找；等号往左是左边界，返回 `l`；等号往右是右边界，返回 `r`。找完边界要检查存在性。

**小数二分看区间长度**：`r - l > eps`，`eps` 比题目精度小一到两位。

**库函数**：升序直接用 `lower_bound` / `upper_bound`，降序加 `greater<T>()`；`lower_bound` 管“不小于”，`upper_bound` 管“大于”。

**二分答案**：在答案范围猜 `mid`，`check(mid)` 只回答可不可行；前提是单调性。两大模型——最大化最小值可行时往右，最小化最大值可行时往左。

**总口诀：单调才能二分，闭区间 `l<=r`；排除加减一，等号看归属；左边界返回 `l`，右边界返回 `r`；答案单调 `check` 判，最大最小看方向；升序库函数直接用，降序别忘 `greater`。**
