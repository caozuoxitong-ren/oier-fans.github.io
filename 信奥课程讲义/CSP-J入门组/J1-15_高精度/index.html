    第 15 课 高精度

    大整数存储、高精度四则运算、结构体封装与浮点高精度

    学习目标：理解高精度“字符串读入、倒序存数组、低位对齐”的核心思想；掌握高精度加、减、乘、除以低精度的竖式规则；能估算结果位数，并写出程序；能封装结构体、重载运算符，像用 int 一样用大整数；理解浮点高精度的定点化思路。

    一、为什么需要高精度

    C++ 的 long long 最多存到约 \(9 \times 10^{18}\)，也就是 19 位十进制数。题目一旦要求计算几十位、几百位甚至上万位的整数，内置类型就装不下了，这时需要自己用数组逐位存储和计算，这就是高精度。

    高精度的核心思想是竖式模拟：把大整数按位拆开，低位在前、高位在后，像小学列竖式一样逐位相加、相减、相乘、相除，把进位、借位、余数处理好。

    二、高精度的输入与存储

    1．为什么必须用字符串输入

    高精度数的位数远超 long long 的范围，cin >> int、cin >> long long 都装不下，会读入失败或溢出。所以高精度数的输入必须先用字符串接收：

    string ca, cb;
cin >> ca >> cb;      // 把大整数当成一串字符读进来

    字符串的每一位就是一个数字字符，'0'～'9'。读进来之后，再把字符逐位转成整数，存进数组。

    这一步不能省：如果题目输入的是 100 位整数，用 int 或 long long 读，从第一位开始就已经错了。

    2．倒序存储：低位在前，高位在后

    存进数组时，小下标对应低位，大下标对应高位。本文档统一约定：数组下标从 1 开始，a[1] 存个位，a[2] 存十位，依此类推，a[len] 存最高位。

    以数字 12345 为例：

    原数字：    1    2    3    4   5
数位：     万位 千位 百位 十位 个位

数组下标：  1    2     3    4    5
数组元素： a[1] a[2] a[3] a[4] a[5]
存储的值：  5    4     3    2    1

    也就是说：

    a[1] = 5   （个位）
a[2] = 4   （十位）
a[3] = 3   （百位）
a[4] = 2   （千位）
a[5] = 1   （万位）
len = 5

    和字符串的下标正好相反：字符串 "12345" 中 s[0]='1' 是最高位，而数组 a[1]=5 是个位。转换时按下面的对应关系来：

    s[0]  s[1]  s[2]  s[3]  s[4]
 '1'   '2'   '3'   '4'   '5'
  ↓     ↓     ↓     ↓     ↓
a[5]  a[4]  a[3]  a[2]  a[1]

    3．为什么要倒序存储

    如果正序存储，a[0] 是最高位，a[len-1] 是个位。竖式计算从个位开始，进位要往高位传，就变成“下标减小”的方向；一旦最高位还要进位，就得把整个数组往后挪一位，非常麻烦。

    倒序存储后，个位在 a[1]，进位方向是“下标增大”，天然和数组增长方向一致，不需要挪动任何已有元素。

    以 123 + 98 为例：

      1 2 3
+   9 8
-------
  2 2 1

    倒序存进数组后：

    a[1]=3  a[2]=2  a[3]=1       (123)
b[1]=8  b[2]=9  b[3]=0       (98，高位补 0)

    逐位相加：

    i=1：3 + 8 = 11        c[1]=1，进位 1
i=2：2 + 9 + 1 = 12    c[2]=2，进位 1
i=3：1 + 0 + 1 = 2     c[3]=2，进位 0

    结果 c[3]c[2]c[1] = 2 2 1，倒着输出就是 221。

    倒序存储的三大好处：

    1. 进位方向自然：进位从 a[i] 传到 a[i+1]，下标增大，不需要移动元素；
    2. 个位天然对齐：两个数的个位都在下标 1，十位都在下标 2，直接 a[i] + b[i] 就对齐了，不用管两个数长度是否相同；
    3. 长度不足自动补 0：数组开得足够大时，超出原长度的位置默认是 0，短数的高位天然就是 0，不需要特殊处理。

    4．读入与倒序存储的代码

    const int N = 1005;
int a[N], len;

void read(int a[], int &len) {
    string s;
    cin >> s;                      // 用字符串接收大整数
    len = s.size();                // 位数
    for (int i = 0; i < len; i++) {
        // s[0] 是最高位，存到 a[len]；s[len-1] 是个位，存到 a[1]
        a[len - i] = s[i] - '0';
    }
}

    以 s = "12345" 为例，循环过程：

    i=0：a[5] = s[0]-'0' = 1
i=1：a[4] = s[1]-'0' = 2
i=2：a[3] = s[2]-'0' = 3
i=3：a[2] = s[3]-'0' = 4
i=4：a[1] = s[4]-'0' = 5

    最终 a[1..5] = 5 4 3 2 1，len = 5，a[1] 是个位。

    5．去掉前导零

    减法、除法可能产生前导零，比如 1000 - 999 = 0001，要删掉高位的 0：

    while (len > 1 && a[len] == 0) {
    len--;
}

    至少保留一位，因为 0 本身也是合法结果，不能把长度删成 0。

    6．数组开多大：按“结果最多几位”来估

    高精度的数组大小，由输入最大位数和运算后结果的最大位数共同决定。设两个输入最多各有 \(n\) 位，常见估算如下：

    运算 结果最多几位 数组至少开多大
    加法 \(n + 1\) 比输入最大位数多 1
    减法 \(n\) 和输入最大位数一样
    乘法 \(2n\) 输入最大位数的两倍
    除以低精度 \(n\) 和被除数最大位数一样

    再加一点余量，避免边界写错时越界。例如题目说输入不超过 100 位，可以统一开 N = 105；如果要做乘法，结果可能到 200 位，就开到 N = 205 左右。下面的代码按题目数据范围分别开数组，并注明理由。

    一句话：高精度数必须用字符串读入，再倒序存进数组，a[1] 是个位、a[len] 是最高位；倒序存储让进位方向自然、个位天然对齐、短数高位自动补 0。数组大小按“结果最多几位”来估，再加一点余量。

    三、高精度加法

    1．竖式规则

    从个位开始逐位相加，当前位结果 = a[i] + b[i] + 进位，本位取 % 10，进位取 / 10。

      1 2 3
+   9 8
-------
  2 2 1

    2．位数估计与数组大小

    两个数最多各有 lena、lenb 位，和最多 max(lena, lenb) + 1 位——因为最高位可能再进 1。

    • 例如输入不超过 100 位，和最多 101 位；
    • a、b 各开 N = 105 够用；
    • 结果 c 要多留一位给进位，开 N + 1 = 106。

    3．例题：P1735 高精度整数加法模板题目

    输入两个整数 \(a,b\)，用空格隔开，输出 \(a+b\)。数据范围 \(1 \le a,b \le 10^{100}\)，即最多 101 位。

    输入：
1 100
输出：
101

    4．写法一：用进位变量单独维护进位

    #include<bits/stdc++.h>
using namespace std;

const int N=105;                  // 输入最多 100 多位，N=105 够用
int a[N],b[N],c[N+1];             // c 多开一位，存放最高位可能的进位

int main(){
    // 输入：用字符串接收大整数
    string ca,cb;
    cin>>ca>>cb;

    // 倒序存储，低位对齐，下标从1开始
    // 例如 "100" 存成 a[1]=0, a[2]=0, a[3]=1
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟加法竖式计算
    int jin=0;                          // 进位，初始为0
    int lenc=max(lena,lenb);            // 结果至少和较长的数一样长
    for(int i=1;i<=lenc;i++){
        int t=a[i]+b[i]+jin;            // 当前位相加，加上低位来的进位
        c[i]=t%10;                      // 本位保留个位
        jin=t/10;                       // 进位
    }
    if(jin>0) c[++lenc]=jin;            // 最高位还有进位，结果长度加1

    // 输出：从最高位倒着输出到个位
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    特点：进位变量单独维护，逻辑最直观，适合初学。

    5．写法二：边加边进位，把进位直接写进 c[i+1]

    #include<bits/stdc++.h>
using namespace std;

const int N=105;
int a[N],b[N],c[N+1];             // c 多开一位，防止最高位进位越界

int main(){
    // 输入：用字符串接收
    string ca,cb;
    cin>>ca>>cb;

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟加法竖式计算
    int lenc=max(lena,lenb);
    for(int i=1;i<=lenc;i++){
        c[i]+=a[i]+b[i];                // 本位加上两个数对应位
        c[i+1]+=c[i]/10;                // 进位直接加到下一位
        c[i]%=10;                       // 本位只保留个位
    }
    if(c[lenc+1]>0) lenc++;             // 最高位有进位则长度加1

    // 输出
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    特点：不需要 jin 变量，进位直接累加到下一位，代码更短。

    6．写法三：先全部对应位相加，再统一处理进位

    #include<bits/stdc++.h>
using namespace std;

const int N=105;
int a[N],b[N],c[N+1];             // c 多开一位，给最高位进位留位置

int main(){
    // 输入：用字符串接收
    string ca,cb;
    cin>>ca>>cb;

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟加法竖式计算
    int lenc=max(lena,lenb);
    for(int i=1;i<=lenc;i++) c[i]=a[i]+b[i];            // 第一步：对应位相加
    for(int i=1;i<=lenc;i++) c[i+1]+=c[i]/10,c[i]%=10;  // 第二步：统一从低到高处理进位
    if(c[lenc+1]>0) lenc++;                             // 最高位还有进位则长度加1

    // 输出
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    特点：先累加、后统一进位，和乘法处理进位的思路一致，适合作为通用模板。

    7．要点

    • 结果最多 max(lena, lenb) + 1 位，c 要比输入数组多开一位；
    • 循环长度取两个数长度的较大值，短数的高位数组默认为 0，自动补 0；
    • 循环结束后进位可能还有 1，要单独补到最高位；
    • 三种写法结果相同，初学建议先掌握写法一，再理解写法二、三。

    四、高精度减法

    1．竖式规则

    从个位开始逐位相减，当前位不够减就向高位借 1：

      1 2 3
-   9 8
-------
    2 5

    高精度减法通常要求被减数 ≥ 减数，结果非负。如果题目可能出负数，先比较大小，必要时交换并输出负号。

    2．位数估计与数组大小

    减法的结果位数不会超过被减数的位数。两个数最多各有 \(n\) 位，结果最多 \(n\) 位。

    • a、b、c 开同样大小即可，比如输入不超过 100 位，统一开 N = 105；
    • 不需要为结果多开位置，因为减法不会让位数变多；
    • 但必须去前导零，否则会多出无效的高位 0。

    3．例题：P1736 高精度整数减法模板题目

    输入两个整数 \(a,b\)，用空格隔开，输出 \(a-b\)。数据范围 \(1 \le a,b \le 10^{100}\)。

    输入：
100 100
输出：
0

    4．写法一：用 jie 变量单独维护借位

    #include<bits/stdc++.h>
using namespace std;

const int N=105;                  // 输入最多 100 多位，N=105 够用
int a[N],b[N],c[N];               // 减法结果不会超过被减数位数，c 和 a 一样大即可

int main(){
    // 输入：用字符串存储
    string ca,cb;
    cin>>ca>>cb;

    // 比较两个数的大小：如果 a < b，交换并输出负号
    // 长度不同时，长的更大；长度相同时，按字符串字典序比较
    if(ca.size()<cb.size() || (ca.size()==cb.size()&&ca<cb)){
        cout<<"-";
        swap(ca,cb);
    }

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟竖式减法
    int jie=0;                          // 借位，初始为0
    int lenc=max(lena,lenb);
    for(int i=1;i<=lenc;i++){
        if(a[i]-b[i]-jie>=0){           // 够减
            c[i]=a[i]-b[i]-jie;
            jie=0;
        }else{                          // 不够减，向高位借1
            c[i]=a[i]-b[i]-jie+10;
            jie=1;
        }
    }

    // 去除前导零，至少保留一位
    while(lenc>1 && c[lenc]==0) lenc--;

    // 输出
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    特点：借位逻辑直观，适合初学。

    5．写法二：先统一按“借位后加 10”累加，再统一处理借位

    #include<bits/stdc++.h>
using namespace std;

const int N=105;
int a[N],b[N],c[N];               // 结果位数不超过被减数，c 和 a 一样大即可

int main(){
    // 输入：用字符串存储
    string ca,cb;
    cin>>ca>>cb;

    // 比较大小，保证 ca >= cb
    if(ca.size()<cb.size() || (ca.size()==cb.size()&&ca<cb)){
        cout<<"-";
        swap(ca,cb);
    }

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟竖式减法
    int lenc=max(lena,lenb);
    // 第一步：每一位先按“借位后加10”计算，并向下一位借1
    for(int i=1;i<=lenc;i++) c[i]+=a[i]-b[i]+10, c[i+1]--;
    // 第二步：统一处理进位（把多借的10还回去）
    for(int i=1;i<=lenc;i++) c[i+1]+=c[i]/10, c[i]%=10;

    // 去除前导零
    while(lenc>1 && c[lenc]==0) lenc--;

    // 输出
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    特点：先统一“加 10、下一位减 1”，再用进位统一修正，和加法的统一进位写法对称。

    6．要点

    • 结果最多和被减数一样长，c 不需要额外多开；
    • 借位用 jie 或“先加 10 再修正”都可以；
    • 循环结束后必须去掉前导零，判断条件写 c[lenc] == 0；
    • 如果 a < b，先交换两个数，记录负号，最后输出时加 -；
    • 结果为 0 时保留一位 0，不能把长度删成 0；
    • 比较大小：长度不同比长度，长度相同按字符串字典序比较。

    五、高精度乘法

    1．竖式规则

    高精度乘高精度，结果第 i + j - 1 位由 a[i] * b[j] 贡献。因为下标从 1 开始，a[1] 和 b[1] 都是个位，乘积贡献到结果第 1 位，正好是个位。

      1 2
×   3 4
-------
  4 0 8

    2．位数估计与数组大小

    乘法是四则运算里结果最长的。两个数最多各有 n 位，积最多 2n 位。

    • 输入不超过 100 位，积最多 200 位；
    • a、b 各开 N = 105；
    • 结果 c 要开 N + N = 210，给乘积留足空间。

    如果数据范围是 \(10^{100}\)，即最多 101 位，积最多 202 位，开 N = 105、c[210] 也够。乘法一定不要沿用加法、减法的 c[N]，否则高位会越界。

    3．例题：P1737 高精度整数乘法模板题

    输入两个整数 \(a,b\)，用空格隔开，输出 \(a \times b\)。数据范围 \(1 \le a,b \le 10^{100}\)。

    输入：
100 5
输出：
500

    4．参考代码

    #include<bits/stdc++.h>
using namespace std;

const int N=105;
int a[N],b[N],c[N+N];                  // 积最多 2n 位，c 要开两倍大小

int main(){
    // 输入：用字符串接收
    string ca,cb;
    cin>>ca>>cb;

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size(),lenb=cb.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';
    for(int i=0;i<lenb;i++) b[lenb-i]=cb[i]-'0';

    // 模拟竖式乘法：a 的第 i 位 × b 的第 j 位，贡献到结果的第 i+j-1 位
    for(int i=1;i<=lena;i++){
        for(int j=1;j<=lenb;j++){
            c[i+j-1]+=a[i]*b[j];        // 累加对应位的乘积
        }
    }

    // 统一处理进位：从低位到高位
    int lenc=lena+lenb;
    for(int i=1;i<=lenc;i++) c[i+1]+=c[i]/10,c[i]%=10;

    // 处理前导零，至少保留一位
    while(lenc>1 && c[lenc]==0) lenc--;

    // 输出
    for(int i=lenc;i>=1;i--) cout<<c[i];
    return 0;
}

    5．要点

    • 结果长度最多是 lena + lenb，c 要开两倍大小；
    • 贡献位置是 i + j - 1，不要写成 i + j；
    • 先全部累加，再统一从低到高处理进位；
    • 最后去前导零，0 × 任何数 = 0 要保留一位。

    六、高精度除以低精度

    1．竖式规则

    高精度除以低精度（除数能用 int 存），从高位到低位逐位试商：

      1 2 3 ÷ 2 = 6 1 …… 1

    每一步用“当前余数 × 10 + 当前位”去除以除数，商写在这一位，余数留给下一位。

    2．位数估计与数组大小

    除法是四则运算里结果最短的。商最多和被除数一样长，余数一定小于除数。

    • 被除数不超过 n 位，商最多 n 位；
    • a、c 开同样大小即可，比如被除数不超过 500 位，开 N = 505；
    • 余数用 long long 存，不需要单独开数组。

    3．例题：lv11703 高精度除以低精度

    输入一个高精度正整数 \(n\)（长度不超过 500 位）和一个低精度正整数 \(p\)（不超过 int 范围），输出整除商和余数。

    输入：
8474747663733
8777
输出：
965563138
1507

    4．参考代码

    #include<bits/stdc++.h>
using namespace std;

const int N=505;                  // 被除数不超过 500 位，N=505 够用
int a[N],c[N];                    // 商不超过被除数位数，c 和 a 一样大即可

int main(){
    // 输入：被除数用字符串接收，除数用低精度整数
    string ca;
    long long b;
    cin>>ca>>b;

    // 倒序存储，低位对齐，下标从1开始
    int lena=ca.size();
    for(int i=0;i<lena;i++) a[lena-i]=ca[i]-'0';

    // 模拟竖式除法：从高位到低位逐位试商
    int lenc=lena;                      // 商的位数不超过被除数
    long long r=0;                      // 余数，用 long long 防止 r*10 溢出
    for(int i=lena;i>=1;i--){           // 从最高位往个位走
        r=r*10+a[i];                    // 当前余数 × 10 + 当前位
        c[i]=r/b;                       // 这一位的商
        r-=c[i]*b;                      // 更新余数
    }

    // 处理前导零，至少保留一位
    while(lenc>1 && c[lenc]==0) lenc--;

    // 输出商
    for(int i=lenc;i>=1;i--) cout<<c[i];
    cout<<endl<<r;                      // 输出余数
    return 0;
}

    5．要点

    • 商最多和被除数一样长，c 不需要额外多开；
    • 从高位往低位做，和加、减、乘的方向相反；
    • 余数用 long long，因为 r * 10 + a[i] 可能超过 int；
    • 商也要去前导零；
    • 除数为 0 要特判，题目一般保证除数不为 0。

    七、结构体封装：像用 int 一样用大整数

    把高精度封装成结构体，重载 + - * / <，就能像用 int 一样用大整数。结构体内部仍然下标从 1 开始，data[1] 是个位，data[len] 是最高位。

    1．完整封装模板

    #include<bits/stdc++.h>
using namespace std;

const int N = 100005;   // 按题目数据范围调整

struct Number {
    int data[N];
    int len;
};

// 加法：先对应位相加，再统一进位
Number operator+(Number x, Number y) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = max(x.len, y.len);
    for (int i = 1; i <= res.len; i++) res.data[i] = x.data[i] + y.data[i];
    for (int i = 1; i <= res.len; i++) {
        res.data[i + 1] += res.data[i] / 10;
        res.data[i] %= 10;
    }
    if (res.data[res.len + 1] > 0) res.len++;
    return res;
}

// 减法：要求 x >= y，先对应位相减，再统一借位，最后去前导零
Number operator-(Number x, Number y) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = max(x.len, y.len);
    for (int i = 1; i <= res.len; i++) {
        res.data[i] += x.data[i] - y.data[i] + 10;
        res.data[i + 1]--;
    }
    for (int i = 1; i <= res.len; i++) {
        res.data[i + 1] += res.data[i] / 10;
        res.data[i] %= 10;
    }
    while (res.len > 1 && res.data[res.len] == 0) res.len--;
    return res;
}

// 乘法：先累加对应位乘积，再统一进位，最后去前导零
Number operator*(Number x, Number y) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = x.len + y.len;
    for (int i = 1; i <= x.len; i++)
        for (int j = 1; j <= y.len; j++)
            res.data[i + j - 1] += x.data[i] * y.data[j];
    for (int i = 1; i <= res.len; i++) {
        res.data[i + 1] += res.data[i] / 10;
        res.data[i] %= 10;
    }
    while (res.len > 1 && res.data[res.len] == 0) res.len--;
    return res;
}

// 除以低精度：从高位到低位试商，余数用 long long
Number operator/(Number x, long long y) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = x.len;
    long long r = 0;
    for (int i = res.len; i >= 1; i--) {
        r = r * 10 + x.data[i];
        res.data[i] = r / y;
        r %= y;
    }
    while (res.len > 1 && res.data[res.len] == 0) res.len--;
    return res;
}

// 比较：先比长度，再从最高位往低位比
bool operator<(Number x, Number y) {
    if (x.len != y.len) return x.len < y.len;
    for (int i = x.len; i >= 1; i--)
        if (x.data[i] != y.data[i]) return x.data[i] < y.data[i];
    return false;
}

// 低精度转高精度
Number trans(long long x) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = 0;
    if (x == 0) { 
        res.len = 1; 
    }else{
        while (x) {
            res.data[++res.len] = x % 10;
            x /= 10;
        }
    }
    return res;
}

// 输出：从最高位倒着输出到个位
void pt(Number x) {
    for (int i = x.len; i >= 1; i--) cout << x.data[i];
}

    2．模板要点

    • 加法、减法、乘法都是先对应位运算，再统一处理进位/借位，和前面四道题的写法一致；
    • 减法用 +10、res.data[i+1]-- 统一借位，再统一进位修正；
    • 除法从高位到低位试商，余数用 long long；
    • 比较运算符从最高位往低位比；
    • trans 负责低精度转高精度，pt 负责倒序输出；
    • 数组大小 N 按题目数据范围调整，乘法结果最长时 N 要能容纳两倍位数。

    3．例题：P1413 数楼梯2

    楼梯有 \(N\) 阶，一次可以上一阶或两阶，求走法总数。\(N \le 5000\)，答案会超过 long long，需要高精度。

    递推式：

    f(1)=1
f(2)=2
f(i)=f(i-1)+f(i-2)

    位数估计：斐波那契第 5000 项约 1045 位，data[N] 开 N = 2000 有余量。

    #include<bits/stdc++.h>
using namespace std;

const int N = 2000;     // 第 5000 项约 1000 多位，N = 2000 有余量

struct Number {
    int data[N];
    int len;
};

// 本题只用加法，所以只写 operator+
Number operator+(Number x, Number y) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = max(x.len, y.len);
    for (int i = 1; i <= res.len; i++) res.data[i] = x.data[i] + y.data[i];
    for (int i = 1; i <= res.len; i++) {
        res.data[i + 1] += res.data[i] / 10;
        res.data[i] %= 10;
    }
    if (res.data[res.len + 1] > 0) res.len++;
    return res;
}

Number trans(long long x) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = 0;
    if (x == 0) { res.len = 1; return res; }
    while (x) {
        res.data[++res.len] = x % 10;
        x /= 10;
    }
    return res;
}

void pt(Number x) {
    for (int i = x.len; i >= 1; i--) cout << x.data[i];
}

Number f1, f2, f3;

int main() {
    int n;
    cin >> n;
    if (n == 1) cout << 1;
    else if (n == 2) cout << 2;
    else {
        f1 = trans(1);
        f2 = trans(2);
        for (int i = 3; i <= n; i++) {
            f3 = f1 + f2;
            f1 = f2;
            f2 = f3;
        }
        pt(f3);
    }
    return 0;
}

    要点：

    • 本题只需要加法，所以只写 operator+、trans、pt 就够；
    • f3 = f1 + f2 和普通整数写法一样，这就是封装的意义；
    • n == 1、n == 2 要特判，否则递推会用到未初始化的 f1、f2；
    • 数组大小按“结果最多几位”估，再留余量。

    一句话：结构体把 data[] 和 len 绑在一起，重载 + - * / < 后，大整数就能像 int 一样参与运算；数组大小按结果最大位数估，输出从 len 倒着输出到 1。

    八、浮点数的高精度计算

    1．为什么浮点也要高精度

    double 大约只有 15～16 位有效数字，算到几百位小数就不准了。浮点高精度常用定点数：把小数点去掉，整体当成高精度整数处理，最后再把小数点插回去。

    2．例题：P1116 高精度加法

    给出两个高精度浮点数，求两个数的和。每个浮点数总位数不超过 200 位。

    输入：
1.234
-2.345
输出：
-1.111

    3．核心思路：定点化

    浮点数 = 去掉小数点后的高精度整数 + 小数位数 + 符号。

    以 1.234 和 12.3 为例，两个数小数位数不同：

    1.234   →  小数 3 位  →  去掉小数点得 1234
12.3    →  小数 1 位  →  去掉小数点得 123

    不能直接拿 1234 和 123 相加，因为小数点没有对齐。要先把小数位数补齐到相同长度，都补到 3 位：

    1.234   →  1.234   →  1234
12.3    →  12.300  →  12300

    此时两个数都放大了 \(10^3\) 倍，再按整数相加：

    1234 + 12300 = 13534

    最后把小数点插回去，小数位数 L = 3：

    13534  →  13.534

    关键：小数点去掉后，两个数必须放大相同的倍数，才能直接做整数运算。小数位数不同的两个数，先补齐到 max(L1, L2)，再运算。

    4．位数估计与数组大小

    题目说每个浮点数总位数不超过 200 位。注意，这 200 位可以是整数部分，也可以是小数部分：

    • 可能 200 位全是整数部分，没有小数点，比如一个 200 位的整数；
    • 也可能整数部分只有 1 位、小数部分接近 199 位，比如 0.1234...；
    • 也可能整数部分和小数部分各占一部分，加起来不超过 200 位。

    两个数相加时，要把小数位数对齐到 L = max(L1, L2)。对齐后，每个数都相当于左移了若干位：

    • 一个数原本最多 200 位；
    • 左移的位数最多接近 200（当另一个数的小数部分接近 200 位时）；
    • 所以一个数放大后，位数最多约 \(200 + 200 = 400\) 位。

    这就是为什么数组要开接近两倍：输入的 200 位可能全在整数部分，对齐小数位时又要整体左移接近 200 位，放大后的位数就可能接近 400。开 N = 505，既覆盖 400 位，又留了进位和边界余量。

    5．结构体设计：复用前文的 Number

    浮点高精度不需要重新发明一套整数运算，直接复用第七章的 Number，再包一层 BigFloat：

    struct BigFloat {
    Number num;    // 去掉小数点后的整数（绝对值）
    int L;         // 小数位数
    int sign;      // 1 表示正，-1 表示负
};
    • num 用第七章的 Number，加、减、比较直接复用；
    • L 记录小数位数，对齐时用；
    • sign 单独记录符号，num 只存绝对值。

    6．参考代码

// 从数字字符串构造 Number（倒序存储，去前导零）
Number fromString(string s) {
    Number res;
    memset(res.data, 0, sizeof res.data);
    res.len = s.size();
    for (int i = 1; i <= res.len; i++) res.data[i] = s[res.len - i] - '0';
    while (res.len > 1 && res.data[res.len] == 0) res.len--;
    return res;
}

// ---------- 浮点高精度 BigFloat ----------
struct BigFloat {
    Number num;    // 去掉小数点后的整数（绝对值）
    int L;         // 小数位数
    int sign;      // 1 正，-1 负
};

// 把 Number 乘以 10^k：整体向高位移动 k 位，低位补 0
Number shiftLeft(Number x, int k) {
    if (k == 0) return x;
    if (x.len == 1 && x.data[1] == 0) return x;   // 0 不用移
    for (int i = x.len; i >= 1; i--) x.data[i + k] = x.data[i];
    for (int i = 1; i <= k; i++) x.data[i] = 0;
    x.len += k;
    return x;
}

// 读入一个浮点字符串，转成 BigFloat
BigFloat readBigFloat(string s) {
    BigFloat res;
    res.sign = 1;
    if (s[0] == '-') { res.sign = -1; s = s.substr(1); }

    int p = s.find('.');
    string ip = s.substr(0, p);
    string fp = "";
    if (p != string::npos) fp = s.substr(p + 1);

    res.L = fp.size();
    res.num = fromString(ip + fp);
    if (res.num.len == 1 && res.num.data[1] == 0) res.sign = 1;  // 0 不带负号
    return res;
}

// 两个 BigFloat 相加
BigFloat operator+(BigFloat a, BigFloat b) {
    // 小数位数对齐到 max(a.L, b.L)
    int L = max(a.L, b.L);
    Number A = shiftLeft(a.num, L - a.L);
    Number B = shiftLeft(b.num, L - b.L);

    BigFloat res;
    res.L = L;

    if (a.sign == b.sign) {
        // 同号：相加，符号不变
        res.num = A + B;
        res.sign = a.sign;
    } else {
        // 异号：大减小，符号取绝对值大的
        if (A < B) {
            res.num = B - A;
            res.sign = b.sign;
        } else if (B < A) {
            res.num = A - B;
            res.sign = a.sign;
        } else {
            res.num = fromString("0");
            res.sign = 1;
        }
    }
    return res;
}

// 把 BigFloat 转回字符串，按 L 插回小数点
string toString(BigFloat a) {
    string s;
    for (int i = a.num.len; i >= 1; i--) s += char(a.num.data[i] + '0');

    // 整数部分至少 1 位，不够就前面补 0
    while ((int)s.size() < a.L + 1) s = "0" + s;

    string ip = s.substr(0, s.size() - a.L);   // 整数部分
    string fp = s.substr(s.size() - a.L);      // 小数部分

    while (!fp.empty() && fp.back() == '0') fp.pop_back();   // 去小数尾零
    while (ip.size() > 1 && ip[0] == '0') ip.erase(ip.begin()); // 去整数前导零

    string res = ip;
    if (!fp.empty()) res += "." + fp;

    if (a.sign == -1) res = "-" + res;
    return res;
}

int main() {
    string sa, sb;
    cin >> sa >> sb;

    BigFloat a = readBigFloat(sa);
    BigFloat b = readBigFloat(sb);
    BigFloat c = a + b;

    cout << toString(c) << '\n';
    return 0;
}

    7．要点

    • 定点化：去掉小数点，整体放大 \(10^L\)，用 Number 做整数运算；
    • 小数位对齐：两个数的小数位数不同，先补齐到 max(L1, L2)，再相加；
    • 数组开两倍：输入的 200 位可能全在整数部分，对齐时又要整体左移接近 200 位，放大后最多接近 400 位，所以 N 要开到输入最大位数的两倍左右；
    • 复用封装：浮点高精度，可以直接重新写一套模板，也可以复用高精度整数的模板 Number；
    • 符号单独处理：num 只存绝对值，sign 存正负；同号相加，异号大减小；
    • 输出：按 L 插回小数点，去掉小数末尾的 0，整数部分至少保留一位；
    • 负零：结果为 0 时不要输出 -0，readBigFloat 和加法里都已经处理。

    九、总结

    本质

    高精度就是竖式模拟：字符串读入、倒序存数组、低位对齐。本课统一下标从 1 开始，a[1] 是个位，a[len] 是最高位。倒序存储让进位方向自然、个位天然对齐、短数高位自动补 0。

    输入与存储

    • 高精度数必须用字符串读入，不能直接用 int / long long 读；
    • 读入后倒序存进数组，a[1] 是个位，a[len] 是最高位；
    • 减法、除法、乘法结束都要去前导零，至少保留一位；
    • 数组大小按“结果最多几位”估，再加一点余量。

    四种整数运算

    运算 方向 结果最多几位 关键
    加法 低位到高位 max(lena, lenb) + 1 进位最后可能多一位，c 比输入多开一位
    减法 低位到高位 max(lena, lenb) 借位、去前导零、先比较大小，c 和输入一样大
    乘法 低位到高位 lena + lenb c[i+j-1] += a[i]*b[j]，最后统一进位，c 开两数位数之和
    除以低精度 高位到低位 lena 余数 r*10 + a[i]，余数用 long long，c 和被除数一样大

    浮点高精度

    核心是定点化：去掉小数点，整体放大 \(10^L\)，用高精度整数算；小数点位置单独记录，输出时再插回去。小数位数不同时，先补齐到 max(L1, L2) 再运算；数组要开输入最大位数的两倍左右，因为输入可能全在整数部分，对齐小数位时又要整体左移。注意去小数尾零、去整数前导零、不要输出 -0。

    结构体封装

    把 data[] 和 len 放进结构体，重载 + - * / <，大整数就能像 int 一样参与运算。结构体内部仍然下标从 1 开始、低位在前。浮点高精度可以重新写一套模板，也可以复用 Number，再包一层 BigFloat进一步处理。
