    第 14 课 二分

    有序查找、二分答案与单调性

    学习目标：理解二分“每次砍半、O(log n)”的核心思想；掌握有序数组上的二分查找，会用 lower_bound 找“第一个满足条件”的位置；理解二分答案的适用条件——单调性，会用“二分 + check”解决“求最大/最小可行答案”的问题；避开 mid 溢出、死循环、区间开闭这些高频坑。

    一、二分的基本思想

    1．从一个游戏说起：猜数字

    主持人心里想一个 0~100 的整数，你每猜一次，他只告诉你“大了”还是“小了”。怎样才能用最少的次数猜中？

    • 最笨的办法：从 0、1、2……一个个猜，最坏要 100 次；
    • 聪明的办法：先猜中间的 50，大了就猜 25，小了就猜 75，每次都砍掉一半。

    这样最多只要 7 次就能保证猜中（因为 2⁷ = 128，已经超过 100）。

    这个“每次都砍一半”的办法，就是二分。范围从 100 砍到 50、25、12……很快就只剩一个，这就是二分快的秘密。

    2．二分是什么

    二分（Binary Search），也称折半搜索（Half-interval Search）、对数搜索（Logarithmic Search），是一种在答案可能出现的范围内，通过每次排除一半候选来快速查找目标或逼近最优解的算法思想。

    它主要有两大用途：

    • 在有序序列里定位某个值及其左右边界——这就是二分查找；
    • 在答案的取值范围内，通过判断“某个答案是否可行”来逼近最优值——这就是二分答案。

    3．核心思想与三步策略

    二分的思想一句话：在答案可能出现的范围内，每次取中点判断一次，根据结果排除掉不可能含答案的那一半，让范围不断折半。

    落地成三步：

    1. 取中点：把当前范围尽量均匀地一分为二；
    2. 做判断：看中点与目标或条件的关系，确定答案在哪一侧；
    3. 保留有希望的一半：丢弃不可能的那一半，问题规模减半，回到第 1 步。

    整个过程不靠逐个枚举，而是“用一次判断排除掉一半候选”。

    4．原理：单调性（表现为二段性）

    二分为什么不会漏掉答案？靠的是判断条件 check(x) 具有单调性。可以把 check(x) 理解成“候选值取 x 时行不行”。随着 x 变化，判断结果只会朝一个方向变化，不会来回反复，表现为二段性：判断结果分成两段，一段全不满足，另一段全满足，中间只有一个分界点。

    false false false false false true true true true true

    或：

    true true true true true false false false false false

    因此，中点的一次判断能够代表一整侧的结论：

    • 若 check(mid) 不满足，则按分界方向，某一侧的所有候选也一定不满足；
    • 若 check(mid) 满足，则另一侧的所有候选也一定满足。

    于是，每次判断都能排除掉一定不含答案的一半，答案始终留在剩余区间内。这就是二分正确性的根本保证。

    5．二分能快到什么程度

    二分查找的复杂度是 O(log n)——每砍一半，规模缩成二分之一，砍到 1 大约要 log₂n 次。

    对比暴力枚举的 O(n)：

    数据规模 n 暴力枚举（最多） 二分（最多）
    100 100 次 7 次
    1000 1000 次 10 次
    100 万 100 万次 20 次
    10 亿 10 亿次 30 次

    n 越大，差距越夸张。这就是“对数搜索”这个名字的由来。

    6．与暴力枚举的关系

    一句话：暴力枚举是一个一个试，二分是一次排除一批。

    同样是“找答案”，暴力要把每个候选都试一遍；二分靠单调性，一次判断就能扔掉一半。二分的代价是——它要求候选结构满足可二分条件，而暴力枚举没有这个要求。

    二、二分查找

    二分查找在有序数组里快速定位元素。先记住：有序才能二分，无序先排序。

    1．找一个值是否存在：闭区间写法

    闭区间指搜索范围写成 [L, R]，左右端点都在范围内。最基础的“找到就返回”写法：

    // 在升序数组 a[1..n] 中找 x，找到返回下标，找不到返回 -1
int L = 1, R = n;                  // 闭区间 [L, R]
while (L <= R) {                   // 闭区间的标志：L <= R
    int mid = L + (R - L) / 2;     // 防溢出
    if (a[mid] == x) return mid;   // 找到
    else if (a[mid] < x) L = mid + 1;   // 去右半
    else R = mid - 1;                     // 去左半
}
return -1;                          // 没找到

    要点：

    • 闭区间 [L, R]，循环条件是 L <= R（L == R 时区间还剩一个元素，要再判断一次）；
    • 每次 L = mid + 1 或 R = mid - 1，mid 被排除，不会死循环；
    • mid = L + (R - L) / 2 先减后除，防溢出。

    但这个写法有个局限：数组里有重复元素时，a[mid] == x 返回的可能是中间某个位置，不是第一次出现。要“第一次出现”，改成“记下答案、继续往左找”：

    // 找 x 第一次出现的位置，找不到返回 -1
int L = 1, R = n, ans = -1;
while (L <= R) {
    int mid = L + (R - L) / 2;
    if (a[mid] >= x) {   // mid 可能是答案
        ans = mid;       // 先记下
        R = mid - 1;     // 继续往左找更早的
    } else {
        L = mid + 1;
    }
}
if (ans == -1 || a[ans] != x) ans = -1;   // 判断是否真的等于 x

    例题：P1680 查找

    问题描述

    输入 n 个单调不减的整数，进行 m 次询问。每次给一个数 q，输出 q 第一次出现的编号（从 1 开始），找不到输出 -1。

    输入：
11 3
1 3 3 3 5 7 9 11 13 15 15
1 3 6
输出：
1 2 -1

    思路

    • 序列已经有序，直接二分；
    • 用“记下答案、继续往左找”的写法，找第一个 ≥ q 的位置；
    • 最后判断 a[ans] == q，相等才是真出现，否则输出 -1。

    参考代码

    #include <iostream>
using namespace std;

const int N = 1000005;
int a[N];
int n, m;

int main() {
    ios::sync_with_stdio(false);   // 数据量大，关同步提速
    cin.tie(0);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];

    while (m--) {
        int q;
        cin >> q;
        int L = 1, R = n, ans = -1;
        while (L <= R) {
            int mid = L + (R - L) / 2;
            if (a[mid] >= q) {
                ans = mid;
                R = mid - 1;
            } else {
                L = mid + 1;
            }
        }
        if (ans != -1 && a[ans] == q) cout << ans << ' ';
        else cout << -1 << ' ';
    }
    return 0;
}

    要点

    • 二分只保证找到“第一个 ≥ q”的位置，不代表它等于 q，最后一定要判断 a[ans] == q；
    • n 到 10⁶、m 到 10⁵，每次询问 O(log n)，总 O(m log n) 能过；
    • 输入量大，加 ios::sync_with_stdio(false) 提速。

    2．找左右边界

    “第一个 ≥ x”和“第一个 > x”是两个最常用的边界，分别叫 lower_bound 和 upper_bound。

    // lower_bound：第一个 >= x 的位置（不存在则返回 n+1）
int lower_bound_x(int x) {
    int L = 1, R = n + 1;            // 上界 n+1，当“不存在”的哨兵
    while (L < R) {
        int mid = L + (R - L) / 2;   // 下取整
        if (a[mid] >= x) R = mid;    // mid 可能是答案，保留
        else L = mid + 1;
    }
    return L;
}

// upper_bound：第一个 > x 的位置（不存在则返回 n+1）
int upper_bound_x(int x) {
    int L = 1, R = n + 1;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] > x) R = mid;
        else L = mid + 1;
    }
    return L;
}

    注意：

    • 循环条件是 L < R（不是 L <= R），R = mid 保留 mid，所以 mid 用下取整，不会死循环；
    • 返回 n + 1 表示“不存在”，方便后面算个数。

    x 出现的个数 = upper_bound − lower_bound：第一个 > x 的位置，减去第一个 ≥ x 的位置，中间正好是全部等于 x 的元素个数。

    例题：P1681 A-B 数对

    问题描述

    给一串数和一个数字 C，求所有满足 A − B = C 的数对 (A, B) 的个数。不同位置的相同数字算不同数对。

    输入：
4 1
1 1 2 3
输出：
3

    思路

    • 把 A − B = C 变形成 A = B + C；
    • 枚举每个数当 B，找 A = B + C 的个数，累加；
    • 先排序，再用“upper_bound − lower_bound”求 A 的个数。

    参考代码（手写二分）

    #include <iostream>
#include <algorithm>
using namespace std;

const int N = 200005;
long long a[N];
long long n, c;

int lower_bound_x(long long x) {
    int L = 1, R = n + 1;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] >= x) R = mid;
        else L = mid + 1;
    }
    return L;
}

int upper_bound_x(long long x) {
    int L = 1, R = n + 1;
    while (L < R) {
        int mid = L + (R - L) / 2;
        if (a[mid] > x) R = mid;
        else L = mid + 1;
    }
    return L;
}

int main() {
    cin >> n >> c;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);          // 题目没说有序，必须先排序

    long long ans = 0;
    for (int i = 1; i <= n; i++) {
        long long target = a[i] + c;  // A = B + C
        int L = lower_bound_x(target);
        int R = upper_bound_x(target);
        ans += R - L;                  // 等于 target 的个数
    }
    cout << ans << '\n';
    return 0;
}

    要点

    • 题目没说序列有序，必须先 sort；
    • a[i] + c 可能较大，用 long long；
    • target 比所有数都大时，lower 和 upper 都返回 n+1，R - L = 0，正好没有，不用特判。

    3．STL：lower_bound / upper_bound

    标准库已经写好这两个函数，头文件 <algorithm>：

    int p1 = lower_bound(a + 1, a + n + 1, x) - a;  // 第一个 >= x 的下标
int p2 = upper_bound(a + 1, a + n + 1, x) - a;  // 第一个 > x 的下标
    • 查找范围 a + 1 到 a + n + 1 是左闭右开 [1, n+1)；
    • 返回值是迭代器（指针），减掉数组首地址 a 才是下标；
    • 找不到时返回 a + n + 1，减 a 得 n + 1。

    升降序列的用法：上面是升序序列（默认），lower_bound 找第一个 ≥ x，upper_bound 找第一个 > x。

    如果是降序序列，加第 4 个参数 greater<类型>()，含义反过来：

    // 降序序列 a（从大到小）
int p1 = lower_bound(a + 1, a + n + 1, x, greater<int>()) - a;  // 第一个 <= x
int p2 = upper_bound(a + 1, a + n + 1, x, greater<int>()) - a;  // 第一个 < x

    速记：升序找“≥ / >”，降序加 greater 后找“≤ / <”。 初学建议统一排成升序再用默认用法，不容易错。

    用 STL 重做：P1681 A-B 数对

    #include <iostream>
#include <algorithm>
using namespace std;

const int N = 200005;
long long a[N];
long long n, c;

int main() {
    cin >> n >> c;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);

    long long ans = 0;
    for (int i = 1; i <= n; i++) {
        long long target = a[i] + c;
        int L = lower_bound(a + 1, a + n + 1, target) - a;
        int R = upper_bound(a + 1, a + n + 1, target) - a;
        ans += R - L;
    }
    cout << ans << '\n';
    return 0;
}

    和手写版结果一致，只是把二分部分换成了 STL，代码更短。

    三、二分答案

    1．什么是二分答案

    很多题的答案是“在一个范围里找一个数”，而且这个范围很大。如果从 1 枚举到 10⁹，肯定超时。

    如果答案满足单调性——某个值可行，比它更“好”的一边也都可行（或都不可行）——就可以二分这个答案，每次猜一个 mid，用 check(mid) 判断它可不可行，再砍半。

    先记住一句话：答案单调，二分来猜；check 验一下，区间砍一半。

    2．适用条件：单调性

    二分答案必须满足单调性。最常见的是这两种：

    • 求最大值：某个值可行，比它小的也都可行（check 随 mid 单调）。例如砍树，锯片越低砍得越多，H 越小越容易达到 M 米。
    • 求最小值：某个值可行，比它大的也都可行。例如最小化最大距离。

    判断能不能二分答案，就问自己：“答案越大（或越小），check 的结果是不是单调变化？” 是就能二分。

    3．模板：二分 + check

    求“最大的可行答案”：

    int L = 起点, R = 终点;
while (L < R) {
    int mid = L + (R - L + 1) / 2;   // 上取整！防止死循环
    if (check(mid)) {
        L = mid;                     // mid 可行，答案至少是 mid
    } else {
        R = mid - 1;                 // mid 不可行，答案在 mid 左边
    }
}
cout << L;                           // L == R，就是答案

    check(mid) 是一个判断函数，回答“mid 这个答案是否可行”，通常就是按题意模拟或贪心。

    4．为什么这里 mid 要“上取整”

    这是二分答案最容易错、也最值得记的一点。

    当 check(mid) 可行时，我们写 L = mid（因为 mid 可能就是答案）。如果此时 mid 用的是下取整，会出现一种危险情况：

    L = 2, R = 3，mid = (2 + 3) / 2 = 2（下取整）
如果 check(2) 可行，L = 2（没变！）
下一轮还是 L = 2, R = 3，mid 还是 2……死循环

    把 mid 改成上取整 mid = L + (R - L + 1) / 2：

    L = 2, R = 3，mid = (2 + 3 + 1) / 2 = 3（上取整）
mid 会真正变大，L 能前进，不会死循环

    速记：

    更新方式 mid 取整 用途
    R = mid 下取整 (L+R)/2 找第一个满足（lower_bound 类）
    L = mid 上取整 (L+R+1)/2 找最大的可行（二分答案常见）

    一句话：谁用 = mid 保留 mid，mid 就朝谁的方向取整。

    四、边界与常见坑

    1．区间开闭要统一

    • 左闭右闭 [L, R]：初始 L = 起点, R = 终点，循环 L <= R 或 L < R（视模板而定）。
    • 左闭右开 [L, R)：初始 R = 终点 + 1，循环 L < R。

    初学建议只用左闭右闭，别混用，混用必错。

    2．mid 溢出

    int mid = (L + R) / 2;   // L + R 可能超过 int 范围，溢出
int mid = L + (R - L) / 2;  // 先减后除，安全

    当 L、R 都接近 2×10⁹ 时，L + R 会溢出 int（甚至 long long 若范围更大）。永远写 L + (R - L) / 2。

    3．死循环

    死循环的根源是“L 或 R 不前进”。检查：

    • 每次循环，L 或 R 至少有一个变化；
    • L = mid 时，mid 必须上取整；
    • R = mid 时，mid 必须下取整；
    • 循环条件写对（L < R 还是 L <= R）。

    4．check 方向与答案区间

    写 check 前先问清楚：

    1. 答案的最小可能值和最大可能值是多少？（决定 L、R 初始值）
    2. check(mid) 为真时，答案是“至少 mid”还是“至多 mid”？（决定 L、R 怎么更新）
    3. 最后答案是 L 还是 R？（两个模板下循环结束 L == R，都一样）

    五、经典例题

    例题 1：二分查找

    问题描述

    给一个升序数组 a[1..n] 和一个整数 x，输出 x 第一次出现的位置（下标从 1 开始）；如果 x 不存在，输出 -1。

    输入：
5 7
1 3 7 7 9
输出：
3

    思路

    • 升序数组，用二分；
    • 找“第一个 ≥ x 的位置”，即 lower_bound；
    • 找到后判断 a[L] == x，相等才是真出现，否则是 -1。

    参考代码

    #include <iostream>
using namespace std;

const int N = 100005;
int a[N];
int n, x;

int main() {
    cin >> n >> x;
    for (int i = 1; i <= n; i++) cin >> a[i];

    int L = 1, R = n;
    while (L < R) {
        int mid = L + (R - L) / 2;      // 下取整
        if (a[mid] >= x) R = mid;       // 保留 mid
        else L = mid + 1;
    }
    // L == R，是第一个 >= x 的位置
    if (a[L] == x) cout << L << '\n';
    else cout << -1 << '\n';
    return 0;
}

    要点

    • R = mid 时 mid 下取整，不会死循环；
    • 二分只保证 a[L] 是“第一个 ≥ x”，不等于它一定是 x，最后要再判断一次；
    • x 比所有数都大时，L 会走到 n，a[n] != x，正确输出 -1。

    例题 2：砍树（P1873）

    问题描述

    有 n 棵树，第 i 棵高 h[i] 米。伐木机锯片设置在高度 H，能砍下所有“高于 H 的部分”。求能获得至少 M 米木材的最大整数高度 H。

    输入：
4 7
20 15 10 17
输出：
15

    （H = 15 时：第 1 棵砍下 5，第 4 棵砍下 2，共 7 米，正好够；H = 16 时只剩 5 米，不够。）

    思路

    • 答案 H 满足单调性：H 越小，砍下的木材越多，越容易达到 M 米；
    • check(H) = “砍下的木材 ≥ M”，用循环累加判断；
    • 求最大 H，用“二分答案 + 上取整”模板。

    参考代码

    #include <iostream>
using namespace std;

const int N = 1000005;
int h[N];
int n;
long long m;

bool check(int H) {                 // 判断 H 是否可行
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        if (h[i] > H) sum += h[i] - H;
    }
    return sum >= m;
}

int main() {
    cin >> n >> m;
    int maxh = 0;
    for (int i = 1; i <= n; i++) {
        cin >> h[i];
        if (h[i] > maxh) maxh = h[i];
    }

    int L = 0, R = maxh;             // 答案区间 [0, 最高树高]
    while (L < R) {
        int mid = L + (R - L + 1) / 2;   // 上取整，因为 L = mid
        if (check(mid)) L = mid;         // 可行，抬高锯片
        else R = mid - 1;                // 不可行，降低锯片
    }
    cout << L << '\n';
    return 0;
}

    要点

    • sum 用 long long：n、h 可能很大，累加会超 int；
    • L = mid 所以 mid 上取整，防死循环；
    • 答案区间是 [0, maxh]，别忘了下限可能是 0。

    例题 3：木材加工（P2440）

    问题描述

    有 n 段原木，第 i 段长 wood[i]。要切成 k 段等长的小木段（多余部分丢弃）。求小木段的最大长度；如果切不出 k 段，输出 0。

    输入：
3 7
232 124 456
输出：
114

    思路

    • 答案是小段长度 len，单调：len 越小，能切出的段数越多；
    • check(len) = “Σ(wood[i] / len) ≥ k”，每段能切出 wood[i] / len 段；
    • 求最大 len，上取整模板。

    参考代码

    #include <iostream>
using namespace std;

const int N = 100005;
int wood[N];
int n, k;

bool check(int len) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++) {
        cnt += wood[i] / len;           // 每段能切几段
    }
    return cnt >= k;
}

int main() {
    cin >> n >> k;
    int maxl = 0;
    for (int i = 1; i <= n; i++) {
        cin >> wood[i];
        if (wood[i] > maxl) maxl = wood[i];
    }

    int L = 0, R = maxl;           // 答案区间 [0, 最长原木]
    while (L < R) {
        int mid = L + (R - L + 1) / 2;   // 上取整
        if (check(mid)) L = mid;
        else R = mid - 1;
    }
    cout << L << '\n';
    return 0;
}

    要点

    • 注意 check(0) 会除以 0，所以答案下限写成 0，但实际二分时 mid 上取整不会取到 0（L 从 0 起步，第一轮 mid 就 ≥ 1）；
    • 若一根都切不出，答案停在 0，正好符合题意；
    • 和砍树是同一套“求最大可行答案”的模板，只是 check 不同。

    六、总结

    本质：二分 = 每次砍一半，把 O(n) 变成 O(log n)。

    二分查找：数组必须有序；两个模板——精确查找（L <= R）和 lower_bound（L < R、R = mid）。

    二分答案：答案单调就能二分；用 check(mid) 判断可行性，再砍半。

    常见坑：

    • mid 用 L + (R - L) / 2 防溢出；
    • L = mid 时 mid 上取整，R = mid 时 mid 下取整，否则死循环；
    • 区间开闭统一，答案区间（L、R 初始值）想清楚；
    • 累加类 check 用 long long。

    总口诀：有序才能二分查，答案单调二分答；mid 防溢上下取，L 动 R 动别写反。
