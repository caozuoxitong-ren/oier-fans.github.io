# 第 05 课 char 数组

字符数组的基本思想、C 风格字符串与经典题型

> **学习目标**：理解字符数组“连续存储 + '\0' 结尾”的核心思想；掌握定义、初始化、遍历和 '\0' 的作用；能正确选择 cin >>、cin.getline 等输入方式，避开空格截断和换行残留；掌握常用 <cstring> 函数和 ASCII 码运算；能解决字符统计、大小写转换、子串匹配、分隔符解析和字典序比较等典型问题。

## 一、char 数组的概念与基本思想

### 1．什么是字符数组

字符数组是用来存放字符的数组，声明方式如 `char s[100];`。每个元素是一个 `char`，占 1 字节。

字符数组本身只是“一排字符”，并不天然表示一个字符串。**C 风格字符串**的约定是：**字符序列以 `'\0'` 结尾**，`'\0'` 之前的内容才是有效字符串，`'\0'` 本身不计入长度。

可以把 `'\0'` 理解为一条“结束线”：所有字符串处理函数（`strlen`、`strcmp`、`strncmp`、`strcpy`、`strncpy`、`strcat`、`strncat`）以及 `cout << s`，都只认 `'\0'` 之前的字符，遇到 `'\0'` 就停。没有 `'\0'`，它们不会知道字符串在哪里结束。

### 2．char 数组与 string 的比较

| 操作 | 字符数组 | string |
| :--- | :--- | :--- |
| 定义 | `char s[100];` | `string s;` |
| 长度 | `strlen(s)` | `s.length()` / `s.size()` |
| 赋值 | 不能直接 `s = "abc"`（初始化除外） | 可以直接 `=` |
| 拼接 | 需要 `strcat` | 直接用 `+` |
| 比较 | 需要 `strcmp` | 可以直接 `==`、`<` |
| 输入含空格 | 需要 `cin.getline` | `getline(cin, s)` |
| 越界风险 | 高，`'\0'` 缺失或数组不够大都会出问题 | 较低，自动管理 |

### 3．`'\0'` 为什么是字符数组的“命门”

`'\0'` 是空字符，对应的 ASCII 码是 0，它既是一个真实存储的字符，又是所有 C 风格字符串函数的终止信号。由此产生两条必须记住的结论：

- **数组大小必须至少比有效字符数多 1**。`"hello"` 有 5 个字符，`char s[5] = "hello";` 没有空间放 `'\0'`，它就不是一个合法的 C 风格字符串；`char s[6] = "hello";` 或 `char s[] = "hello";` 才是正确的。
- **`strlen` 只数到第一个 `'\0'`**。如果数组中 `'\0'` 出现得比预期早，`strlen` 会返回一个偏小的值；如果整个数组没有 `'\0'`，`strlen` 会越界继续向后找，结果不确定。


## 二、字符数组的定义、初始化与遍历

### 1．定义与初始化

```cpp
char a[10];                              // 未初始化，内容不确定
char b[5] = {'h', 'e', 'l', 'l', 'o'};   // 5 个字符，结尾没有 '\0'，不是有效字符串
char c[6] = {'h', 'e', 'l', 'l', 'o', '\0'}; // 合法的 C 风格字符串
char d[6] = "hello";                     // 编译器自动在末尾补 '\0'
char e[] = "hello";                      // 长度自动定为 6
```

用双引号初始化时，编译器自动在末尾补 `'\0'`；用花括号逐个列字符时，不会自动补。**如果后续要使用 `strlen`、`strcmp`、`cout <<`，必须确保有 `'\0'`。**

部分初始化时，未显式赋值的元素自动补 0（即 `'\0'`）。例如 `char f[10] = {'a', 'b'};` 的后 8 个元素都会自动赋值为 0，它仍然是一个以 `'\0'` 结尾的合法字符串。

### 2．遍历的两种边界

字符数组的遍历有两种写法，边界条件不同，不能混用：

```cpp
char s[10] = "hello";
// 写法一：按数组容量遍历（可能包含 '\0' 及之后的无效字符）
// 字符数组，本身就是一个字符类型的数组，完全可以按照数组的遍历方式进行
for (int i = 0; i < 10; i++) { /* ... */ }

// 写法二：按字符串有效长度遍历（只到 '\0' 之前）
// C风格字符串以 '\0' 为结尾，如果只需遍历有效字符串，则遍历到'\0'停止
for (int i = 0; s[i] != '\0'; i++) { /* ... */ }

// 或者
int len = strlen(s);
for (int i = 0; i < len; i++) { /* ... */ }
```

**如果题目处理的是“有效字符串”，应当使用写法二**；如果题目处理的是“字符数组”本身（比如统计每个字符出现次数、不关心有无 `'\0'` 结尾），则写法一更直接。

### 3．字符数组可以直接用 `cout` 输出

`int` 数组用 `cout << a` 输出的是数组的首地址，但 `char` 数组会直接输出 `'\0'` 之前的字符序列：

```cpp
char s[6] = "hello";
cout << s;   // 输出 hello
```

这是因为 `operator<<` 对 `char*` 有重载，会按 C 风格字符串处理。这一点在调试时很方便，但也意味着**如果字符数组没有 `'\0'`，输出会一直向后读取，产生乱码甚至崩溃**。


## 三、输入：字符数组最容易出错的地方

字符数组的输入方式多，行为差异大，是 CSP-J 中失分最集中的环节。下面按“会遇到什么输入”来梳理。

### 1．不含空格的字符串：`cin >> s` 或 `scanf("%s", s)`

两者都从第一个非空白字符开始读，遇到空格、制表符或换行停止，**自动在末尾补 `'\0'`**。

```cpp
char s[100];
cin >> s;
// 或
scanf("%s", s);
```

适合输入“一个单词”或“一串不含空格的字符”。`scanf` 的 `%s` 不需要取地址符 `&`，因为数组名本身就对应首地址。

### 2．含空格的整行：`cin.getline(s, size)`

如果输入是 `hello world`，`cin >> s` 只能读到 `hello`。要读整行，需要使用 cin.getline()函数：

cin.getline 的两种形式：

```cpp
cin.getline(s, n);          // 默认读到分隔符 '\n'
cin.getline(s, n, delim);   // 读取到指定分隔符 delim 
```

例如：
```cpp
char s[100];
cin.getline(s, 100);        // 读一行，最多 99 个有效字符 (要保留1个位置存放 '\0')
cin.getline(s, 100, 'a');   // 读到 'a' 停止，最多 99 个有效字符
```

`cin.getline` 读到分隔符（默认为换行符'\n'）就停止，**并把分隔符从输入缓冲区取走并丢弃**，不会留在缓冲区里。

### 3．前面有输入残留换行符，接着读整行

`cin >>` 和 `scanf("%s", s)` 读完后，**换行符会留在输入缓冲区**。紧接着调用 `cin.getline`，它会立刻读到这个 `'\n'`，得到一个空串。

```cpp
int n;
char s[100];

cin >> n;              // 输入 3 后按回车，'\n' 留在缓冲区
cin.getline(s, 100);   // 立刻读到残留 '\n'并返回，s 为空串
```

解决办法：读整行前先吃掉残留的换行符。

```cpp
cin >> n;
cin.ignore();          // 吃掉一个字符，通常是 '\n'
cin.getline(s, 100);   // 正常读入下一行
```

也可以用 `getchar()` 吃掉换行符：
```cpp
cin >> n;
getchar()；           // 吃掉残留的 '\n'
cin.getline(s, 100);  // 正常读入下一行
```

**一句话：`cin >>` 之后要读整行，先 `cin.ignore()` 或 `getchar()` 清掉残留换行符，否则 `cin.getline` 会读到空串。**

### 4．一张表看清字符串的输入方式

| 需求 | 推荐写法 | 是否自动补 `'\0'` | 换行符处理 |
| --- | --- | --- | --- |
| 读不含空格的字符串 | `cin >> s` 或 `scanf("%s", s)` | 是 | 遇空白符则停止，换行符通常留在缓冲区 |
| 读含空格的整行 | `cin.getline(s, n)` | 是 | 读到 `'\n'` 停止，取走`\n`并丢弃 |
| 读到指定分隔符 | `cin.getline(s, n, delim)` | 是 | 读到 `delim` 停止，取走`delim`并丢弃 |
| `cin >>` 后接着读整行 | 先 `cin.ignore()` 或 `getchar()`，再 `cin.getline(s, n)` | 是 | 先清掉残留 `'\n'`，再正常读行 |
| 用 `string` 读不含空格的字符串 | `cin >> s` | 不适用（自动管理） | 遇空白符则停止，换行符通常留在缓冲区 |
| 用 `string` 读整行 | `getline(cin, s)` | 不适用（自动管理） | 读到 `'\n'` 停止，并取走丢弃 |
| 用 `string` 读到指定分隔符 | `getline(cin, s, delim)` | 不适用（自动管理） | 读到 `delim` 停止，并取走丢弃 |

## 四、`<cstring>` 常用函数

C 风格字符串的函数都放在 `<cstring>` 头文件中，它们的共同前提是：**参数必须是合法的、以 `'\0'` 结尾的字符数组**。

### 1．`strlen(s)`：有效长度

**参数**：`s`，一个以 `'\0'` 结尾的 C 风格字符串。  
**返回值**：`size_t` 类型，返回 `'\0'` 之前的字符个数，**不包含 `'\0'`**。

```cpp
char s[10] = "hello";
cout << strlen(s);   // 5
```

如果数组没有 `'\0'`，`strlen` 的行为未定义。

### 2．`strcmp(a, b)`：字典序比较

**参数**：`a`、`b`，两个以 `'\0'` 结尾的 C 风格字符串。  
**返回值**：`int` 类型：

- `a` 和 `b` 完全相同：返回 0；
- `a` 在字典序中小于 `b`：返回负数；
- `a` 在字典序中大于 `b`：返回正数。

```cpp
char a[] = "apple", b[] = "banana";
if (strcmp(a, b) < 0) { /* a 的字典序小于 b */ }
```

注意不能直接用 `a == b` 比较两个字符数组，那比较的是地址，不是内容。

### 3．`strcpy(dest, src)`：复制

**参数**：`dest` 是目标字符数组，`src` 是源字符串。  
**返回值**：`char*`，指向 `dest` 的首地址。

把 `src` 的内容（包括 `'\0'`）复制到 `dest`。`dest` 必须足够大，否则越界。

```cpp
char src[] = "hello";
char dest[10];
strcpy(dest, src);       // dest 变成 "hello"
```

字符数组不能用 `dest = src` 赋值，必须用 `strcpy`。

### 4．`strcat(dest, src)`：拼接

**参数**：`dest` 是目标字符数组（必须是合法字符串），`src` 是要追加的源字符串。  
**返回值**：`char*`，指向 `dest` 的首地址。

把 `src` 追加到 `dest` 的末尾，`dest` 必须有足够的剩余空间。

```cpp
char s[20] = "hello";
strcat(s, " world");     // s 变成 "hello world"
```

### 5．带长度限制的版本：`strncpy`、`strncmp`、`strncat`

`strcpy`、`strcmp`、`strcat` 都不检查目标数组大小，容易越界。C 标准库提供了带 `n` 的版本，**最多只处理从给定地址开始的 `n` 个字符**。

#### `strncpy(dest, src, n)`：最多复制 n 个字符

**参数**：`dest` 目标数组，`src` 源字符串，`n` 最多复制的字符数。  
**返回值**：`char*`，指向 `dest` 的首地址。

```cpp
char src[] = "hello";
char dest[10];
strncpy(dest, src, 3);   // dest 得到 "hel"，但不会自动补 '\0'
```

关键行为：

- 最多从 `src` 复制 `n` 个字符到 `dest`；
- 如果 `src` 长度 **小于** `n`，剩余位置用 `'\0'` 填充；
- 如果 `src` 长度 **大于等于** `n`，**不会自动补 `'\0'`**，`dest` 可能不是合法字符串。

所以 `strncpy` 后通常要手动补结束符：

```cpp
char dest[10];
strncpy(dest, src, 3);
dest[3] = '\0';          // 手动补，确保是合法字符串
```

#### `strncmp(a, b, n)`：最多比较前 n 个字符

**参数**：`a`、`b` 两个字符串，`n` 最多比较的字符数。  
**返回值**：`int`，含义与 `strcmp` 相同，只是最多比较 `n` 个字符就停止。

```cpp
char a[] = "abcdef";
char b[] = "abcxyz";
strncmp(a, b, 3);   // 比较 "abc" 和 "abc"，返回 0
strncmp(a, b, 4);   // 比较 "abcd" 和 "abcx"，返回负数
```

常用于“只比较前缀”或“限制比较长度”。

#### `strncat(dest, src, n)`：最多追加 n 个字符

**参数**：`dest` 目标字符串，`src` 源字符串，`n` 最多追加的字符数。  
**返回值**：`char*`，指向 `dest` 的首地址。

```cpp
char s[20] = "hello";
strncat(s, " world!!!", 6);   // 最多追加 6 个字符，s 变成 "hello world"
```

关键行为：

- 最多从 `src` 追加 `n` 个字符到 `dest` 末尾；
- **总是自动补 `'\0'`**；
- `dest` 仍需有足够空间容纳“原内容 + 最多 `n` 个字符 + `'\0'`”。

### 6．三组函数对比

| 不限长度 | 带长度限制 | 长度限制的含义 | 是否自动补 `'\0'` |
| --- | --- | --- | --- |
| `strcpy(dest, src)` | `strncpy(dest, src, n)` | 最多复制 `n` 个字符 | `src` 不足 `n` 时补`'\0'`；`src` 达到 `n` 时**不补** |
| `strcmp(a, b)` | `strncmp(a, b, n)` | 最多比较 `n` 个字符 | 不涉及 |
| `strcat(dest, src)` | `strncat(dest, src, n)` | 最多追加 `n` 个字符 | **总是补** |

**记忆要点**：

- 空间是否足够大：使用任何 C 风格字符串函数前，都要先确认目标数组足够大、字符串以 `'\0'` 结尾。
- 是否自动补`'\0'`: `strncpy` 的“不补 `'\0'`”是最容易踩的坑；`strncat` 总会补；`strncmp` 只影响比较范围。

## 五、ASCII 码：字符运算的基础

字符在底层是整数，`char` 参与运算时按 ASCII 码进行。CSP-J 不要求背完整 ASCII 表，但以下几组必须熟练：

| 关系 | 结论 |
| --- | --- |
| `'0'` 到 `'9'` | 连续，`'5' - '0' = 5` |
| `'A'` 到 `'Z'` | 连续，`'A'` = 65 |
| `'a'` 到 `'z'` | 连续，`'a'` = 97 |
| 大小写差 | `'a' - 'A' = 32` |
| 小写转大写 | `c - 'a' + 'A'` |
| 大写转小写 | `c - 'A' + 'a'` |

这些关系是字符统计、大小写转换、数字字符转数值等操作的基础。需要注意：**字符 `'0'` 和整数 `0` 不是一回事**，前者 ASCII 码是 48，后者是 `'\0'` 的码值。


## 六、经典例题

下面五道题覆盖字符数组的主要操作：整行读入、ASCII 判断、大小写转换、子串匹配、按分隔符解析和字典序比较。每道题都给出问题描述、思路、参考代码和要点。

### 例题 1：字符统计

#### 问题描述

读入一行可能含有空格的字符串，统计其中数字字符、大写字母、小写字母各有多少个。其他字符（空格、标点等）不统计。

```text
输入：Hello 2024 World!
输出：数字：4，大写：3，小写：7
```

#### 思路

- 用 `cin.getline` 读整行，避免空格截断；
- 按 `s[i] != '\0'` 遍历有效字符；
- 用 ASCII 区间判断三类字符：`'0'~'9'`、`'A'~'Z'`、`'a'~'z'`。

#### 参考代码

```cpp
#include <iostream>
using namespace std;

int main() {
    char s[1005];
    cin.getline(s, 1005);

    int digits = 0, upper = 0, lower = 0;

    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            digits++;
        } else if (s[i] >= 'A' && s[i] <= 'Z') {
            upper++;
        } else if (s[i] >= 'a' && s[i] <= 'z') {
            lower++;
        }
    }

    cout << "数字：" << digits
         << "，大写：" << upper
         << "，小写：" << lower << '\n';
    return 0;
}
```

#### 要点

- 含空格的整行必须用 `cin.getline`，不能用 `cin >>`；
- 遍历边界是 `s[i] != '\0'`，不是数组容量；
- 三类判断用 `if / else if` 链，互斥且清晰。


### 例题 2：大小写转换

#### 问题描述

读入 `n`，再读入 `n` 行字符串，每行可能含有空格。把每行中的大写字母转成小写、小写字母转成大写，其他字符不变，逐行输出。

```text
输入：
2
Hello World
CSP-J 2024
输出：
hELLO wORLD
csp-j 2024
```

#### 思路

- `cin >> n` 后缓冲区残留换行符，先 `cin.ignore()`；
- 每行用 `cin.getline` 读入；
- 遍历时用 ASCII 差 `'a' - 'A' = 32` 完成转换。

#### 参考代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();          // 吃掉残留的 '\n'

    char s[1005];
    for (int i = 1; i <= n; i++) {
        cin.getline(s, 1005);

        for (int j = 0; s[j] != '\0'; j++) {
            if (s[j] >= 'a' && s[j] <= 'z') {
                s[j] = s[j] - 'a' + 'A';   // 小写转大写
            } else if (s[j] >= 'A' && s[j] <= 'Z') {
                s[j] = s[j] - 'A' + 'a';   // 大写转小写
            }
        }

        cout << s << '\n';
    }
    return 0;
}
```

#### 要点

- **`cin >> n` 之后必须 `cin.ignore()`**，否则第一行 `cin.getline` 会读到空串；
- 转换只改字母，数字、空格、标点保持原样；


### 例题 3：字典序比较

#### 问题描述

读入 `n`，再读入 `n` 组字符串，每组两个不含空格的单词。按字典序比较两个单词，输出：

- `-1`：第一个单词字典序小于第二个；
- `0`：两个单词相同；
- `1`：第一个单词字典序大于第二个。

```text
输入：
3
apple banana
hello hello
zoo apple
输出：
-1
0
1
```

#### 思路

- 用 `strcmp(a, b)` 比较；
- `strcmp` 的返回值只保证“负数 / 0 / 正数”，**不保证恰好是 -1、0、1**，所以要归一化输出；
- 每组用 `cin >> a >> b` 读两个单词即可，单词不含空格。

#### 参考代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    int n;
    cin >> n;

    char a[105], b[105];
    for (int i = 1; i <= n; i++) {
        cin >> a >> b;

        int r = strcmp(a, b);
        if (r < 0) {
            cout << -1 << '\n';
        } else if (r > 0) {
            cout << 1 << '\n';
        } else {
            cout << 0 << '\n';
        }
    }
    return 0;
}
```

#### 要点

- **不能直接输出 `strcmp(a, b)`**，它的返回值可能是任意负数或正数，题目要求的是 `-1 / 0 / 1`，必须判断后归一化；
- 不能用 `a == b` 比较两个字符数组，那比较的是地址；
- 如果单词可能含空格，就要改用 `cin.getline` 分别读两行，本题单词不含空格，`cin >>` 更简洁。

### 例题 4：统计子串出现次数

#### 问题描述

给定两个不含空格的字符串 `s` 和 `p`。统计 `p` 在 `s` 中出现了多少次。允许重叠，例如 `s = "aaa"`、`p = "aa"` 时出现 2 次。

```text
输入：
aaaaa
aa
输出：
4
```

#### 思路

- 用 `strlen` 求两个串的长度；
- 枚举起点 `i`，只要 `i + lenp <= lens` 就还有足够空间；
- 用 `strncmp(p, s + i, lenp) == 0` 判断从 `s[i]` 开始的 `lenp` 个字符是否与 `p` 相同；
- 每次 `i++`，允许重叠。

#### 参考代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[1005], p[105];
    cin >> s >> p;

    int lens = strlen(s);
    int lenp = strlen(p);
    int ans = 0;

    for (int i = 0; i + lenp - 1 < lens; i++) {
        if (strncmp(p, s + i, lenp) == 0) {
            ans++;
        }
    }

    cout << ans << '\n';
    return 0;
}
```

#### 要点

- **循环边界是 `i + lenp -1 < lens`**，保证 `s + i` 之后至少有 `lenp` 个字符，不会越界；
- `strncmp(p, s + i, lenp)` 只比较前 `lenp` 个字符，不要求 `s + i` 后面恰好是 `'\0'`；
- 如果题目要求**不重叠**，匹配成功后改成 `i += lenp - 1`（配合 `for` 的 `i++` 相当于跳过整个匹配段）；本题允许重叠，所以 `i++`。

### 例题 5：逗号分隔数字求和

#### 问题描述

读入一行不含空格的字符串，由数字和逗号组成，数字之间用逗号分隔。求所有数字之和。

```text
输入：12,34,5,100
输出：151
```

#### 思路

- 用 `cin >> s` 读入整串（不含空格）；
- 遍历字符：
  - 遇到数字，累积到当前数 `cur = cur * 10 + (s[i] - '0')`；
  - 遇到逗号，把 `cur` 加到总和，`cur` 清零；
- 遍历结束后，**最后一段数字还没有结算**，要再 `sum += cur`。

#### 参考代码

```cpp
#include <iostream>
using namespace std;

int main() {
    char s[1005];
    cin >> s;

    long long sum = 0;
    long long cur = 0;

    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            cur = cur * 10 + (s[i] - '0');
        } else if (s[i] == ',') {
            sum += cur;
            cur = 0;
        }
    }
    sum += cur;      // 处理最后一段

    cout << sum << '\n';
    return 0;
}
```

#### 要点

- **最后一段数字没有逗号结尾，循环结束后必须补一次 `sum += cur`**，这是本题最容易漏的地方；
- 数字可能较大，用 `long long` 存总和和当前数；
- `s[i] - '0'` 把数字字符转成数值，是 ASCII 运算的典型用法；
- 如果输入末尾带逗号，最后 `cur = 0`，加 0 不影响结果。

## 七、总结

**本质：字符数组 = 连续空间 + `'\0'` 结束线。函数和输出都只认 `'\0'` 之前的内容。**

**两条铁律**

- 数组最小长度 = 有效字符数 + 1；
- 没有 `'\0'` 就不是有效字符串。

**输入**

- 不含空格：`cin >> s`
- 含空格整行：`cin.getline(s, n)`
- `cin >>` 后读整行：先 `cin.ignore()`

**函数**

- `strlen`：数到 `'\0'`，不含 `'\0'`
- `strcmp`：返回负/0/正
- `strcpy`：复制，`dest` 要够大
- `strcat`：拼接，`dest` 要有剩余空间
- `strncpy`：最多复制 n 个，**达到 n 时不补 `'\0'`**
- `strncmp`：最多比较 n 个，常用于前缀、子串匹配
- `strncat`：最多追加 n 个，**总是补 `'\0'`**

**ASCII**

- 数字转值：`c - '0'`
- 大小写互转：`c - 'a' + 'A'`，`c - 'A' + 'a'`

**遍历**

- 字符串：`s[i] != '\0'`
- 字符数组：`i < 容量`
