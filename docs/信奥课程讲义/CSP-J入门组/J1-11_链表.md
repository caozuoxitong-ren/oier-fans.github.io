# 第11课 · 链表

## 一、链表是什么

链表是一种**物理存储不连续、逻辑上连续**的线性数据结构。每个节点包含：

-   **数据域**：存储元素值；
-   **指针域**：存储后继（单链表）或前驱/后继（双向链表）的位置。

链表通过指针把离散节点串联成序列，因此插入、删除在**已知目标节点位置**时只需修改指针，不需要像数组那样移动大量元素。

---

## 二、链表与数组的核心区别

| 对比项 | 数组 | 链表 |
| --- | --- | --- |
| 存储方式 | 连续存储 | 不一定连续，节点靠指针链接 |
| 访问方式 | 支持随机访问，`a[k]` 为 O(1) | 只能顺序访问，找第 k 个为 O(k) |
| 插入/删除 | 通常需移动元素，O(n) | 已知节点指针时改指针，O(1) |
| 容量 | 通常固定 | 可动态调整，或静态预分配 |
| 适用场景 | 频繁按下标访问 | 频繁插入、删除、维护相邻关系 |

---

## 三、链表的常见类型

链表的“类型”可以从不同角度划分：按指针方向和首尾关系分，是最核心的逻辑类型；按是否带头节点分，影响边界处理；按实现方式分，影响写法实现。

### 1\. 按指针方向与首尾关系划分

#### (1) 单链表

单链表中每个节点只保存一个指向后继节点的指针。整个链表从头部开始，沿着后继指针依次向后访问，最后一个节点指向空。

特点是结构最简单，只能单向顺序访问。查找某个节点必须从头开始逐个经过，不能直接跳到中间位置。已知某个节点时，在它后面插入新节点比较方便；但删除某个节点通常需要先找到它的前驱节点，因为要修改前驱的后继指向。

单链表适合频繁在尾部或已知位置之后插入、并且主要从头顺序处理的场景。

```text
head
 ↓
┌───┬───┐    ┌───┬───┐    ┌───┬───┐
│ A │ ●─┼──> │ B │ ●─┼──> │ C │ ∅ │
└───┴───┘    └───┴───┘    └───┴───┘

只能单向走：A → B → C
```

---

#### (2) 双向链表

双向链表中每个节点同时保存前驱指针和后继指针，因此既可以向后访问，也可以向前访问。

特点是删除某个已知节点时非常方便，只需要让它的前驱和后继互相连接，不需要像单链表那样先找前驱。插入新节点时，需要同时维护前驱和后继两个方向，指针修改的顺序容易出错，是常考的细节。

双向链表适合需要频繁删除节点、需要访问相邻节点、或者需要同时向两个方向维护关系的场景。

```cpp
     head
      ↓
┌───┬───┬───┐──> ┌───┬───┬───┐──> ┌───┬───┬───┐
│ ∅ │ A │ ● │    │ ● │ B │ ● │    │ ● │ C │ ∅ │
└───┴───┴───┘ <──└───┴───┴───┘ <──└───┴───┴───┘

```

---

#### (3) 单向循环链表

单向循环链表仍然是每个节点只保存后继指针，但最后一个节点不指向空，而是指回头节点，使整个链表形成一个环。

特点是没有真正的“末尾空指针”，从任意节点出发都可以沿着后继指针绕圈遍历。删除当前节点后，要特别注意还能正确移动到下一个节点，否则可能丢失继续遍历的起点。

约瑟夫环是单向循环链表的典型模型：一群人围成环，报数出圈，然后从下一个人继续。

```cpp
        ┌──────────────────────────┐
        ↓                          │
      ┌───┐    ┌───┐    ┌───┐      │
head→ │ A │──→ │ B │──→ │ C │──────┘
      └───┘    └───┘    └───┘

绕圈走：A → B → C → A → B → C → …
```

---

#### (4) 双向循环链表

双向循环链表结合了双向链表和循环链表的特点：每个节点同时有前驱和后继指针，并且头节点的前驱指向尾节点，尾节点的后继指向头节点，首尾相接形成环。

特点是可以双向遍历，同时首尾边界被环结构统一，某些操作不需要单独判断“是否在头部或尾部”。但指针维护比普通双向链表更复杂，插入和删除时要同时保证两个方向和首尾连接都正确。

它适合需要双向访问且首尾操作频繁的场景。

```text
       ┌───────────────────┐
       ↓                   │
     ┌───┐ --> ┌───┐ --> ┌───┐ 
head→│ A │     │ B │     │ C │
     └───┘ <-- └───┘ <-- └───┘
       │                   ↑
       └───────────────────┘

既可 A ⇄ B ⇄ C，也可 A ⇄ C
```

---

### 2\. 按是否带头节点划分

#### （1）不带头节点的链表

不带头节点的链表中，头指针直接指向第一个真实数据节点。

特点是结构直观，第一个节点就是有效数据。但在头部插入或删除时，需要单独修改头指针，边界情况需要特判，代码逻辑不如带头节点统一。

```text
head
 ↓
┌───┐    ┌───┐    ┌───┐
│ A │──→ │ B │──→ │ C │
└───┘    └───┘    └───┘

head 直接指向第一个数据节点 A
```

---

#### （2）带头节点的链表

带头节点的链表在第一个真实数据节点之前增加一个虚拟头节点，也叫哨兵节点。哨兵节点通常不存储有效数据，只用来统一操作。

特点是在头部插入、删除时不再特殊处理，因为真实数据节点前面始终有一个“前驱”。双向链表中还常同时设置头哨兵和尾哨兵，进一步减少边界判断。

带头节点的写法能显著减少“删头”“插头”等特判，是值得掌握的技巧。

```text
head
 ↓
┌─────┐    ┌───┐    ┌───┐    ┌───┐
│ 哨兵 │──→ │ A │──→ │ B │──→ │ C │
└─────┘    └───┘    └───┘    └───┘

哨兵不存有效数据，只负责统一头部操作
```

---

### 3\. 按实现方式划分

#### （1）动态链表

动态链表在程序运行过程中动态申请节点空间，节点之间通过指针连接。

特点是概念直观，链表长度可以随操作动态变化。但频繁申请和释放内存有额外开销，也容易出现内存泄漏、指针悬挂等问题。

```text
节点在内存中位置分散：

    [A] ──→ [B] ──→ [C]
     ↑        ↑        ↑
   内存某处  另一处   又一处

物理上不一定连续，靠指针找到下一个节点
```

---

#### （2） 静态链表（数组模拟）

静态链表用数组下标代替内存地址，用“下一个节点的下标”表示指针关系，而不是真正申请节点。

特点是避免动态内存管理风险，代码简洁、常数较小、便于调试。需要理解：数组下标在这里扮演“指针”的角色，逻辑上仍然是链表。

```text
下标 i    :   0     1     2     3
data[i]   :   —     A     B     C
next[i]   :   —     2     3     0

head = 1

链接关系：下标 1 → 下标 2 → 下标 3 → 结束

逻辑上：
head = 1

[1: A] ──→ [2: B] ──→ [3: C] ──→ 空

节点在数组中，靠“下一个下标”串成链
```

---

## 四、STL 模板：`std::list`

在信奥中，如果不需要对链表做非常精细的底层控制，直接使用 C++ STL 提供的 `std::list` 是编码速度最快的方式。`list` 的底层就是**带哨兵节点的双向循环链表**，它不支持随机访问，但任意位置的插入和删除都是 (O(1))。

### 1\. 核心接口

```cpp
#include <list>

list<int> L;                    // 空链表
list<int>::iterator it;         // 双向迭代器

L.push_back(x);                 // 尾部插入 O(1)
L.push_front(x);                // 头部插入 O(1)
L.pop_back();                   // 删除尾部 O(1)
L.pop_front();                  // 删除头部 O(1)

it = L.insert(pos, x);          // 在迭代器 pos 之前插入 x，返回新节点迭代器
it = L.erase(pos);              // 删除 pos 所指节点，返回下一个有效迭代器

L.begin();                      // 第一个真实节点
L.end();                        // 哨兵节点
--L.end();                      // 最后一个真实节点
L.empty();                      // 链表判空：空返回true，非空返回false
L.size();                       // 链表元素个数
L.clear();                      // 清空链表
```

**迭代器特性**：`list` 的迭代器是**双向迭代器**，只能 `++it`、`--it`，**不能** `it + k`、`it2 - it1`，也不能用 `<` 比较，只能用 `!=` 或 `==`。

**迭代器失效**：`insert` 不会使任何已有迭代器失效；`erase(pos)` 只使指向被删节点的迭代器失效，其他迭代器仍然有效。被 `erase` 删除后，应当用它的返回值更新迭代器。

### 2．手写双向循环链表

下面用节点指针模拟 `list` 的核心结构。`tail` 是尾哨兵，同时也是循环链表的连接点：

```text
tail ⇄ 第一个真实节点 ⇄ ... ⇄ 最后一个真实节点 ⇄ tail
```

-   `begin()` 返回第一个真实节点；空链表时返回 `tail`；
-   `end()` 返回尾哨兵 `tail`；
-   `insert(it, val)` 在 `it` 前插入；
-   `erase(it)` 删除 `it`，并返回下一个节点。

```cpp
/*
手写链表
仿写 list：带尾哨兵的双向循环链表
*/

struct Node {
    int data;
    Node *pre;
    Node *nxt;
};

struct Link {
    Node *tail;   // 尾哨兵
    int total;

    Link() {
        tail = new Node;
        tail->nxt = tail;
        tail->pre = tail;
        total = 0;
    }

    ~Link() {
        while (!empty()) {
            pop_front();
        }
        delete tail;
    }

    Node *begin() {
        return tail->nxt;
    }

    Node *end() {
        return tail;
    }

    bool empty() {
        return tail->nxt == tail;
    }

    int size() {
        return total;
    }

    // 在 it 前插入 val，返回新节点
    Node *insert(Node *it, int val) {
        Node *temp = new Node;
        temp->data = val;

        temp->pre = it->pre;
        temp->nxt = it;
        it->pre->nxt = temp;
        it->pre = temp;

        total++;
        return temp;
    }

    // 删除 it，返回被删除节点的下一个节点
    Node *erase(Node *it) {
        Node *nxt = it->nxt;

        it->pre->nxt = it->nxt;
        it->nxt->pre = it->pre;

        delete it;
        total--;
        return nxt;
    }

    void push_back(int val) {
        insert(tail, val);
    }

    void push_front(int val) {
        insert(tail->nxt, val);
    }

    // 调用前要求链表非空
    void pop_back() {
        erase(tail->pre);
    }

    // 调用前要求链表非空
    void pop_front() {
        erase(tail->nxt);
    }
};
```

手写链表中，`Node *` 的作用与 `list<int>::iterator` 类似，都是“定位某个节点的位置”。插入和删除时只需要修改该节点附近的连接关系。

## 五、例题一：P1814 盲打——遍历与 `insert`

### 1．题意简化

输入一串字符：

-   普通字符：在当前光标位置输入；
-   `[`：相当于按下 `Home`，光标移到文本开头；
-   `]`：相当于按下 `End`，光标移到文本末尾。

输出最终文本。

例如：

```text
输入：This_is_a_[Beiju]_text
输出：BeijuThis_is_a__text
```

题目中的字符串长度可达 `100000`，直接用普通数组或 `string` 在中间、开头插入会反复搬移字符，最坏可达 $O(n^2)$。

### 2．核心状态

设：

```cpp
list<char> ls;
list<char>::iterator it;
```

其中：

-   `ls`：当前已经输入的文本；
-   `it`：当前光标位置，表示“下一个字符应插入到 `it` 的前面”。

初始时链表为空：

```cpp
it = ls.begin();
```

由于空链表中 `begin()` 与 `end()` 相同，仍可作为插入位置。

### 3．操作规则

| 输入字符 | 操作 | 含义 |
| --- | --- | --- |
| `[` | `it = ls.begin();` | 光标移到开头 |
| `]` | `it = ls.end();` | 光标移到末尾 |
| 普通字符 `c` | `ls.insert(it, c);` | 在光标前插入 `c` |

重点：`insert(it, c)` 会在 `it` **之前**插入字符，原来的 `it` 仍然指向原节点。

因此，光标在开头时连续输入 `B`、`e`、`i`、`j`：

```text
初始：This_is_a__text
光标：^

插入 B：BThis_is_a__text
插入 e：BeThis_is_a__text
插入 i：BeiThis_is_a__text
插入 j：BeijThis_is_a__text
```

这里不能写成：

```cpp
it = ls.insert(it, c);
```

否则下一次仍在刚插入字符的前面插入，连续输入会反序。

### 4．参考代码

```cpp
/*
P1814 盲打
*/
#include <iostream>
#include <string>
#include <list>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;

    while (cin >> s) {
        list<char> ls;
        list<char>::iterator it = ls.begin();

        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] == '[') {
                it = ls.begin();
            } else if (s[i] == ']') {
                it = ls.end();
            } else {
                // 在当前光标位置前插入字符
                // 不接收返回值，原来的 it 继续表示光标位置
                ls.insert(it, s[i]);
            }
        }

        for (char c : ls) {
            cout << c;
        }
        cout << '\n';
    }

    return 0;
}
```

### 5．复杂度分析

设一行字符串长度为 $n$：

-   遍历输入：$O(n)$；
-   每次 `insert`：$O(1)$；
-   最后遍历输出：$O(n)$。

总时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

### 6．易错点

-   `insert(pos, x)` 是在 `pos` **前面**插入；
-   `end()` 不是最后一个字符，而是尾哨兵位置；在 `end()` 前插入就是尾插；
-   `list` 不支持下标访问，不能写 `ls[i]`；
-   连续在同一光标位置输入时，不应把 `insert` 的返回值赋回 `it`。

## 六、例题二：P1799 约瑟夫问题——遍历与 `erase`

### 1．题意简化

有 `n` 个人围成一圈，从第一个人开始报数，报到第 `m` 个的人出圈；从下一个人重新报数，直到所有人都出圈。输出出圈顺序。

例如：

```text
n = 10，m = 3
输出：3 6 9 2 7 1 8 5 10 4
```

### 2．用 `list` 模拟环

先将编号 `1 ~ n` 按顺序放入链表：

```cpp
for (int i = 1; i <= n; i++) {
    ls.push_back(i);
}
```

`list` 本身不是循环链表，但可以在迭代器走到 `end()` 时手动回到 `begin()`，达到“绕圈”的效果。

设：

```cpp
auto pos = ls.begin();
```

`pos` 表示当前正在报数的人。

### 3．删除后的迭代器处理

```cpp
pos = ls.erase(pos);
```

`erase(pos)` 会：

1.  删除 `pos` 指向的人；
2.  返回被删位置的下一个有效迭代器。

如果删除的是最后一个人，返回值是 `ls.end()`。此时应回到开头：

```cpp
if (pos == ls.end()) {
    pos = ls.begin();
}
```

注意：不能对 `end()` 执行 `++pos`，因为 `end()` 不指向真实节点，继续自增是未定义行为。

### 4．参考代码

```cpp
/*
P1799 约瑟夫问题
*/
#include <iostream>
#include <list>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    list<int> ls;

    // 初始站成一圈
    for (int i = 1; i <= n; i++) {
        ls.push_back(i);
    }

    int num = 0;
    auto pos = ls.begin();

    while (!ls.empty()) {
        num++;

        if (num == m) {
            cout << *pos << ' ';
            num = 0;

            // 删除当前人，返回下一个位置
            pos = ls.erase(pos);

            // 到达尾哨兵后，回到第一个人
            if (pos == ls.end() && !ls.empty()) {
                pos = ls.begin();
            }
        } else {
            pos++;

            // 普通移动到末尾后，也要绕回开头
            if (pos == ls.end()) {
                pos = ls.begin();
            }
        }
    }

    return 0;
}
```

### 5．过程示例

以 `n = 5，m = 3` 为例：

```text
初始：1 2 3 4 5
报到 3，删除 3：1 2 4 5
从 4 开始报数，删除 1：2 4 5
从 2 开始报数，删除 5：2 4
从 2 开始报数，删除 2：4
最后删除 4
```

出圈顺序：

```text
3 1 5 2 4
```

### 6．复杂度分析

每轮只进行常数次迭代器移动或删除：

-   建表：$O(n)$；
-   报数与删除：共处理 `n` 人。

时间复杂度为 $O(n \times m)$，这里的报数过程每走一步都要移动一次。题目范围较小，`n,m ≤ 100`，可以直接模拟。

`erase` 本身是 $O(1)$，但它不能消除“从一个人走到下一个人并报数”的次数。

空间复杂度为 $O(n)$。

### 7．易错点

-   删除前要先输出 `*pos`，删除后原迭代器失效；
-   必须接住 `erase` 的返回值；
-   链表为空时不能使用 `begin()`、解引用迭代器；
-   `pos == end()` 时应写 `pos = begin()`，不能写 `pos++`（虽然实际也可以运行，在GUN C++中，对end()进行++操作属于未定义行为）；
-   本题模拟的是“人数较小”的约瑟夫过程。若 `n` 很大、只要求最后剩下的人，应使用约瑟夫递推，而不是逐个删除。

## 七、应用：P1798 队列安排

### 1．题意简化

编号 `1 ~ n` 的同学依次进队：

-   1 号先入队；
-   对于第 `i` 个同学，给出一个已在队中的同学 `k`；
-   `p = 0`：将 `i` 插入到 `k` 左边；
-   `p = 1`：将 `i` 插入到 `k` 右边；
-   最后删除若干指定同学，重复删除同一人时忽略。

数据范围：

```text
n, m ≤ 100000
```

如果每次都从队头查找编号为 `k` 的同学，单次查找 $O(n)$，总复杂度会达到 $O(n^2)$。

关键是：**按编号记录每个同学当前所在节点的位置。**

---

### 2．写法一：迭代器数组 + `list`

#### （1）核心思想

```cpp
list<int>::iterator pos[N];
```

`pos[i]` 记录编号为 `i` 的同学在链表中的位置。

这样，给出 `k` 后可以在 $O(1)$ 时间得到：

```cpp
auto it = pos[k];
```

再用 `insert` 在其左边或右边插入新同学。

删除 `x` 后：

```cpp
ls.erase(pos[x]);
pos[x] = ls.end();
```

这里将 `pos[x] == ls.end()` 作为“该同学已经删除”的标记。

#### （2）插入规则

插入到 `k` 左边：

```cpp
pos[i] = ls.insert(pos[k], i);
```

插入到 `k` 右边：

```cpp
auto it = pos[k];
it++;
pos[i] = ls.insert(it, i);
```

若 `k` 已经是最后一个人，则 `it++` 后恰好等于 `ls.end()`，在 `end()` 前插入就是尾插，不需要特判。

#### （3）参考代码

```cpp
/*
P1798 队列安排
list + 迭代器数组
*/
#include <iostream>
#include <list>
using namespace std;

const int N = 100000 + 5;

int n, m;
list<int>::iterator pos[N];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n;

    list<int> ls;

    // 先全部设为 end()，表示当前位置无有效节点
    for (int i = 1; i <= n; i++) {
        pos[i] = ls.end();
    }

    // 1 号入列
    ls.push_back(1);
    pos[1] = ls.begin();

    // 2 ~ n 依次入列
    for (int i = 2; i <= n; i++) {
        int k, p;
        cin >> k >> p;

        auto it = pos[k];

        if (p == 0) {
            // 插入到 k 的左边
            pos[i] = ls.insert(it, i);
        } else {
            // 插入到 k 的右边
            it++;
            pos[i] = ls.insert(it, i);
        }
    }

    // 删除元素
    cin >> m;

    while (m--) {
        int x;
        cin >> x;

        if (pos[x] == ls.end()) {
            continue;
        }

        ls.erase(pos[x]);
        pos[x] = ls.end();
    }

    bool first = true;

    for (int v : ls) {
        if (!first) {
            cout << ' ';
        }
        cout << v;
        first = false;
    }
    cout << '\n';

    return 0;
}
```

#### （4）复杂度分析

-   每次根据 `pos[k]` 定位：$O(1)$；
-   `insert`、`erase`：$O(1)$；
-   最后输出：$O(n)$。

总时间复杂度为 $O(n+m)$，空间复杂度为 $O(n)$。

### 3．写法二：静态数组模拟双向循环链表

当每个节点的编号就是 `1 ~ n` 时，不必额外建立节点结构，可以直接让“编号”充当数组下标。

设：

```cpp
L[i]：i 左边相邻的同学编号
R[i]：i 右边相邻的同学编号
```

并令 `0` 为哨兵节点：

```text
R[0]：队首同学
L[0]：队尾同学
```

逻辑关系是一个双向循环链表：

```text
0 ⇄ 队首 ⇄ ... ⇄ 队尾 ⇄ 0
```

因此，插入队首、插入队尾、删除首尾都不需要单独分类。

#### （1）在 `k` 左边插入 `i`

原来局部关系：

```text
L[k] ⇄ k
```

插入后：

```text
L[k] ⇄ i ⇄ k
```

对应代码：

```cpp
L[i] = L[k];
R[i] = k;
R[L[k]] = i;
L[k] = i;
```

#### （2）在 `k` 右边插入 `i`

原来局部关系：

```text
k ⇄ R[k]
```

插入后：

```text
k ⇄ i ⇄ R[k]
```

对应代码：

```cpp
L[i] = k;
R[i] = R[k];
L[R[k]] = i;
R[k] = i;
```

#### （3）删除 `x`

让 `x` 的左右邻居直接相连：

```cpp
R[L[x]] = R[x];
L[R[x]] = L[x];
```

再把 `x` 标记为已删除：

```cpp
L[x] = -1;
R[x] = -1;
```

#### （4）参考代码

```cpp
/*
P1798 队列安排
数组模拟双向循环链表
*/
#include <iostream>
using namespace std;

const int N = 100000 + 5;

int n, m;
int L[N], R[N];   // L[i]：i 左边节点，R[i]：i 右边节点

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n;

    // 0 是双向循环链表的哨兵节点
    L[0] = 0;
    R[0] = 0;

    // 1 号入列
    L[1] = 0;
    R[1] = 0;
    L[0] = 1;
    R[0] = 1;

    // 2 ~ n 依次入列
    for (int i = 2; i <= n; i++) {
        int k, p;
        cin >> k >> p;

        if (p == 0) {
            // i 插入到 k 的左边
            L[i] = L[k];
            R[i] = k;
            R[L[k]] = i;
            L[k] = i;
        } else {
            // i 插入到 k 的右边
            L[i] = k;
            R[i] = R[k];
            L[R[k]] = i;
            R[k] = i;
        }
    }

    // 删除元素
    cin >> m;

    while (m--) {
        int x;
        cin >> x;

        if (L[x] == -1 || R[x] == -1) {
            continue;
        }

        R[L[x]] = R[x];
        L[R[x]] = L[x];

        // 删除标记
        L[x] = -1;
        R[x] = -1;
    }

    bool first = true;

    // 从队首开始，沿右指针遍历
    for (int cur = R[0]; cur != 0; cur = R[cur]) {
        if (!first) {
            cout << ' ';
        }
        cout << cur;
        first = false;
    }
    cout << '\n';

    return 0;
}
```

#### （5）复杂度分析

每次插入、删除都只修改常数个数组位置：

-   建队：$O(n)$；
-   删除：$O(m)$；
-   输出：$O(n)$。

总时间复杂度为 $O(n+m)$，空间复杂度为 $O(n)$。

---

### 4．两种写法对比

| 方案 | 定位节点 | 插入/删除 | 优点 | 注意点 |
| --- | --- | --- | --- | --- |
| `list` + 迭代器数组 | `pos[i]` | $O(1)$ | 写法直观，适合快速实现 | 迭代器不能失效后继续使用 |
| 静态数组模拟链表 | 节点编号就是下标 | $O(1)$ | 常数小、可控性强、不依赖 STL | 必须正确维护左右连接关系 |

本题中，两个方案都能通过。若题目节点编号固定且操作只有插入、删除、遍历，静态数组模拟链表通常更稳定；若节点不是固定编号，或者需要快速表达复杂的链表操作，`list` 写法更直接。

## 八、链表操作的复杂度与常见错误

### 1．常见操作复杂度

| 操作 | 数组 | `list` / 已知节点的链表 |
| --- | --: | --: |
| 按下标访问第 `k` 个元素 | $O(1)$ | $O(k)$ |
| 查找指定值 | $O(n)$ | $O(n)$ |
| 已知位置插入 | $O(n)$ | $O(1)$ |
| 已知位置删除 | $O(n)$ | $O(1)$ |
| 遍历全部元素 | $O(n)$ | $O(n)$ |

链表的优势是“**已经拿到节点位置之后**”的插入和删除，而不是任意查找都很快。

### 2．常见错误

1.  **把 `list` 当数组使用**
    
    ```cpp
    ls[i];       // 错误
    it + 3;      // 错误
    ```
    
    `list` 只能通过迭代器一步一步移动。
    
2.  **解引用 `end()`**
    
    ```cpp
    cout << *ls.end();   // 错误
    ```
    
    `end()` 是尾哨兵之后的位置，不保存元素。
    
3.  **删除后继续使用旧迭代器**
    
    ```cpp
    ls.erase(it);
    it++;                // 错误：it 已失效
    ```
    
    应写为：
    
    ```cpp
    it = ls.erase(it);
    ```
    
4.  **循环链表模拟时忘记绕回开头**
    
    `list` 自身不是循环结构，到达 `end()` 后需要显式回到 `begin()`。
    
5.  **静态链表只改一边**
    
    双向链表中，插入和删除都要同时维护左右两边。只修改 `L` 或只修改 `R` 会破坏链表。
    
6.  **删除同一节点两次**
    
    可以使用“迭代器是否为 `end()`”或“左右指针是否为 `-1`”作为删除标记。

## 九、本课总结

### 1．核心结论

-   链表适合频繁插入、删除，但不擅长按下标随机访问；
-   `std::list` 是双向链表，迭代器只能前后移动；
-   `insert(pos, x)` 在 `pos` 前插入，`erase(pos)` 返回下一个有效位置；
-   当需要按编号快速找到节点时，可以额外保存迭代器数组；
-   当节点编号固定时，可用数组 `L[]`、`R[]` 模拟双向链表；
-   哨兵节点能够统一首尾插入、删除，减少边界特判。

### 2．链表的适用场景

判断一道题是否适合链表时，先问两个问题：

1.  是否存在大量“已知位置”的插入、删除操作？
2.  是否需要频繁按下标随机访问？

前者明显、后者较少时，链表通常是合适的结构。
