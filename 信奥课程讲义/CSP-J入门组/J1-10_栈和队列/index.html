    第 10 课 栈和队列

    栈、队列、数组模拟与经典题型

    学习目标：理解栈和队列的定义、性质及操作顺序；掌握使用数组模拟栈、普通队列和循环队列；会使用 stack 与 queue 模板；能够解决出栈序列检查、括号匹配、后缀表达式、队列模拟和约瑟夫环等 CSP-J 范围内的基础问题。

    一、栈的概念、性质和操作

    1．栈是什么

    栈是一种只能在一端进行插入和删除的数据结构。

    进行插入和删除的一端叫作栈顶，另一端叫作栈底。

    栈的特点是：

    后进先出，即 LIFO（Last In, First Out）。

    例如，依次把 1、2、3 放入栈中：

    入栈 1：1
入栈 2：1 2
入栈 3：1 2 3

    此时只能先取出 3，再取出 2，最后取出 1。

    2．栈的基本操作

    操作 含义
    push(x) 把 x 放入栈顶
    pop() 删除栈顶元素
    top() 查看栈顶元素，不删除
    empty() 判断栈是否为空
    size() 返回栈中元素个数

    栈只能操作栈顶，不能直接访问中间元素。

    3．栈的状态变化

    初始：空

push(10)：10
push(20)：10 20
push(30)：10 20 30

top()：30
pop()：10 20
top()：20

    调用 pop() 前必须保证栈不为空：

    if (!st.empty()) {
    st.pop();
}

    4．栈的典型使用场景

    栈适合处理具有“最近一次进入的数据先处理”特点的问题：

    • 检查括号是否匹配；
    • 检查一个出栈序列是否合法；
    • 计算后缀表达式；
    • 模拟撤销操作；
    • 深度优先搜索中的路径状态；
    • 递归调用过程中的调用栈。

    二、使用 stack 模板

    1．基本写法

    C++ 标准库中的栈类型是：

    #include <stack>
using namespace std;

stack<int> st;

    常见类型：

    stack<int> st1;
stack<long long> st2;
stack<char> st3;

    2．基本操作代码

    #include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> st;

    st.push(10);
    st.push(20);
    st.push(30);

    cout << st.top() << '\n';  // 30

    st.pop();

    cout << st.top() << '\n';  // 20
    cout << st.size() << '\n'; // 2

    return 0;
}

    3．操作复杂度

    操作 复杂度
    push \(O(1)\)
    pop \(O(1)\)
    top \(O(1)\)
    empty \(O(1)\)
    size \(O(1)\)

    4．常见错误

    st.pop();

    pop() 只负责删除元素，不返回被删除的值。

    如果需要先取得栈顶元素，应写：

    int x = st.top();
st.pop();

    不能对空栈调用：

    st.top();
st.pop();

    否则程序行为不正确。

    三、数组模拟栈

    1．数组模拟的思想

    可以使用数组保存栈中元素，再用一个变量表示栈顶位置。

    常见约定：

    top = 0：栈为空
栈中元素存放在 stk[1] 到 stk[top]

    操作过程：

    • 入栈：stk[++top] = x
    • 出栈：top--
    • 栈顶：stk[top]

    2．基本模板

    const int N = 100000 + 5;
int stk[N];
int top = 0;

// 入栈
void push(int x) {
    top++;
    stk[top] = x;
}

// 查看栈顶
int getTop() {
    return stk[top];
}

// 出栈
void pop() {
    top--;
}

// 判空
bool empty() {
    return top == 0;
}

    更完整的使用示例：

    #include <iostream>
using namespace std;

const int N = 100000 + 5;
int stk[N];
int top = 0;

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        stk[++top] = x;
    }

    while (top > 0) {
        cout << stk[top] << ' ';
        top--;
    }

    cout << '\n';
    return 0;
}

    输入：

    5
1 2 3 4 5

    输出：

    5 4 3 2 1

    3．数组模拟栈的边界

    入栈前要确认栈没有满：

    if (top < N - 1) {
    stk[++top] = x;
}

    出栈或查看栈顶前要确认栈不为空：

    if (top > 0) {
    top--;
}

    数组模拟栈本质上是用：

    数组 + 栈顶下标

    实现后进先出。

    四、题型一：出栈序列检查

    1．问题模型

    有 n 个数字，入栈顺序固定为：

    1、2、3、……、n

    给定一个出栈顺序，判断它是否合法。

    例如：

    入栈顺序：1 2 3 4 5
出栈顺序：4 5 3 2 1

    过程：

    入栈 1、2、3、4，弹出 4
入栈 5，弹出 5
弹出 3、2、1

    所以该序列合法。

    2．方法一：尽量出栈

    依次处理入栈数字 x：

    1. 入栈顺序固定为 1, 2, ..., n。
    2. 按顺序枚举每个入栈元素：
      1. 先将当前元素入栈；
      2. 如果栈顶元素等于当前期望出栈的元素，就将它出栈；
      3. 出栈后继续检查新的栈顶，直到栈顶不等于期望元素，或者栈为空。
    3. 所有入栈元素处理完后：
      1. 如果栈为空，说明给出的出栈顺序合法；
      2. 如果栈不为空，说明有元素无法按照给定顺序出栈，序列不合法。
    #include<iostream>
using namespace std;

const int N=1e5+5;
int n;
int a[N],b[N];

int stk[N];
int top=0;

int main(){
    cin>>n;
    for(int i=1;i<=n;i++) a[i]=i;//入栈序列
    for(int i=1;i<=n;i++) cin>>b[i];//出栈序列

    for(int in=1,out=1;in<=n;in++){
        //入栈一个元素
        stk[++top]=a[in];
        //能出栈则出栈，直到不能出栈
        while(top>0 && stk[top]==b[out]){
            top--;
            out++;
        }
    }
    //检查栈是否为空
    if(top>0) cout<<"Invalid";
    else cout<<"Valid";
    return 0;
}

    3．方法二：尽量入栈

    依次处理出栈数字 x：

    1. 入栈顺序固定为 1, 2, ..., n。
    2. 按顺序枚举给出的出栈序列 b。
    3. 对于当前需要出栈的元素 b[out]：
      1. 如果栈为空，或者栈顶元素不是 b[out]，就继续把还未入栈的元素压入栈；
      2. 如果所有元素都已经入栈，栈顶仍然无法匹配 b[out]，说明该出栈序列不合法，输出 Invalid；
      3. 如果栈顶等于 b[out]，就将它出栈，继续检查下一个出栈元素。
    4. 如果所有出栈元素都能顺利匹配，说明序列合法，输出 Valid。
    #include<iostream>
using namespace std;

const int N=1e5+5;
int n;
int a[N],b[N];
int st[N];
int top=0;

int main(){
    //两个序列 
    cin>>n;
    for(int i=1;i<=n;i++) a[i]=i;
    for(int i=1;i<=n;i++) cin>>b[i]; 
    //出栈序列判断：能入则入，相等则出 
    for(int in=1,out=1;out<=n;out++){
        //若栈顶不等于出栈序列,则入栈
        while(top==0 || st[top]!=b[out]){
            if(in>n){
                cout<<"Invalid";
                return 0;
            }
            st[++top]=a[in++];
        }
        //出栈
        top--; 
    }
    cout<<"Valid"; 
    return 0;
}

    4．复杂度

    每个数字最多入栈一次、出栈一次，因此：

    \[ O(n) \]

    栈最多保存 n 个数字，空间复杂度为：

    \[ O(n) \]

    五、题型二：括号匹配

    1．问题模型

    给定一个只包含圆括号 ( 和 ) 的字符串，判断括号是否匹配。

    例如：

    (()())

    是合法的。

    ())(

    是不合法的。

    2．括号匹配的两个条件

    一个括号序列合法，必须满足：

    1. 从左到右扫描时，任意前缀中右括号数量不能超过左括号数量；
    2. 扫描结束后，左括号和右括号数量相等。

    使用栈时：

    • 遇到左括号 (：入栈；
    • 遇到右括号 )：必须弹出一个左括号；
    • 如果右括号出现时栈为空：不合法；
    • 扫描结束后栈不为空：不合法。

    3．参考代码

    #include<iostream>
#include<stack>
using namespace std;

int main(){
    string s;
    cin>>s;

    stack<char> stk;
    for(int i=0;i<s.size();i++){
        if(s[i]=='('){
            //左括号，则入栈
            stk.push(s[i]);
        }else{
            //右括号，则匹配
            if(!stk.empty()){
                stk.pop();
            }else{
                cout<<"No";
                return 0;
            }
        }
    }
    //检查：栈空则正确，否则错误
    if(stk.empty()) cout<<"Yes";
    else cout<<"No";
    return 0;
}

    六、题型三：后缀表达式计算

    1．什么是后缀表达式

    普通表达式：

    3 * (5 - 2) + 7

    对应的后缀表达式可以写成：

    3 5 2 - * 7 +

    后缀表达式的特点：

    • 不需要括号；
    • 不需要考虑运算符优先级；
    • 运算符写在两个操作数之后；
    • 从左到右扫描即可计算。

    2．计算规则

    从左到右扫描每个元素：

    • 遇到数字，则入栈；
    • 遇到运算符，则计算：
      • 弹出栈顶两个值：
        1. 弹出右操作数 b；
        2. 弹出左操作数 a；
      • 计算结果再入栈：
        1. 计算 a op b；
    • 最终：栈顶即为所求值。

    注意两个操作数的顺序：

    b = st.top(); st.pop();
a = st.top(); st.pop();
result = a - b;

    不能写反。

    3．简化题面

    输入一个以空格分隔的后缀表达式，表达式只包含：

    • 非负整数；
    • +、-、*、/ 四种运算符。

    例如：

    3 5 2 - * 7 +

    输出表达式的值：

    16

    4．参考代码

    #include<iostream>
using namespace std;

const int N=1005;
int stk[N];
int top=0;

int main(){
    string s;
    cin>>s;
    int num=0;
    for(int i=0;i<s.size();i++){
        if(s[i]=='@') break;
        //遇到数字则入栈
        if('0'<=s[i] && s[i]<='9'){
            num=num*10+(s[i]-'0');
        }else if(s[i]=='.'){
            stk[++top]=num;
            num=0;
        }else{
            //遇到符号则计算
            //（1）弹出栈顶两个值
            int R=stk[top--];
            int L=stk[top--];
            // (2) 计算结果再入栈
            switch (s[i]) {
                case '+': stk[++top]=L+R;break;
                case '-': stk[++top]=L-R;break;
                case '*': stk[++top]=L*R;break;
                case '/': stk[++top]=L/R;break;
            }   
        }
    }
    //最后：栈顶即为所求值
    cout<<stk[top];
    return 0;
}

    5．表达式合法性的基本检查

    如果题目不保证表达式合法，还需要检查：

    • 运算符出现时栈中是否至少有两个数；
    • 除法的除数是否为 0；
    • 表达式结束后栈中是否只剩一个结果。

    七、队列的概念、性质和操作

    1．队列是什么

    队列是一种在一端插入、另一端删除的数据结构。

    • 插入的一端叫作队尾；
    • 删除的一端叫作队头。

    队列的特点是：

    先进先出，即 FIFO（First In, First Out）。

    例如依次进入队列：

    1、2、3

    离开顺序一定是：

    1、2、3

    2．队列的基本操作

    操作 含义
    push(x) 把 x 放入队尾
    pop() 删除队头元素
    front() 查看队头元素，不删除
    back() 查看队尾元素，不删除
    empty() 判断队列是否为空
    size() 返回队列元素个数

    调用 front() 或 pop() 前，要确认队列不为空。

    3．队列的典型使用场景

    队列适合处理按到达顺序依次处理的问题：

    • 任务排队；
    • 广度优先搜索；
    • 模拟窗口或缓存；
    • 操作队列；
    • 约瑟夫环；
    • 机器翻译中的内存淘汰；
    • 生产者和消费者模型。

    八、使用 queue 模板

    1．基本写法

    #include <queue>
using namespace std;

queue<int> q;

    常见操作：

    q.push(10);
q.push(20);

cout << q.front() << '\n';  // 10
cout << q.back() << '\n';   // 20

q.pop();

    与栈一样，pop() 只删除元素，不返回元素值。

    正确取出队头：

    int x = q.front();
q.pop();

    2．操作复杂度

    操作 复杂度
    push \(O(1)\)
    pop \(O(1)\)
    front \(O(1)\)
    back \(O(1)\)
    empty \(O(1)\)
    size \(O(1)\)

    九、数组模拟普通队列

    1．基本模型

    使用数组保存元素，并用两个下标：

    • head：指向队头；
    • tail：指向下一个可插入位置。

    约定：

    队列中的元素存放在 q[head] 到 q[tail - 1]

    初始状态：

    head = 0;
tail = 0;

    操作：

    • 入队：q[tail++] = x
    • 查看队头：q[head]
    • 出队：head++
    • 判空：head == tail

    2．基本模板

    const int N = 100000 + 5;
int q[N];
int head = 0;
int tail = 0;

void push(int x) {
    q[tail++] = x;
}

int front() {
    return q[head];
}

void pop() {
    head++;
}

bool empty() {
    return head == tail;
}

    3．普通队列的特点

    普通数组队列中，出队只移动 head，不会把剩余元素整体向前搬移，因此出队仍然是 \(O(1)\)。

    但是，tail 只会不断增加。即使前面已经有很多空位置，也不会自动重复使用，因此适合：

    • 操作次数有限；
    • 可以提前估计最大入队次数；
    • 或者只需要单向处理一次的场景。

    十、数组模拟循环队列

    1．为什么需要循环队列

    普通队列可能出现：

    前面有空位，但 tail 已经到达数组末尾

    循环队列让下标到达数组末尾后回到开头，重复利用已经出队的位置。

    下标移动公式：

    index = (index + 1) % capacity;

    2．一种清晰的约定

    使用长度为 N 的数组，但只存放最多 N - 1 个元素：

    • head：队头位置；
    • tail：下一个入队位置；
    • head == tail：队列为空；
    • (tail + 1) % N == head：队列已满。

    这样通过空出一个位置区分“空”和“满”。

    3．循环队列模板

    const int N = 100005;
int q[N];
int head = 0;
int tail = 0;

bool empty() {
    return head == tail;
}

bool full() {
    return (tail + 1) % N == head;
}

void push(int x) {
    if (full()) {
        return;
    }

    q[tail] = x;
    tail = (tail + 1) % N;
}

void pop() {
    if (empty()) {
        return;
    }

    head = (head + 1) % N;
}

int front() {
    return q[head];
}

    4．循环队列的元素个数

    在上述约定下，当前元素个数为：

    int size() {
    return (tail - head + N) % N;
}

    加上 N 是为了避免 tail - head 为负数。

    5．循环队列的另一种写法

    也可以额外记录 count：

    int q[N];
int head = 0;
int tail = 0;
int count = 0;

    判断：

    empty: count == 0
full:  count == N

    这种写法可以使用数组中的全部位置，但每次入队和出队都必须同步修改 count。两种写法都可以，关键是整个程序使用同一种约定。

    十一、题型四：队列模拟

    1．问题模型

    有一个初始为空的队列，执行若干次操作：

    1 x：把 x 加入队尾
2：弹出队头并输出

    如果执行 2 时队列为空，输出 empty。

    2．思路

    使用先进先出队列：

    • 操作 1 x：push(x)；
    • 操作 2：
      • 队列非空，输出 front() 并 pop()；
      • 队列为空，输出 empty。

    3．参考代码

    #include <iostream>
#include <queue>
using namespace std;

int main() {
    int n;
    cin >> n;

    queue<int> q;

    while (n--) {
        int type;
        cin >> type;

        if (type == 1) {
            int x;
            cin >> x;
            q.push(x);
        } else {
            if (q.empty()) {
                cout << "empty\n";
            } else {
                cout << q.front() << '\n';
                q.pop();
            }
        }
    }

    return 0;
}

    每个操作只进行常数次队列操作，时间复杂度为：

    \[ O(n) \]

    空间复杂度为：

    \[ O(n) \]

    4．数组模拟写法

    const int N = 100000 + 5;
int q[N];
int head = 0;
int tail = 0;

for (int i = 0; i < n; i++) {
    int type;
    cin >> type;

    if (type == 1) {
        int x;
        cin >> x;
        q[tail++] = x;
    } else {
        if (head == tail) {
            cout << "empty\n";
        } else {
            cout << q[head++] << '\n';
        }
    }
}

    当所有元素只从左向右进入、从左向右离开，且最大操作数已知时，普通数组队列足够使用。

    十二、题型五：约瑟夫环

    1．问题模型

    有 n 个人围成一圈，从第一个人开始报数：

    • 报到 m 的人出列；
    • 从下一个人重新开始报数；
    • 直到所有人出列。

    要求输出出列顺序。

    例如：

    n = 10，m = 3

    出列顺序为：

    3 6 9 2 7 1 8 5 10 4

    2．队列模拟思路

    把还没有出列的人放入队列：

    1 2 3 4 5 ... n

    重复执行：

    1. 把队头元素移到队尾，表示它报数但没有出列；
    2. 重复 m - 1 次；
    3. 弹出此时的队头，它就是报到 m 的人；
    4. 输出被弹出的编号。

    3．参考代码

    #include<bits/stdc++.h>
using namespace std;

int main(){
    int n,m;
    cin>>n>>m;

    queue<int> q;
    //开始时，先站好一圈
    for(int i=1;i<=n;i++) q.push(i);
    //循环报数
    int num=0;
    while(!q.empty()){
        //报数
        ++num;
        if(num>m) num=1;
        //检查是否出圈
        if(num==m){
            cout<<q.front()<<" ";
            q.pop();
        }else{
            int f=q.front();
            q.pop();
            q.push(f);
        }
    }
    return 0;
}

    4．复杂度

    每次出列前可能需要移动 m - 1 个人，共出列 n 次，因此时间复杂度为：

    \[ O(nm) \]

    空间复杂度为：

    \[ O(n) \]

    当 n、m 较小时，队列模拟简单直接。若数据很大，需要学习约瑟夫问题的数学递推或其他优化方法。

    十三、队列的应用：先进先出的缓存

    1．问题模型

    有一个容量为 M 的内存，依次访问 N 个单词：

    • 如果单词已经在内存中，不需要查词典；
    • 如果不在内存中，需要查词典；
    • 如果内存未满，直接加入；
    • 如果内存已满，删除最早进入内存的单词，再加入新单词。

    这个模型体现了队列的先进先出性质。

    2．简单思路

    需要同时判断：

    1. 单词是否已经在内存中；
    2. 哪个单词最早进入内存。

    可以使用：

    • 队列保存进入顺序；
    • 集合或数组标记当前是否在内存中。

    对于单词编号范围较小的简化版本，可以使用数组标记：

    bool inMemory[1005] = {};

    3．参考代码

    #include<bits/stdc++.h>
using namespace std;

const int N=1005;
int n,m;
int q[N];
int f=1;//指向队首元素
int r=1;//指向队尾元素的下一个

int main(){
    cin>>m>>n;
    int cnt=0;
    for(int i=1;i<=n;i++){
        //输入一个单词
        int word;
        cin>>word;
        //查内存
        bool have=false;
        for(int j=f;j<r;j++){
            if(q[j]==word){
                have=true;
                break;
            }
        }
        //没找到，就要访问外存
        if(have==false){
            if(r-f<m){//内存还有空间，直接入队
                q[r++]=word;
            }else{//内存空间不足，先出队，再入队
                f++;//队首出队
                q[r++]=word;
            }
            cnt++;
        }
    }
    cout<<cnt;
    return 0;
}

    十四、栈和队列的比较

    对比项 栈 队列
    核心原则 后进先出 先进先出
    插入位置 栈顶 队尾
    删除位置 栈顶 队头
    主要操作 push、pop、top push、pop、front
    典型问题 括号、撤销、后缀表达式 排队、广搜、缓存、约瑟夫环
    数组模拟 一个 top head 与 tail
    关键顺序 最近进入的先处理 最早进入的先处理

    记忆方式：

    栈：只看顶部，后进先出
队列：从尾进，从头出，先进先出
