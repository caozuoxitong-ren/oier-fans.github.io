    第 09 课 双指针

    双指针的基本思想、常见类型与经典题型

    学习目标：理解双指针的概念、基本思想和适用条件；掌握对撞指针、快慢指针、滑动窗口、分离指针和多指针的基本结构；理解双指针如何利用有序性、单调性和区间状态减少重复工作；能够分析并实现常见的典型问题。

    一、双指针的概念与基本思想

    1．什么是双指针

    双指针中的“指针”，通常不是 C++ 的指针类型，而是数组、字符串或序列的下标。

    双指针是一类通过设置两个指针在数组、字符串或链表上按规则移动，从而降低时间复杂度、减少嵌套循环的解题技巧。其核心思想是：利用数据的有序性、单调性或区间约束，让两个指针协同遍历，避免盲目枚举所有组合。

    2. 常见类型

    • 左右对撞指针 ：两个指针分别从两端向中间移动，根据当前两指针指向元素的和、大小或约束等，决定移动左指针还是右指针。常用于有序数组、回文判断、两数之和、三数之和、盛水容器等问题。

    • 快慢指针：两个指针同向移动但速度不同，快指针负责探索，慢指针负责维护有效结果或目标位置。常用于链表找环、找中点、删除倒数第 N 个节点，也用于数组去重、移动零等原地操作。

    • 滑动窗口 / 同向双指针：用左右指针维护一个连续区间，通过扩大右边界和收缩左边界来满足条件，右指针负责扩张窗口，左指针负责在条件不满足或需要优化时收缩窗口。常用于子数组、子串问题，如最长无重复子串、最小覆盖子串、满足条件的最短子数组等。

    • 分离双指针 / 多数组双指针：两个指针分别遍历两个数组或链表，按元素大小或匹配关系分别推进指针。常用于归并、求交集、合并有序数组、判断子序列等。

    • 多指针：使用两个以上指针协同遍历，是双指针思想的推广。常见形式包括“固定一个或多个元素 + 双指针”的降维组合，如三数之和、四数之和；也包括多个边界指针进行区间划分，如荷兰国旗问题中的三指针划分；还包括多路归并中每一路各维护一个指针等。多指针的核心仍然是利用有序性、单调性或区间约束减少无效枚举，只是需要同时协调更多指针的移动规则。

    3. 适用场景

    双指针通常适用于以下特征的问题：

    • 数组或字符串具有有序性，或排序后可以利用单调性；
    • 需要寻找满足某种条件的一对元素、一个区间、一个子数组/子串；
    • 需要在原地完成删除、去重、移动、合并等操作；
    • 可以将暴力双重循环优化为线性或近似线性扫描；
    • 链表中的环、中点、倒数节点、相交等问题。

    4. 复杂度特点

    双指针算法通常能将时间复杂度从 (O(n^2)) 优化到 (O(n))；若需要先排序，则整体为 (O(n\log n))。空间复杂度通常为 (O(1))，滑动窗口有时需要哈希表等额外结构。

    5. 解题关键

    使用双指针时要明确三点：

    1. 两个指针分别代表什么：边界、候选位置、快慢角色，还是两个数组的遍历位置；
    2. 指针如何移动：依据当前元素大小、和值、窗口条件或匹配关系；
    3. 为什么这样移动不会漏解：通常依赖有序性、单调性或窗口不变量。

    同时要注意边界条件、重复元素处理、指针相遇/越界条件，以及窗口收缩时机。

    6. 一句话总结

    双指针是一种利用两个指针协同扫描来减少无效枚举的算法思想，常见形式包括左右对撞、快慢指针、滑动窗口和分离双指针；多指针则是其进一步推广，用于多元素组合、区间划分和多路归并等场景。掌握双指针的关键是明确指针含义、移动规则和单调性依据。

    二、对撞指针：找指定和的整数对

    1．问题描述

    给定 n 个互不相同的整数和一个目标值 m，找出数组中和为 m 的整数对。为了使用对撞指针，先将数组从小到大排序。

    例如：

    数组：21 4 5 6 13 65 32 9 23
目标值：28

    排序后：

    4 5 6 9 13 21 23 32 65

    可以找到：

    5 23

    这里将题目简化为：输出找到的数对，因为整数互不相同，所以不用考虑重复问题。

    2．暴力思路

    枚举两个下标 i 和 j：

    for (int i = 1; i <= n; i++) {
    for (int j = i + 1; j <= n; j++) {
        if (a[i] + a[j] == m) {
            // 找到一组答案
        }
    }
}

    这种方法要检查大量下标组合，时间复杂度为：

    \[ O(n^2) \]

    3．排序后的单调性

    排序后设置：

    L = 1，R = n

    当前检查 a[L] + a[R]。

    • 如果和小于 m，说明当前左端点太小，应该增大 L；
    • 如果和大于 m，说明当前右端点太大，应该减小 R；
    • 如果和等于 m，找到一组答案，再继续移动指针。

    当前和小于目标值

    a[L] + a[R] < m

    由于 a[R] 已经是当前右侧最大的数，如果 a[L] 不变，无法通过向左移动右指针使和变大。因此应该让 L++。

    当前和大于目标值

    a[L] + a[R] > m

    由于 a[L] 已经是当前左侧最小的数，如果 a[R] 不变，无法通过向右移动左指针使和变小。因此应该让 R--。

    这就是对撞指针每一步移动的依据。

    4．参考代码

    #include <iostream>
#include <algorithm>
using namespace std;

const int N = 100000 + 5;

int n;
long long a[N];
long long m;

int main() {
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    cin >> m;

    sort(a + 1, a + 1 + n);

    int L = 1;
    int R = n;

    while (L < R) {
        if (a[L] + a[R] < m) {
            L++;
        } else if (a[L] + a[R] == m) {
            cout << a[L] << ' ' << a[R] << '\n';
            L++;
        } else {
            R--;
        }
    }

    return 0;
}

    5．复杂度分析

    排序需要：

    \[ O(n\\log n) \]

    排序后，L 只向右移动，R 只向左移动，扫描过程为：

    \[ O(n) \]

    因此总时间复杂度为：

    \[ O(n\\log n) \]

    额外空间复杂度为：

    \[ O(1) \]

    6．类型特点

    对撞指针与后面的快慢指针不同：

    • 对撞指针从序列两端向中间移动；
    • 每一步根据两个元素的当前结果决定移动哪一侧；
    • 通常依赖数组有序；
    • 主要用于查找数对或两端约束问题。

    三、快慢指针：找两倍的数组

    1．问题描述

    给定一个从小到大排序的正整数数组。对于每个 a[i]，找到最小的 a[j]，满足：

    a[j] >= 2 * a[i]

    如果不存在这样的数，输出 -1。

    例如：

    数组：1 2 5 10

    输出：

    2 5 10 -1

    2．暴力做法

    对于每个 a[i]，都从数组开头重新寻找第一个满足条件的 a[j]。

    #include <iostream>
using namespace std;

const int N = 100000 + 5;

int n;
long long a[N];

int main() {
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    for (int i = 1; i <= n; i++) {
        bool exist = false;
        for (int j = 1; j <= n; j++) {
            if (a[j] >= 2 * a[i]) {
                exist = true;
            }
        }

        if (exist == true) {
            cout << a[j] << ' ';
        } else {
            cout << -1 << ' ';
        }
    }

    return 0;
}

    最坏情况下，每个 i 都要从头扫描数组，时间复杂度为：

    \[ O(n^2) \]

    额外空间复杂度为：

    \[ O(1) \]

    3．快慢指针优化

    观察上述暴力算法，还有优化的空间：

    • 内层循环的“尾巴”可以跳过：找到第一个满足的位置后，可以break，无需继续向后查找；
    • 下一层循环的“开头”可以跳过：因为上一层的 a[i] 的第一个不低于2倍的数字是 a[j]，而下一层的 a[i+1]>=a[i]，那么 a[i+1] 的两倍必然不可能在下标[1,j-1]之间，所以第 i+1 层循环的开头也是可以跳过的。只需要沿用上一层循环的 j ，继续向右查找即可, j 不需要向左移动。
    #include <iostream>
using namespace std;

const int N = 100000 + 5;

int n;
long long a[N];

int main() {
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    int L = 1;
    int R = 1;

    while (L <= n) {
        // 右指针右移，找到第一个成立的位置
        while (R <= n && a[R] < 2 * a[L]) {
            R++;
        }
        // 处理当前点对
        if (R <= n) {
            cout << a[R] << ' ';
        } else {
            cout << -1 << ' ';
        }

        // 左指针右移，继续处理下一个元素
        L++;
    }

    return 0;
}

    4．复杂度分析

    • L 从 1 移动到 n，共移动 n 次；
    • R 最多从 1 移动到 n + 1，不会回退；
    • 每个数组位置最多被 R 检查一次。

    所以时间复杂度为：

    \[ O(n) \]

    额外空间复杂度为：

    \[ O(1) \]

    与暴力做法对比：

    做法 时间复杂度 主要工作
    暴力 \(O(n^2)\) 每个左端点都从头寻找
    快慢指针 \(O(n)\) 右指针保留上次位置，只向右移动

    四、滑动窗口：找子串与邀请朋友

    滑动窗口是同向双指针的一种具体形式。两个指针维护一个连续区间：

    [L,R]

    通常：

    • 右指针负责扩大窗口；
    • 左指针负责收缩窗口；
    • 窗口中维护一个可以快速更新的状态。

    滑动窗口题目常见两种目标：

    1. 找到满足条件的最小窗口；
    2. 找到满足条件的最大窗口。

    1．最小窗口：P1655 找子串

    1.1 问题描述

    给定一个只包含小写字母的字符串 S，求有多少个子串至少包含 k 个不同的字符。

    例如：

    S = abcabc
k = 3

    需要统计所有包含至少 3 种不同字符的连续子串。

    这里的“最小窗口”不是只求一个最短长度，而是：

    对每个固定的左端点，寻找第一个满足条件的最小右端点，然后统计由此产生的所有合法子串。

    1.2 区间状态维护

    维护当前区间 [L,R]：

    cnt[c]：字符 c 在窗口中出现的次数
total：窗口中不同字符的数量

    右指针加入字符：

    cnt[c]++;
if (cnt[c] == 1) {
    total++;
}

    左指针移出字符：

    cnt[c]--;
if (cnt[c] == 0) {
    total--;
}

    1.3 贡献分析

    固定左端点 L，让 R 向右移动，直到：

    total >= k

    此时 [L,R] 是第一个满足条件的窗口。

    由于继续扩大右端点不会减少不同字符的数量，所以：

    [L,R]、[L,R+1]、……、[L,n]

    都满足条件，共有：

    n - R + 1

    个合法子串。

    因此每个 L 的贡献为：

    \[ n-R+1 \]

    1.4 为什么右指针不回退

    当 L 向右移动时，窗口会移除一个字符，不同字符的数量不会因为移除而增加。

    所以新的窗口如果要达到 k 种不同字符，右端点不可能比原来的 R 更靠左，右指针可以从当前位置继续向右寻找。

    1.5 参考代码

    #include <iostream>
#include <cstring>
using namespace std;

const int N = 1000000 + 5;

int n;
int k;
char s[N];

int main() {
    cin >> (s + 1) >> k;
    n = strlen(s + 1);

    long long ans = 0;

    int L = 1;
    int R = 0;

    int cnt[26] = {};
    int total = 0;

    while (L <= n) {
        // 右指针右移，寻找第一个满足条件的右端点
        while (R < n && total < k) {
            R++;

            int c = s[R] - 'a';
            cnt[c]++;

            if (cnt[c] == 1) {
                total++;
            }
        }

        // 处理当前区间 [L,R]
        if (total >= k) {
            // 以 L 为左端点的合法子串数量
            ans += n - R + 1;
        }else{
            // R 已经到最后，仍然不满足条件
            break;
        }

        // 左指针右移，删除 s[L]
        int c = s[L] - 'a';
        cnt[c]--;

        if (cnt[c] == 0) {
            total--;
        }

        L++;
    }

    cout << ans;
    return 0;
}

    1.6 复杂度分析

    L 和 R 都只向右移动，每个字符最多加入窗口一次、移出窗口一次。

    时间复杂度为：

    \[ O(n) \]

    由于字符种类只有 26 种，计数数组的额外空间复杂度为：

    \[ O(1) \]

    2．最大窗口：P1666 邀请朋友

    2.1 问题描述

    有 n 个朋友，每个朋友有两个属性：

    • 金钱值 m；
    • 关系度 s。

    要求邀请的朋友中，任意两个人的金钱差的绝对值不超过 d。

    求能够邀请的朋友关系度总和的最大值。

    2.2 先排序

    按照金钱值 m 从小到大排序。

    排序后，如果当前窗口为 [L,R)，只要：

    a[R].m - a[L].m <= d

    就说明窗口内任意两人的金钱差都不超过 d。

    当 a[R].m - a[L].m > d 时，R 不能继续加入窗口。

    2.3 为什么窗口中的人全部邀请

    题目中每个人的关系度 s 都是非负数。

    因此，对于固定的 L，只要一个朋友在合法窗口内，就把他邀请进来不会使总和变小。

    所以固定 L 时，应当找到能够维持条件的最大窗口。

    2.4 前缀和维护区间状态

    定义：

    pre[i] = a[1].s + a[2].s + ... + a[i].s

    窗口 [L,R) 的关系度总和为：

    pre[R - 1] - pre[L - 1]

    这样计算任意窗口和只需要常数时间。

    2.5 为什么右指针不回退

    当 L 向右移动时，新的左端点金钱值变大，条件：

    a[R].m - a[L].m <= d

    会变得更容易满足。

    因此新的最大合法右端点不会比旧的右端点更靠左，R 可以继续向右移动。

    2.6 参考代码

    #include <iostream>
#include <algorithm>
using namespace std;

const int N = 100000 + 5;

struct Node {
    long long m;
    long long s;
} a[N];

long long pre[N];

bool cmp(Node x, Node y) {
    return x.m < y.m;
}

int main() {
    int n;
    long long d;

    cin >> n >> d;

    for (int i = 1; i <= n; i++) {
        cin >> a[i].m >> a[i].s;
    }

    sort(a + 1, a + 1 + n, cmp);

    // 计算关系度前缀和
    for (int i = 1; i <= n; i++) {
        pre[i] = pre[i - 1] + a[i].s;
    }

    long long ans = 0;

    int L = 1;
    int R = 1;

    while (L <= n) {
        // 右指针右移：找到第一个不满足条件的位置
        while (R <= n && a[R].m - a[L].m <= d) {
            R++;
        }

        // 处理当前窗口 [L,R)
        long long sum = pre[R - 1] - pre[L - 1];

        if (sum > ans) {
            ans = sum;
        }

        // 左指针右移
        L++;
    }

    cout << ans;
    return 0;
}

    2.7 复杂度分析

    排序复杂度为：

    \[ O(n\\log n) \]

    排序之后，L 和 R 各自只向右移动一次，窗口扫描复杂度为：

    \[ O(n) \]

    总时间复杂度为：

    \[ O(n\\log n) \]

    数组、结构体和前缀和需要：

    \[ O(n) \]

    空间复杂度为：

    \[ O(n) \]

    五、分离指针：P1335 序列合并

    1．问题描述

    给定两个已经升序排列的序列，将它们合并为一个升序序列。

    例如：

    序列 A：1 3 7 9 22
序列 B：2 8 10 17 33 44

    合并结果：

    1 2 3 7 8 9 10 17 22 33 44

    2．为什么可以使用分离指针

    两个序列已经有序，因此：

    • i 指向序列 A 当前还没有合并的第一个元素；
    • j 指向序列 B 当前还没有合并的第一个元素。

    当前只需要比较：

    a[i] 和 b[j]

    较小的元素一定是合并结果中的下一个元素。

    取出较小元素后，对应指针向后移动。

    3．合并过程

    A: 1 3 7 9 22
   ↑

B: 2 8 10 17 33 44
   ↑

    比较 1 和 2，取 1，i++。

    A: 1 3 7 9 22
     ↑

B: 2 8 10 17 33 44
   ↑

    比较 3 和 2，取 2，j++。

    重复这个过程，直到其中一个序列处理完。

    如果一个序列已经处理完，另一个序列剩余部分仍然有序，可以直接全部加入结果。

    4．参考代码

    #include <iostream>
using namespace std;

const int N = 5005;

int n;
int m;
int a[N];
int b[N];
int c[N * 2];

int main() {
    cin >> n >> m;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    for (int i = 1; i <= m; i++) {
        cin >> b[i];
    }

    int i = 1;
    int j = 1;
    int k = 0;

    // 两个序列都没有处理完时，比较当前元素
    while (i <= n && j <= m) {
        if (a[i] <= b[j]) {
            c[++k] = a[i++];
        } else {
            c[++k] = b[j++];
        }
    }

    // 处理序列 A 的剩余元素
    while (i <= n) {
        c[++k] = a[i++];
    }

    // 处理序列 B 的剩余元素
    while (j <= m) {
        c[++k] = b[j++];
    }

    for (int t = 1; t <= n + m; t++) {
        cout << c[t] << ' ';
    }

    return 0;
}

    5．复杂度分析

    每个元素只被访问和复制一次，因此时间复杂度为：

    \[ O(n+m) \]

    如果使用结果数组保存合并结果，空间复杂度为：

    \[ O(n+m) \]

    分离指针的关键是：

    两个指针分别在两个有序序列中向前移动，不需要回退，也不需要重复比较已经处理过的元素。

    六、多指针：P1681 A-B 数对

    1．问题描述

    给定 n 个整数和一个整数 C，统计满足：

    A - B = C

    的数对 (A,B) 数量。

    不同位置上的相同数字也算不同的数对。

    例如：

    数组：1 1 2 3
C = 1

    满足条件的数对数量为 3。

    因为：

    2 - 1 = 1
3 - 2 = 1

    而数组中有两个位置上的 1，它们分别可以作为 B。

    2．变形为查找目标值

    由：

    A - B = C

    可以得到：

    B = A - C

    枚举每个 A，就变成：

    统计数组中等于 A - C 的元素个数。

    先将数组排序。由于数组有序，所有等于 B 的元素一定连续。

    3．两个边界指针

    对于当前目标值 B：

    • L：第一个满足 a[L] >= B 的位置；
    • R：第一个满足 a[R] > B 的位置。

    那么：

    [L,R) 中的所有元素都等于 B

    目标值 B 的出现次数就是：

    R - L

    当前 A 对答案的贡献就是 R - L。

    4．为什么这是多指针

    程序中有三个需要协同推进的位置：

    i：枚举 A
L：寻找 B 的左边界
R：寻找 B 的右边界（第一个超过B的位置）

    随着 i 增大，a[i] 不减，因此：

    B = a[i] - C

    也不减。

    所以 L 和 R 都不会向左移动，可以继续使用上一次的位置。

    5．参考代码

    #include <iostream>
#include <algorithm>
using namespace std;

const int N = 200000 + 5;

int n;
long long C;
long long a[N];

int main() {
    cin >> n >> C;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    sort(a + 1, a + 1 + n);

    int L = 1;
    int R = 1;

    long long ans = 0;

    for (int i = 1; i <= n; i++) {
        long long A = a[i];
        long long B = A - C;

        // 找到第一个大于等于 B 的位置
        while (L <= n && a[L] < B) {
            L++;
        }

        // 找到第一个大于 B 的位置
        while (R <= n && a[R] <= B) {
            R++;
        }

        // [L,R) 中的元素都等于 B
        ans += R - L;
    }

    cout << ans;
    return 0;
}

    6．复杂度分析

    排序需要：

    \[ O(n\\log n) \]

    枚举 A 时，L 和 R 都只向右移动，总扫描复杂度为：

    \[ O(n) \]

    总时间复杂度为：

    \[ O(n\\log n) \]

    额外空间复杂度为：

    \[ O(1) \]

    七、总结

    1．双指针的本质

    双指针的本质不是“使用了两个变量”，而是：利用问题的有序性、单调性、不变量或约束关系，保证指针只沿一个方向移动、不回退，从而安全排除不可能候选，减少重复枚举和重复工作。

    因此，使用双指针时不能只记住代码模板，更要说明：指针为什么可以移动、为什么不需要回退、移动后为什么不会漏掉答案。

    2．五类指针的区别

    类型 指针关系 核心思想 典型用途 代表题目
    对撞指针 左右两端向中间移动 根据当前结果决定移动哪一侧，并排除一批不可能候选 有序数组找数对、回文判断、盛水容器 找指定和的整数对
    快慢指针 同向移动，推进速度或职责不同 快指针探索，慢指针维护结果位置；或利用速度差构造不变量 数组去重、移动零、链表找环/中点 找两倍的数组
    滑动窗口 左右边界维护连续区间 右端扩张、左端收缩，维护窗口状态和可行性条件 子数组、子串的最值或计数问题 找子串、邀请朋友
    分离指针 分别遍历两个序列 按大小关系或匹配关系分别推进指针 归并、求交集、合并有序数组、判断子序列 序列合并
    多指针 两个以上指针协同推进 多个指针共同维护边界、候选区间或多路位置，是双指针的推广 多元素组合、区间划分、多路归并、统计连续相等区间 A-B 数对

    3．使用双指针前必须回答的问题

    • 为什么这个指针可以移动？
    • 为什么它不需要回退？
    • 移动后为什么不会漏掉答案？
    • 指针移动的依据是什么？
    • 指针维护的状态如何更新？

    这五个问题分别对应双指针的正确性、单向性、完备性和状态维护。能回答清楚，才说明真正理解了这道题为什么能用双指针。
