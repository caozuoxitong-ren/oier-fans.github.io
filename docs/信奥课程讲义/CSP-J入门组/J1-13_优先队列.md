# 第 13 课 优先队列

大顶堆、小顶堆、自定义比较函数及经典问题

> **学习目标**：理解优先队列“队首永远是优先级最高、最该先处理的元素”这一本质，分清它与普通队列的区别；会定义大顶堆、小顶堆，掌握 push、pop、top、size、empty 五个操作；会用结构体重载和仿函数自定义优先级，并会用“取相反数”把小顶堆需求转成大顶堆；能用优先队列解决合并、反悔贪心、多路归并、模拟等经典问题。

## 一、什么是优先队列

### 1．普通队列与优先队列

普通队列 `queue`：先进先出，队首是“来得最早”的那个。

优先队列 `priority_queue`：出队的是“优先级最高”的那个，**队首永远是优先级最高、最该先处理的元素**，跟谁先来无关。

| 对比项 | 普通队列 queue | 优先队列 priority_queue |
| :--- | :--- | :--- |
| 出队顺序 | 先进先出 | 按优先级，优先级最高的先出 |
| 取队首 | `front()` | `top()` |
| 头文件 | `<queue>` | `<queue>` |

### 2．队首永远是优先级最高的元素

先记住一句话：**优先队列永远把“优先级最高、最该先处理”的元素顶在队首，每次 `top()` 拿到的就是当前最该处理的。**

那“优先级”用什么表示？**默认用数值大小**：

- 大顶堆：数值越大优先级越高，队首是最大值；
- 小顶堆：数值越小优先级越高，队首是最小值。

所以“最大 / 最小”只是默认的一种优先级；换成结构体后，优先级可以是任意一个字段（进程的优先级、好听度、时长……）。

### 3．底层是堆：先建直觉

优先队列的底层是“堆”，一种特殊的完全二叉树。堆的性质只有一条：

> 每个父节点的优先级，都不低于它的孩子。

- 大顶堆：父 ≥ 孩子，根（堆顶）优先级最高（值最大）；
- 小顶堆：父 ≤ 孩子，根（堆顶）优先级最高（值最小）。

好处：插入、删除、取队首都是 O(log n)，比每次从头找一遍 O(n) 快得多。

初学先直接用 STL 的 `priority_queue`，不必手写堆；只要记住“**堆顶就是优先级最高的元素**”就够了。

### 4．什么时候用

凡是“反复取出当前最该处理（往往是最大或最小）的元素”的题，优先队列都很合适：合并果子、反悔贪心、多路归并、进程模拟等，下面都会讲到。

## 二、定义、初始化与常用操作

### 1．头文件与两种定义

```cpp
#include <queue>
#include <vector>
using namespace std;

priority_queue<int> q;                               // 大顶堆：队首最大（默认）
priority_queue<int, vector<int>, less<int> > q2;     // 大顶堆：队首最大（完整写法）
priority_queue<int, vector<int>, greater<int> > q3;  // 小顶堆：队首最小
```

注意：

- 小顶堆要写全三个模板参数，不能只写 `priority_queue<int, greater<int> >`。第二个参数是底层容器（默认 `vector`），要指定第三个比较器，就必须把第二个也写出来。
- **`> >` 之间为什么要加空格**：`greater<int>` 自己带一个 `>`，外层模板还要一个 `>`，两个 `>` 挨在一起就变成 `>>`。C++11 之前的老编译器会把 `>>` 误当成右移运算符而报错，所以习惯在两个 `>` 之间加一个空格写成 `> >`。C++11 起不加空格也能编译，但为了兼容老评测机、也为了代码更清楚，本文统一写 `> >`。

### 2．常用操作速查

| 操作 | 作用 | 复杂度 |
| :--- | :--- | :--- |
| `q.push(x)` | 插入 x，自动调整位置 | O(log n) |
| `q.pop()` | 删除队首（优先级最高的元素） | O(log n) |
| `q.top()` | 返回队首（优先级最高的元素），不删除 | O(1) |
| `q.size()` | 元素个数 | O(1) |
| `q.empty()` | 是否为空 | O(1) |

要点：

- 优先队列只有 `top()`，**没有** `front()`、`back()`。
- 取队首用 `top()`；要“取走”它，先 `top()` 拿到，再 `pop()` 删掉。

### 3．不能遍历，也不能下标访问

优先队列不是数组：不能写 `q[i]`，也不能用 `for` 遍历。

想把它里面的元素一个个拿出来，只能反复 `top()` + `pop()`：

```cpp
while (!q.empty()) {
    cout << q.top() << ' ';
    q.pop();
}
```

## 三、自定义优先级

### 1．大顶堆与小顶堆

默认是大顶堆（数值大的优先级高、在队首）；加 `greater<int>` 就变小顶堆（数值小的优先级高、在队首）。

```cpp
priority_queue<int> big;                              // 大顶堆
priority_queue<int, vector<int>, less<int> > big2;    // 大顶堆（完整参数写法）
priority_queue<int, vector<int>, greater<int> > small; // 小顶堆
```

速记：**less 对应大顶堆，greater 对应小顶堆**。

### 2．结构体：重载 operator<

要按结构体的某个字段定优先级，就重载 `operator<`。

```cpp
struct Node {
    int hp, dps;
    // 按 hp 大的优先（大顶堆）
    bool operator < (const Node &o) const {
        return hp < o.hp;
    }
};
priority_queue<Node> q;   // hp 最大的在队首
```

理解方向：`operator<` 返回 `true`，表示“this 排在 other 后面”（优先级更低）。所以 `return hp < o.hp` 表示 hp 小的排后面，小的排到后面了，大的也就跑到前面了，也就是 hp 大的优先，就是大顶堆了。

想让 hp 小的优先，把 `<` 反过来：

```cpp
bool operator < (const Node &o) const {
    return hp > o.hp;      // hp 小的优先
}
```

### 3．仿函数（函数对象）

想在比较器里写复杂规则，用一个重载 `()` 的结构体：

```cpp
struct Cmp {
    bool operator()(int a, int b) {
        return a > b;      // 小顶堆：小的优先
    }
};
priority_queue<int, vector<int>, Cmp> q;
```

注意：优先队列的第三个参数要的是“类型”，不是普通函数，所以不能直接传一个函数名，要用结构体（仿函数）。

### 4．与 sort 的 cmp 方向相反（高频坑）

这是最容易错的地方，单独记：

- `sort` 的 `cmp(a, b)` 返回 `true`，表示 a 排在 b **前面**；
- `priority_queue` 的比较返回 `true`，表示 a 排在 b **后面**（优先级更低）。

同样想“大的优先”：

```cpp
sort(a + 1, a + n + 1, cmp);   // cmp 里 return a > b → 降序（大的在前）
priority_queue<int, vector<int>, less<int> > q;      // less → 大顶堆
```

想“小的优先”：

```cpp
// sort 里：return a < b → 升序
priority_queue<int, vector<int>, greater<int> > q;   // greater → 小顶堆
```

### 5．取相反数：把大顶堆当小顶堆用

有时懒得写小顶堆的三个参数，可以“存相反数”——把值取负后放进默认大顶堆。大顶堆的堆顶是“最大的负数”，也就是“最小的正数”，效果等于小顶堆。

```cpp
priority_queue<int> q;      // 默认大顶堆
q.push(-x);                 // 存相反数
int mn = -q.top();          // 取出来再取反，就是最小值
```

合并果子一节会用它，到时候对照着看。

## 四、经典例题

### 1．合并果子（P1750，小顶堆 + 取相反数）

**题目**：n 堆果子，每次合并两堆，花费两堆重量之和的体力，求合成一堆的最小体力。

**思路**：每次合并最小的两堆。两种写法：直接用 `greater<int>` 小顶堆；或者“取相反数”放进默认大顶堆。

**写法一：小顶堆**

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n;
    cin >> n;
    priority_queue<int, vector<int>, greater<int> > q;   // 小顶堆
    for (int i = 1; i <= n; i++) {
        int x; cin >> x; q.push(x);
    }
    long long ans = 0;
    while (q.size() >= 2) {
        int a = q.top(); q.pop();   // 取最小的两堆
        int b = q.top(); q.pop();
        ans += a + b;
        q.push(a + b);              // 新堆放回去
    }
    cout << ans << '\n';
    return 0;
}
```

**写法二：取相反数，用大顶堆**

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n;
    cin >> n;
    priority_queue<int> q;          // 默认大顶堆
    for (int i = 1; i <= n; i++) {
        int x; cin >> x; q.push(-x);   // 存相反数
    }
    long long ans = 0;
    while (q.size() >= 2) {
        int a = -q.top(); q.pop();   // 取出来再取反
        int b = -q.top(); q.pop();
        ans += a + b;
        q.push(-(a + b));
    }
    cout << ans << '\n';
    return 0;
}
```

**要点**：取两堆要连续 `pop()` 两次；新堆必须 `push` 回去；`ans` 用 `long long`。写法二的核心是“存相反数”，大顶堆堆顶是最大负数，即最小正数。

### 2．股票（P1753，反悔贪心）

**题目**：预测某股票未来 N 天的价格。每天要么买一股、要么卖一股、要么不动。初始 0 股，结束时也要 0 股，求最大利润。

**思路**：反悔贪心。用小顶堆存“可反悔的买入价”。每天价格为 p：若堆顶（历史最低买入价）< p，就卖出一股赚差价，并把 p 也压入堆作为“反悔”（允许将来用更高价替换这次卖出）；无论是否卖出，每天都把 p 压入堆作为新的买入候选。

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long ans = 0;
    priority_queue<int, vector<int>, greater<int> > q;   // 小顶堆
    for (int i = 1; i <= n; i++) {
        int p;
        cin >> p;
        // 卖出之前低于当前价格的股票
        if (!q.empty() && q.top() < p) {
            ans += p - q.top();
            q.pop();
            // 反悔标记：允许未来以更高的价格替换本次卖出价
            q.push(p);
        }
        // 今天也可以作为未来某天的候选
        q.push(p);
    }
    cout << ans << '\n';
    return 0;
}
```

**要点**：卖出后 `push(p)` 一次是“反悔标记”，最后再 `push(p)` 一次是“今天的买入候选”，所以一天最多压入两次。反悔贪心的思想是：先贪着卖，随时用更高价“反悔”成“改在更高价卖”。

### 3．序列合并（P2777，多路归并 + 分块）

**题目**：两个长度 N 的升序序列 A、B，各取一个数相加得 N² 个和，输出其中最小的 N 个。

**思路**：把 a[i] + b[j] 看成 N 行 N 列的表格，每行、每列都升序。两种做法：

**方法一：多路归并（优先队列存每行队首）**

优先队列里放每行最小的候选 a[i] + b[1]。每次取出最小的，再把该行的下一个 a[i] + b[j+1] 补进来。

```cpp
#include <iostream>
#include <queue>
using namespace std;

const int N = 100005;
int a[N], b[N];

struct Node {
    int sum;   // 当前和 a[i] + b[bid]
    int bid;   // 当前用的是 B 的第几个
    bool operator < (const Node &o) const {
        return sum > o.sum;   // sum 小的优先（小顶堆效果）
    }
};

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    priority_queue<Node> q;
    for (int i = 1; i <= n; i++) q.push({a[i] + b[1], 1});

    for (int i = 1; i <= n; i++) {
        Node t = q.top(); q.pop();
        cout << t.sum << ' ';
        if (t.bid < n) {
            q.push({t.sum - b[t.bid] + b[t.bid + 1], t.bid + 1});
        }
    }
    cout << '\n';
    return 0;
}
```

**方法二：分块（按 1/1、1/2、1/3… 入队）**

前 n 小里，如果 a[i] + b[j] 排在第 n 名以内，一定有 i×j ≤ n。所以第 i 行只要取前 ⌈n/i⌉ 个就够，全部入堆后直接取前 n 个。

- 如果第一行够 n 个最小值，那么就取第一行；
- 如果第一行不够，那么取到第二行，第二行最多取到前 1/2，因为第二行前 1/2 能取的时候，第 1 行的前 1/2 必然能取，可以凑够 n 个；
- 如果第二行不够，取到了第 3 行，那么第三行只需要前 1/3 即可，因为如果第 3 行的前 1/3 可取，那么前 2 行的前 1/3 也可取，就可以凑够 n 个；
- 依次类推，……
- 第 n 行若可取，那么只需要取 n/n = 1 个即可，因为第 n 行能取一个，那么前 n-1 行必然至少能取 1 个，也可以凑够 n 个。

入堆的元素总数约 n·(1 + 1/2 + … + 1/n) ≈ n·ln n 个，所以总时间复杂度 O(n·ln n·log n) ≈ O(n log² n)。

```cpp
#include <iostream>
#include <queue>
using namespace std;

const int N = 100005;
int a[N], b[N];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    priority_queue<int, vector<int>, greater<int> > q;   // 小顶堆
    for (int i = 1; i <= n; i++) {
        int cnt = (n + i - 1) / i;   // 第 i 行取 ⌈n/i⌉ 个 (上取整)
        for (int j = 1; j <= cnt; j++) {
            q.push(a[i] + b[j]);
        }
    }
    for (int i = 1; i <= n; i++) {
        cout << q.top() << ' ';
        q.pop();
    }
    cout << '\n';
    return 0;
}
```

**要点**：方法一里 `Node` 没存行号，因为 `t.sum - b[t.bid]` 就是 a[i]，再 `+ b[t.bid+1]` 就是下一项，行号隐含在 sum 里。方法二的依据是“前 n 小里，第 i 行只可能用到前 ⌈n/i⌉ 个”。

### 4．学长A的才艺表演（P1754，仿函数 + sort + 优先队列）

**题目**：n 首歌，每首有时长 t 和好听度 b。至多选 k 首，愉悦感 = 所选总时长 × 所选最小好听度，求最大愉悦感。

**思路**：先按好听度降序排序；再依次枚举“当前歌的好听度作为最小好听度”，用时长小顶堆维护已选歌里时长最小的，超 k 就弹掉最小的。这里演示 `sort` 的 cmp 和 `priority_queue` 的仿函数两种比较器。

```cpp
#include <iostream>
#include <algorithm>
#include <queue>
using namespace std;

const int N = 300005;
struct Node {
    int t;   // 时长
    int b;   // 好听度
} a[N];

// sort 用：按好听度降序
bool cmp1(Node x, Node y) {
    return x.b > y.b;
}

// 优先队列用：仿函数，按时长小顶堆（时长小的优先）
struct cmp2 {
    bool operator() (Node &x, Node &y) {
        return x.t > y.t;
    }
};

int main() {
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++) cin >> a[i].t >> a[i].b;

    sort(a + 1, a + n + 1, cmp1);   // 好听度降序

    long long ans = 0, sumt = 0;    // ans 答案，sumt 已选总时长
    priority_queue<Node, vector<Node>, cmp2> q;
    for (int i = 1; i <= n; i++) {
        if ((int)q.size() < k) {           // 还没选满
            q.push(a[i]);
            sumt += a[i].t;
            ans = max(ans, sumt * a[i].b);
        } else if (q.top().t < a[i].t) {   // 弹掉时长最小的，换进时长更大的
            Node h = q.top(); q.pop();
            q.push(a[i]);
            sumt = sumt - h.t + a[i].t;
            ans = max(ans, sumt * a[i].b);
        }
    }
    cout << ans << '\n';
    return 0;
}
```

**要点**：`sort` 用普通函数 `cmp1`，`priority_queue` 用仿函数 `cmp2`，两者都要“自定义比较”，但一个返回“谁在前”、一个返回“谁在后”，方向相反。因为按好听度降序处理，当前歌的 b 就是已处理歌里最小的好听度。

### 5．操作系统（P2779，优先队列模拟）

**题目**：模拟单 CPU 的进程调度。每个进程有到达时间、执行时间、优先级。优先级高的抢占 CPU；CPU 空闲时选优先级最高（相同则到达最早）的进程。按结束时间顺序输出每个进程的进程号和结束时间。

**思路**：用优先队列维护等待进程，比较器按“优先级降序、到达时间升序”。用一个 `now` 记录当前时刻，读入每个进程时，先处理在它到达前能跑完的进程，再处理抢占。

```cpp
#include <iostream>
#include <queue>
using namespace std;

struct Node {
    int pid;   // 进程号 Process ID
    int st;    // 到达时间 start
    int re;    // 剩余执行时间 remain
    int pr;    // 优先级 priority
    bool operator < (const Node &o) const {
        if (pr != o.pr) return pr < o.pr;   // 优先级高的优先
        return st > o.st;                   // 相同则到达早的优先
    }
};

int main() {
    Node cur;
    priority_queue<Node> q;
    long long now = 0;   // 当前时刻

    while (cin >> cur.pid >> cur.st >> cur.re >> cur.pr) {
        // 在 cur 到达前能跑完的进程，依次跑完并输出
        while (!q.empty() && now + q.top().re <= cur.st) {
            Node b = q.top(); q.pop();
            cout << b.pid << ' ' << now + b.re << '\n';
            now += b.re;
        }
        // cur 到达时，堆顶还没跑完：它先跑一段，剩下的放回
        if (!q.empty()) {
            Node b = q.top(); q.pop();
            b.re -= (cur.st - now);
            q.push(b);
        }
        // 新进程入队
        q.push(cur);
        now = cur.st;
    }
    // 所有进程都读完了，剩下的依次跑完
    while (!q.empty()) {
        Node b = q.top(); q.pop();
        cout << b.pid << ' ' << now + b.re << '\n';
        now += b.re;
    }
    return 0;
}
```

**要点**：比较器用多关键字——先比优先级（`pr < o.pr` 让大的优先），再比到达时间（`st > o.st` 让小的优先）。模拟的关键是维护“剩余执行时间” `re`：抢占发生时，把被抢进程已经跑掉的时间从 `re` 里扣掉再放回。

## 五、总结

**本质**：优先队列 = 队首永远是优先级最高（最该先处理）的元素的队列；优先级默认用数值大小表示（大顶堆 / 小顶堆），换成结构体则可以是任意字段。底层是堆，插入 push()、删除 pop() 都是 O(log n)，取队首 top()、大小 size()、判空 empty() 都是 O(1)。

**定义与操作**：默认大顶堆，`greater<int>` 变小顶堆；只有 `top()`，没有 `front()`；不能遍历、不能下标访问。

**自定义优先级**：结构体重载 `operator<`，或用仿函数；比较方向与 `sort` 相反；也可以用“取相反数”把大顶堆当小顶堆用。

**常见坑**：小顶堆三个模板参数要写全；取队首先 `top()` 再 `pop()`；结构体比较器方向想清楚。

**一句话总结**：优先队列把“优先级最高、最该先处理”的元素顶在队首，凡是反复取最优先元素、按优先级抢占的问题，都可以尝试用优先队列高效解决。
