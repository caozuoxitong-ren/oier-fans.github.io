## 四、什么是标记法——从"判断"问题说起

### 引入：判断型问题

前面学过的循环都是**处理型**——求和、求最值、拆位数，循环跑完得到一个结果。但有一类问题是**判断型**：

-   这个数是素数吗？
-   数组里有没有 3？
-   这个序列是递增的吗？

这类问题的答案是"是"或"否"，怎么用循环来解决？核心思路是：**用一个变量记录"目前是否发现满足/不满足条件的证据"，循环结束后根据这个变量做最终判断**。这个变量就叫**标记**（flag）。

### bool 类型

标记变量通常用 `bool` 类型。`bool` 是布尔类型，只有两个值：`true`（真）和 `false`（假），占 1 字节（`sizeof(bool) = 1`）。`bool` 适合做标记变量，因为标记的本质就是"是"或"否"。

```cpp
bool flag = true;   // 真
bool found = false; // 假

```

> **要点**：`if(flag)` 等价于 `if(flag == true)`，`if(!flag)` 等价于 `if(flag == false)`。写标记判断时推荐简写形式 `if(flag)` / `if(!flag)`，更简洁。也可以用 `int`（0 表示假，1 表示真），但 `bool` 语义更清晰。

### 最小示例：判断偶数

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    bool isEven = true;      // 假设是偶数
    if (n % 2 != 0) {        // 找到反例：不能被2整除
        isEven = false;      // 修改标记
    }
    if (isEven) cout << "Even" << '\n';
    else cout << "Odd" << '\n';
    return 0;
}

```

输入：

```
7

```

输出：

```
Odd

```

这个例子没有循环，但已经体现了标记法的核心：**先假设，再找反例，根据标记做判断**。加上循环，就能解决更复杂的问题。

## 五、标记法基本套路——四步流程

### 四步流程

标记法的标准流程：

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| ① 初始化标记 | `bool flag = true;`（或 `false`） | 根据问题类型选择初始假设 |
| ② 循环检查 | `for (...) { if (...) {` | 遍历每个元素/每种情况 |
| ③ 修改标记 | `flag = false; break;` | 发现反例/证据时修改，通常配合 `break` 跳出 |
| ④ 循环外决策 | `if (flag) ... else ...` | 根据标记输出最终结果 |

### 两种初始假设策略

标记法的关键在于**初始假设怎么设**：

| 问题类型 | 初始假设 | 找到什么时修改 | 典型例子 |
| --- | --- | --- | --- |
| 验证属性（是否满足 XX） | 假设满足（`flag = true`） | 找到**反例**时 `flag = false` | 素数判断、序列递增 |
| 存在性判断（有没有 XX） | 假设不存在（`flag = false`） | 找到**证据**时 `flag = true` | 数组中是否有 x |

> **记忆口诀**：验证属性"先说好，找到反例就推翻"；存在性判断"先说没有，找到证据才承认"。

### 通用框架代码

```cpp
#include <iostream>
using namespace std;
int main() {
    // ① 初始化标记（根据问题类型选 true 或 false）
    bool flag = true;  // 此处以"验证属性"为例

    // ② 循环检查
    for (int i = 0; i < n; i++) {
        if (/* 找到反例 */) {
            // ③ 修改标记并跳出
            flag = false;
            break;
        }
    }

    // ④ 循环外决策
    if (flag) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

> **要点**：第 ③ 步的 `break` 不是必须的（不加 break 结果也对，因为标记已经被修改），但加了 break 可以**提前结束循环**，避免做无用功。详见第七模块。

## 六、素数判断——标记法的经典应用

### 素数定义

**素数**（质数）：大于 1 的自然数，除了 1 和它本身没有其他因数。2、3、5、7、11 是素数，4、6、8、9、10 不是。

### 标记法思路

-   **问题类型**：验证属性——"n 是不是素数？"
-   **初始假设**：假设是素数（`isPrime = true`）
-   **找反例**：从 2 到 n-1 逐个试除，如果 n 能被某个数整除，说明 n 有其他因子，不是素数

### 完整代码

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    bool isPrime = true;  // ① 假设是素数

    if (n <= 1) {
        isPrime = false;  // 边界：1 和负数不是素数
    } else {
        for (int i = 2; i <= n - 1; i++) {  // ② 从2到n-1试除
            if (n % i == 0) {  // 找到反例：i 是 n 的因子
                isPrime = false;  // ③ 修改标记
                break;            // 跳出循环
            }
        }
    }

    // ④ 循环外决策
    if (isPrime) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

输入：

```
7

```

输出：

```
Yes

```

输入：

```
9

```

输出：

```
No

```

> **边界处理**：`n <= 1` 时不是素数（1 既不是素数也不是合数），必须单独处理。`n = 2` 时循环不执行（`i = 2, i <= 1` 为假），`isPrime` 保持 `true`，正确。

> **试除范围**：从 2 开始（1 不是有效因子），到 n-1 结束（n 本身一定是因子，试除 n 没有意义）。第七模块会进一步优化到 `i*i <= n`。

## 七、break 优化——发现即跳出

### 为什么需要 break

不加 break 的素数判断也能得到正确结果——标记一旦被设为 `false`，后续循环再怎么跑也不会变回来。但问题是**浪费时间**：判断 1000000 是不是素数，试除到 2 就发现它是偶数（不是素数），不加 break 会继续试除 3、4、5……一直到 999999，全是无用功。

加 break 后，发现因子立即跳出，不再做多余的比较：

```cpp
// 不加 break：最坏情况循环 n-2 次
for (int i = 2; i <= n - 1; i++) {
    if (n % i == 0) {
        isPrime = false;  // 标记已改，但循环继续
    }
}

// 加 break：发现即停，最少 1 次就跳出
for (int i = 2; i <= n - 1; i++) {
    if (n % i == 0) {
        isPrime = false;
        break;  // 立即跳出
    }
}

```

### 进一步优化：i\*i \<= n

试除范围其实不需要到 n-1，只需要到 √n。原因：如果 n 有一个大于 √n 的因子 a，那么 `n / a` 一定小于 √n，也是 n 的因子。所以我们只需要检查 2 到 √n 范围内有没有因子，就能判断 n 是不是素数。

用 `i * i <= n` 代替 `i <= sqrt(n)`，可以避免浮点运算和 `<cmath>` 头文件：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    bool isPrime = true;

    if (n <= 1) {
        isPrime = false;
    } else {
        for (int i = 2; i * i <= n; i++) {  // 只试到 sqrt(n)
            if (n % i == 0) {
                isPrime = false;
                break;
            }
        }
    }

    if (isPrime) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

> **效率对比**（以 n = 1000003 为例，这是一个素数）：
> 
> -   试除到 n-1：循环约 100 万次
> -   试除到 `i*i <= n`：循环约 1000 次（√1000003 ≈ 1000）
> 
> 优化后快了约 1000 倍。这就是算法优化的威力。

> **要点**：`i * i <= n` 要注意 `i` 是 `int` 类型，`i * i` 也是 `int`。当 n 接近 `int` 上限（约 21 亿）时，`i * i` 可能溢出。本题 n 不超过 10^9 时安全；更大的 n 需要用 `long long`。

## 八、存在性判断——数组里有没有 X

### 问题描述

给定 n 个整数和一个目标值 x，判断 x 是否在数组中出现。

### 标记法思路

-   **问题类型**：存在性判断——"数组里有没有 x？"
-   **初始假设**：假设不存在（`found = false`）
-   **找证据**：遍历数组，如果某个元素等于 x，说明存在

### 完整代码

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x;
    cin >> n >> x;
    int a[10000];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    bool found = false;  // ① 假设不存在
    for (int i = 0; i < n; i++) {  // ② 遍历检查
        if (a[i] == x) {  // 找到证据
            found = true;  // ③ 修改标记
            break;          // 跳出
        }
    }

    // ④ 循环外决策
    if (found) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

输入：

```
5 3
1 3 5 7 9

```

输出：

```
Yes

```

> **与第9课查找搜索的区别**：第9课的查找输出**位置**（第几个），本课的判断输出**是否存在**（Yes/No）。查找可以用 `return 0` 直接退出，标记法用 `flag + break` 记录结果后在循环外统一输出。两种写法都可以，标记法更体现"判断型"问题的套路。

## 九、属性验证——序列是否满足条件

### 问题描述类型

属性验证：判断一个序列是否整体满足某个条件。

-   序列是否严格递增？（每个数比前一个数大）
-   序列是否全为正数？
-   序列是否全为偶数？

### 经典案例：判断严格递增

-   **问题类型**：验证属性——"序列是否严格递增？"
-   **初始假设**：假设是递增的（`increasing = true`）
-   **找反例**：遍历相邻元素，如果 `a[i] >= a[i+1]`（前一个不小于后一个），说明不是严格递增

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int a[1000];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    bool increasing = true;  // ① 假设严格递增
    for (int i = 0; i < n - 1; i++) {  // ② 检查相邻对
        if (a[i] >= a[i + 1]) {  // 反例：前一个不小于后一个
            increasing = false;  // ③ 修改标记
            break;
        }
    }

    // ④ 循环外决策
    if (increasing) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

输入：

```
5
1 3 5 7 9

```

输出：

```
Yes

```

输入：

```
5
1 3 3 7 9

```

输出：

```
No

```

> **反例条件**：严格递增要求 `a[i] < a[i+1]`，反例就是 `a[i] >= a[i+1]`（含等于）。相等不是严格递增，所以用 `>=` 而非 `>`。循环范围是 `i < n - 1`（比较 n-1 对相邻元素），不是 `i < n`，否则 `a[i+1]` 越界。

## 十、数组标记法——桶思想初步

### 引入：单个标记不够用

前面的问题只需要一个"是/否"的答案，一个 `bool` 变量就够了。但如果要问"哪些数出现过"，单个标记就不够了——需要为每个可能的值各设一个标记。

### 思想：用数组下标标记

用一个数组 `mark`，下标就是值，`mark[x] = 1` 表示 x 出现过，`mark[x] = 0` 表示没出现过。这种做法叫**桶标记**，是标记法的数组版本。

### 经典案例：值域内查询

给定 n 个整数（值在 1 到 100 之间），再给 q 个查询，每个查询问"x 出现过吗？"

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int mark[101] = {0};  // 值域1~100，标记数组初始化全为0
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        mark[x] = 1;  // 标记x出现过
    }

    int q;
    cin >> q;
    for (int i = 0; i < q; i++) {
        int x;
        cin >> x;
        if (mark[x]) cout << "Yes" << '\n';  // mark[x]==1 即出现过
        else cout << "No" << '\n';
    }
    return 0;
}

```

输入：

```
5
3 7 1 7 9
3
7
2
1

```

输出：

```
Yes
No
Yes

```

> **效率优势**：不用桶标记时，每次查询要遍历整个数组（O(n)）；用桶标记后，预处理 O(n)，每次查询只需看 `mark[x]`（O(1)），q 次查询总共 O(n+q)。

> **计数版本**：把 `mark[x] = 1` 改成 `mark[x]++`，就能记录每个值出现了几次，`mark[x]` 的值就是 x 出现的次数。这就是**桶计数**。

> **值域约束**：桶标记要求值域有限且不大。值域 1~100 用 \`mark\[101\]\`（下标 0~100）；值域 1~10000 用 `mark[10001]`。值域太大（如 10^9）不能用桶标记，需要其他方法。

## 十一、标记法的常见变体

### 计数标记

不只用 true/false，而是记录"有几个"。例如判决素数个数：遍历区间内每个数，用素数判断（标记法）检查，用一个计数器 `cnt` 统计素数的个数。

```cpp
int cnt = 0;
for (int i = x; i <= y; i++) {
    bool isPrime = true;
    if (i <= 1) isPrime = false;
    else {
        for (int j = 2; j * j <= i; j++) {
            if (i % j == 0) { isPrime = false; break; }
        }
    }
    if (isPrime) cnt++;
}
cout << cnt << '\n';

```

> 这里标记法（素数判断）嵌套在循环里，外层循环遍历每个数，内层用标记法判断。计数器 `cnt` 是另一种"标记"——记录满足条件的个数。

### 多标记

同时维护多个标记变量。例如判断一个数是否同时满足"是素数"和"是两位数"：

```cpp
bool isPrime = true;
bool isTwoDigit = (n >= 10 && n <= 99);
// ... 素数判断代码 ...
if (isPrime && isTwoDigit) cout << "Yes" << '\n';
else cout << "No" << '\n';

```

### 标记变量 vs 标记数组

| 场景 | 选择 | 原因 |
| --- | --- | --- |
| 判断一个整体是否满足条件 | 标记变量（`bool`） | 只需要一个"是/否"的答案 |
| 判断多个值各自是否出现 | 标记数组（`int[]`） | 每个值需要独立的标记 |
| 统计每个值出现几次 | 计数数组（`int[]`） | 每个值需要独立的计数器 |

> **留待后续**：本课的标记法用单个 `bool` 变量或一维数组做标记。后续课程中，标记法会与函数结合（把素数判断封装成函数，随时调用），与更复杂算法结合（如埃拉托斯特尼筛法——用标记数组批量筛素数，就是标记法的批量应用）。掌握标记法，就是掌握了"用循环做判断"的核心套路。

## 十二、常见错误与注意事项

| 编号 | 错误 | 后果 | 改正 |
| --- | --- | --- | --- |
| E1 | 标记变量未初始化 | 值不确定，结果不可预测 | 定义时立即赋初值（`true` 或 `false`） |
| E2 | 标记初始值设反 | 验证属性时初始设 `false`，永远输出"不满足" | 验证属性初始设 `true`，存在性判断初始设 `false` |
| E3 | `if(flag = true)` 误写赋值 | 赋值结果为 `true`，条件恒成立 | 判断标记用 `if(flag)` 或 `if(flag == true)` |
| E4 | 素数判断未处理 `n<=1` | 1 被误判为素数 | 先判断 `if(n <= 1) isPrime = false;` |
| E5 | 素数判断从 1 开始试除 | 1 是所有数的因子，全判为非素数 | 从 `i = 2` 开始试除 |
| E6 | 素数判断试除到 n | n 本身是因子，全判为非素数 | 试除到 `n-1` 或 `i*i <= n` |
| E7 | `break` 写在 `if` 外面 | 第一次循环就跳出，标记永远不变 | `break` 写在 `if` 花括号内 |
| E8 | 严格递增反例条件写错 | `a[i] > a[i+1]` 漏掉相等（相等也不是严格递增） | 用 `a[i] >= a[i+1]` 找反例 |
| E9 | 桶标记数组未清零 | 残留数据导致判断错误 | 定义时用 `int mark[N] = {0};` 初始化全为 0 |
| E10 | 桶标记下标越界 | 值超过数组大小，越界访问 | 确保数组大小覆盖整个值域 |

> **E3 展开**：`if(flag = true)` 是赋值（把 `true` 赋给 `flag`，赋值结果为 `true`），不是比较。这是 `==` 与 `=` 混淆的变体（第3课红线）。推荐直接写 `if(flag)`，既简洁又避免这个错误。

> **E7 展开**：
> 
> ```cpp
> // 错误：break 在 if 外面
> for (int i = 2; i <= n - 1; i++) {
>     if (n % i == 0) isPrime = false;
>     break;  // 每次循环都 break，只检查了 i=2
> }
> // 正确：break 在 if 里面
> for (int i = 2; i <= n - 1; i++) {
>     if (n % i == 0) { isPrime = false; break; }
> }
> 
> ```

## 十三、方法、套路与策略小结

### 标记法四步套路

```
初始化标记 → 循环检查 → 修改标记(配合break) → 循环外决策

```

这是所有判断型问题的万能框架。遇到"是不是""有没有""满不满足"的问题，第一反应就是标记法。

### 两种初始假设策略决策表

| 问题类型 | 初始假设 | 找到什么时修改 | 典型例子 |
| --- | --- | --- | --- |
| 验证属性 | 假设满足（`true`） | 找到反例 → `false` | 素数判断、序列递增、全为正数 |
| 存在性判断 | 假设不存在（`false`） | 找到证据 → `true` | 数组中是否有 x、有没有偶数 |

### 标记变量 vs 标记数组决策表

| 场景 | 选择 | 原因 |
| --- | --- | --- |
| 判断一个整体是否满足条件 | 标记变量（`bool`） | 只需一个"是/否"答案 |
| 判断多个值各自是否出现 | 标记数组（`int[]`） | 每个值需独立标记 |
| 统计每个值出现几次 | 计数数组（`int[]`） | 每个值需独立计数器 |

### 信奥策略意识

-   **性能意识**：标记修改后加 `break` 提前跳出；素数试除用 `i*i <= n` 代替 `i <= n-1`；循环内输出用 `'\n'` 而非 `endl`。
-   **规范意识**：标记变量名见名知意（`isPrime`、`found`、`increasing`）；定义即初始化；`if`/`else` 一律加花括号。
-   **策略意识**：先判断问题类型（验证属性 vs 存在性判断），再选初始假设；边界必测（素数测 n=1、n=2；递增测 n=2、相等序列）；样例验证（测"满足"和"不满足"两种情况）。

### 模板 1：素数判断（含 i\*i\<=n 优化）

```cpp
// 用途：判断 n 是否为素数，输出 Yes/No
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    bool isPrime = true;
    if (n <= 1) isPrime = false;
    else {
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) { isPrime = false; break; }
        }
    }
    if (isPrime) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

```

// 用途：判断序列是否严格递增，输出 Yes/No
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int a[1000];
    for (int i = 0; i < n; i++) cin >> a[i];
    bool ok = true;
    for (int i = 0; i < n - 1; i++) {
        if (a[i] >= a[i + 1]) { ok = false; break; }
    }
    if (ok) cout << "Yes" << '\n';
    else cout << "No" << '\n';
    return 0;
}

// 用途：标记值域内每个数是否出现，支持 O(1) 查询
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int mark[101] = {0};  // 值域1~100
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        mark[x] = 1;
    }
    int q;
    cin >> q;
    while (q--) {
        int x;
        cin >> x;
        if (mark[x]) cout << "Yes" << '\n';
        else cout << "No" << '\n';
    }
    return 0;
}

```
