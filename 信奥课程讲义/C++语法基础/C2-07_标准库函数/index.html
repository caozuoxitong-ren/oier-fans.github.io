    第 07 课 标准库函数

    常用工具函数、文件处理与文件结束符

    学习目标：掌握常用工具函数的头文件、参数和返回值，分清数学函数与通用工具函数；理解文件重定向与文件流操作两类方式，知道 fclose/close() 的作用；理解 EOF 的本质，掌握 getchar()、cin >>、scanf 读到文件结尾的标准写法

    一、常用工具函数

    这一节包含两类函数：数学函数和通用工具函数。它们功能不同，头文件也不同，先分清归属，再记用法。

    类别 头文件 函数
    数学函数 <cmath> abs、ceil、floor、round、sqrt、pow
    通用工具函数 <algorithm> min、max、swap

    1．取最小值/最大值函数：min / max

    两个值的版本：

    返回值类型 min(数据类型 a, 数据类型 b);   // 返回 a、b 中较小的那个
返回值类型 max(数据类型 a, 数据类型 b);   // 返回 a、b 中较大的那个

    注意： std::min 和 std::max 的适用范围比较广泛。它们是模板函数，其核心要求是类型必须支持比较操作。具体来说，几乎所有能进行“小于”比较的类型都可以使用它们。

    参数：两个同类型值 a、b。
    返回值：min 返回较小的那个，max 返回较大的那个；返回类型与参数相同。

    #include <algorithm>
int a = 3, b = 7;
cout << min(a, b) << ' ' << max(a, b);   // 3 7

    要点：

    • 两个值的版本只接受两个参数，不能写 max(a, b, c)；
    • 两个参数类型应一致，max(3, 5.0) 在部分编译器下会报错或产生意外结果；

    多个值的版本（C++11 起）：

    用法很简单，用花括号把多个值括起来：

    min({a, b, c, ...});   // 返回其中最小的
max({a, b, c, ...});   // 返回其中最大的

    参数：花括号 {a, b, c, ...} 中的多个同类型值。
    返回值：其中最小 / 最大的值。
    版本要求：C++11 及以上。C++11 之前没有这个写法，写 max({a, b, c}) 无法编译。

    #include <algorithm>
#include <iostream>
using namespace std;

int main() {
    cout << max({3, 7, 2, 9, 5}) << '\n';   // 9
    cout << min({3, 7, 2, 9, 5}) << '\n';   // 2
    return 0;
}

    要点：

    • 花括号里的元素类型要一致，max({3, 7.5, 2}) 会有类型推导问题，建议统一为同一类型，如 max({3.0, 7.5, 2.0})；
    • 多个值版本返回的是值，不是引用，不能对它取地址或修改原变量；
    • 如果编译器只支持 C++98/03，这个写法不可用，只能两两调用 max 或手写循环。

    2．绝对值函数：abs

    函数原型：

    int abs(int x);           // <cmath>
double abs(double x);     // <cmath>

    参数：一个整数或浮点数 x。
    返回值：x 的绝对值。整数版本返回整数，浮点版本返回浮点数。

    #include <cmath>
cout << abs(-123) << endl;       // 输出 123
cout << abs(-3.14) << endl;      // 输出 3.14

    补充说明：abs 最初只有整数版本，放在 <cstdlib> 中；浮点绝对值当时用 fabs，在 <cmath>。C++ 后来为 abs 增加了浮点版本，放进 <cmath>。再往后，标准把整数和浮点版本在 <cmath> 中整合，因此现在直接包含 <cmath> 通常就能同时使用整数和浮点的 std::abs。

    3．上下取整/四舍五入函数：ceil / floor / round

    函数原型：

    double ceil(double x);  // 向上取整
double floor(double x); // 向下取整
double round(double x); // 四舍五入

    参数：一个浮点数 x。
    返回值：取整后的浮点数，不是 int。

    #include <cmath>

cout << ceil(2.3) << ' ' << ceil(2.7) << endl;    // 3 3，向上取整
cout << floor(2.3) << ' ' << floor(2.7) << endl;  // 2 2，向下取整
cout << round(2.3) << ' ' << round(2.7) << endl;  // 2 3，四舍五入

cout << ceil(-2.3) << endl;                       // -2，向上取整：往大的方向走
cout << floor(-2.3) << endl;                      // -3，向下取整：往小的方向走
cout << round(-2.5) << endl;                      // -3，四舍五入远离零

    要点：

    • ceil 向正无穷方向取整，floor 向负无穷方向取整，对负数要小心：ceil(-2.3) = -2，floor(-2.3) = -3；
    • 如果要把结果存成整数，需要显式转换：int n = (int)ceil(x);。

    4．开平方/乘方函数：sqrt / pow

    函数原型：

    double sqrt(double x);          // 开平方函数
double pow(double a, double b); // 乘方函数，求a的b次方

    参数：sqrt 接受一个非负浮点数 x；pow 接受底数 a 和指数 b。
    返回值：sqrt 返回 x 的平方根；pow 返回 \(a^b\)。两者都返回浮点数。

    #include <cmath>
cout << sqrt(16);        // 4
cout << pow(2, 10);      // 1024
cout << pow(2.0, 0.5);   // 1.414...，平方根

    要点：

    • sqrt 的参数应为非负数，负数开方返回 nan；
    • 乘方函数 pow 的参数和返回值为 double类型，有效数字为15-16位十进制，可能有浮点误差。

    5．交换函数：swap

    函数原型（以 int 为例）：

    void swap(int& a, int& b);   // 交换 a、b 的值，无返回值

    这里只是以 int 举例，实际 swap 对多种类型都能用。

    参数：两个同类型变量 a、b。
    返回值：无（void）。函数直接交换两个变量的值。

    #include <algorithm>
int a = 3, b = 7;
swap(a, b);              // a = 7, b = 3

    swap 是通用工具函数，不是数学函数。它对基本类型和大多数容器都可用。手写 t = a; a = b; b = t; 当然也可以，swap 只是更简洁。

    二、文件重定向与文件流操作

    C++ 中读写文件常见两类方式：文件重定向和文件流操作。

    类别 代表 头文件 核心特点
    文件重定向 freopen <cstdio> 把 stdin/stdout 重新绑定到文件，原来的 cin/cout 写法不变
    文件流操作 ifstream / ofstream <fstream> 用独立流对象读写文件，标准输入输出不受影响

    1．文件重定向：freopen

    函数原型：

    FILE* freopen(const char* filename, const char* mode, FILE* stream);

    参数：

    • filename：文件名，如 "data.in"、"data.out"；
    • mode：打开模式，"r" 读、"w" 写；
    • stream：要重定向的标准流，stdin 或 stdout。

    返回值：成功时返回 stream 指针；失败时返回 NULL。

    #include <cstdio>
#include <iostream>
using namespace std;

int main() {
    freopen("data.in", "r", stdin);    // 输入从 data.in 读
    freopen("data.out", "w", stdout);  // 输出写到 data.out

    int a, b;
    cin >> a >> b;        // 实际从 data.in 读
    cout << a + b;        // 实际写到 data.out

    fclose(stdin);        // 刷新并关闭输入流
    fclose(stdout);       // 刷新并关闭输出流

    return 0;
}

    定位：简单、不侵入代码，写完重定向两行，剩下的 cin/cout 原样不动。缺点是它改变了整个程序的标准输入输出，调试时想切回键盘/屏幕，需要把两行注释掉或删掉。

    关于 fclose 要不要写：

    freopen 之后可以写 fclose(stdin)、fclose(stdout)，也可以不写。

    • 不写：程序正常结束时，运行库会自动关闭所有流并刷新缓冲区，大多数情况下不出错；
    • 写：fclose 先刷新缓冲区，再关闭文件，能确保数据完整写入，不会导致“关早了、写失败”；
    • 程序可能异常终止时，写 fclose 更保险，避免缓冲区数据来不及写出。

    2．文件流操作：ifstream / ofstream

    构造参数：

    ifstream fin("data.in");     // 参数：输入文件名
ofstream fout("data.out");   // 参数：输出文件名

    构造返回值：构造函数没有返回值，创建出流对象 fin、fout。

    流操作 >> / <<：

    • fin >> a：从 fin 读入 a，返回 istream&，可放在条件中判断是否读入成功；
    • fout << a + b：向 fout 写出，返回 ostream&。

    .close()：

    • 参数：无；
    • 返回值：void。
    #include <fstream>
using namespace std;

int main() {
    ifstream fin("data.in");     // 打开输入文件 data.in
    ofstream fout("data.out");   // 打开输出文件 data.out

    int a, b;
    fin >> a >> b;               // 从文件 data.in 读入 a、b
    fout << a + b;               // 把 a+b 写到文件 data.out

    fin.close();                 // 关闭输入文件 data.in
    fout.close();                // 关闭输出文件 data.out
    return 0;
}

    要点：

    • 用法与 cin/cout 几乎一样，只是把对象名换掉；
    • 可以同时保留 cin/cout 用于调试，比如 cout 打印中间结果，fout 只写最终答案；
    • 需要显式 close()，虽然析构时会自动关闭，显式关闭更清晰。

    3．两类方式怎么选

    文件重定向（freopen） 文件流操作（ifstream/ofstream）
    改动量 只加重定向两行 要把 cin/cout 换成 fin/fout
    标准输入输出 被覆盖 保留，可继续用 cin/cout
    适合 竞赛提交、整程序读写文件 需要同时用屏幕调试、或只读写部分数据
    头文件 <cstdio> <fstream>
    关闭方式 fclose(stdin) / fclose(stdout)，可写可不写 建议显式 close()

    三、EOF 与输入结束判断

    1．EOF 是什么

    EOF 是 End Of File 的缩写，是一个特殊的整数值，通常为 -1，表示“没有更多输入了”。

    EOF 不是一个真实字符，它是输入函数在“读不到东西”时返回的信号。

    2．getchar() 与 EOF

    函数原型：

    int getchar();

    参数：无。
    返回值：成功时返回读到的字符的 ASCII 码（int 类型）；读到文件结尾或出错时返回 EOF。

    getchar() 从标准输入读一个字符，返回值类型是 int，不是 char。

    为什么 getchar() 的返回值必须用 int 接？ 因为 char 可能无法表示 EOF（-1），如果用 char c 接收，EOF 可能被截断成某个普通字符，导致死循环。标准写法是 int c。

    int c;
while ((c = getchar()) != EOF) {
    // 处理字符 c
}

    这是 C/C++ 中“逐字符读到文件结束”的经典写法。注意括号：(c = getchar()) 先赋值，再拿赋值结果和 EOF 比较。如果写成 c = getchar() != EOF，含义完全不同，会导致错误。

    3．cin >> 和 scanf 怎么判断结束

    cin >> 作为循环条件：

    int x;
while (cin >> x) {
    // 成功读入一个 x
}
    • 参数：cin 是输入流对象，x 是要读入的变量；
    • 返回值：cin >> x 返回 istream&，在条件中转换为 bool。读入成功为真，失败（遇到文件结尾或类型不匹配）为假。

    scanf 的返回值：

    int x;
while (scanf("%d", &x) != EOF) {
    // 成功读入一个 x
}
    • 参数：格式串 "%d"，以及变量地址 &x；
    • 返回值：int，表示成功读入的变量个数；读到文件结尾时返回 EOF。

    如果一次读多个变量，scanf("%d %d", &a, &b) == 2 表示两个都读成功了。

    4．读取到文件结尾的常见写法

    场景 写法 函数返回值含义 结束条件
    逐字符读到结尾 int c; while ((c = getchar()) != EOF) 字符 ASCII 码或 EOF 读到文件尾
    逐个读整数（C++ 流） while (cin >> x) 流引用，成功为真 读入失败
    逐个读整数（C 风格） while (scanf("%d", &x) != EOF) 成功读入个数或 EOF 读到文件尾
    一次读多个数 while (scanf("%d %d", &a, &b) == 2) 成功读入个数 不能完整读入两个

    共同点：把输入表达式本身放进循环条件，读成功就继续，读失败就停。

    四、总结

    工具函数：先看头文件，再看参数和返回值。min/max/swap 在 <algorithm>，其余数学函数在 <cmath>。分清数学函数与通用工具函数，注意整数/浮点版本和返回类型。

    文件处理：两种方式——文件重定向改 cin/cout 的读写方向，文件流操作用独立对象读写文件。按“是否保留屏幕调试”来选。关闭函数可写可不写，写了更保险。

    输入结束：EOF 是输入结束的信号，不是真实字符。可以把输入表达式放进循环条件，读到EOF时结束输入。
