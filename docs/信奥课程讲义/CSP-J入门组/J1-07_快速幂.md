# 第 07 课 快速幂

递归法、倍增法与龟速乘

> 学习目标：理解普通幂运算为什么可以通过拆分减少计算；掌握递归快速幂和循环倍增法；能够计算大整数幂的模；理解快速幂与快速乘的相同思想；能够在乘法可能溢出时使用快速乘(或龟速乘)。

---

## 一、为什么需要快速幂

### 1．普通幂运算的问题

计算：

$$
a^n
$$

最直接的方法是重复乘法：

$$
a^n=a\times a\times a\times\cdots\times a
$$

一共需要乘 $n-1$ 次，因此时间复杂度是：

$$
O(n)
$$

当 $n$ 很小时，这种方法没有问题；但如果 $n$ 很大，例如：

```text
n = 1 000 000 000
```

就不能真的循环十亿次。

---

## 二、递归法求快速幂


### 1．利用平方关系减少计算

幂运算有一个重要规律：

-   当 $n$ 是偶数时：

$$
a^n=a^{n/2}\times a^{n/2}
$$

-   当 $n$ 是奇数时：

$$
a^n=a^{n-1}\times a
$$

而 $n-1$ 是偶数，所以还可以继续利用平方关系。

例如：

$$
a^{13}=a\times a^{12}
=a \times (a^6 \times a^6 )
$$

指数每次大约减半，因此计算次数从 $n$ 级别降到了 $\log n$ 级别。

定义函数：

```text
qpow(a, n) = a^n
```

因此可以写成：

$$
\operatorname{qpow}(a,n)=
\begin{cases}
1, & n=0\\
\operatorname{qpow}(a,n/2)^2, & n\text{ 为偶数}\\
\operatorname{qpow}(a,n-1)\times a, & n\text{ 为奇数}
\end{cases}
$$

### 2．为什么要边计算边取模

很多题目要求输出：

$$
a^n\bmod m
$$

如果先计算完整的 $a^n$，结果通常会非常大，可能远远超出 `long long` 的范围。

可以利用：

$$
(x\times y)\bmod m
=
\big((x\bmod m)\times(y\bmod m)\big)\bmod m
$$

因此，每次乘法后都可以取模，避免数值无限增长。

### 3．递归代码

```cpp
//快速幂（递归法）: 求 a^b % mod
long long qpow(long long a,long long b,long long mod){
	//递归出口
	if(b == 0) return 1 % mod;
	
	//递归处理
	long long half = qpow(a, b / 2, mod);
	
	if(b % 2 == 1) return a * half % mod * half % mod; //每次乘法都要取模
	else return half * half % mod;
}
```

当 `mod == 1` 时，所有整数除以 `mod` 的余数都是 `0`，所以：

```cpp
1 % mod
```

仍然是 `0`。

### 4．递归方法的复杂度

每次递归后，指数 n 大约变成原来的一半：

```text
n → n / 2 → n / 4 → n / 8 → ...
```

因此递归深度和时间复杂度都是：

$$
O(\log n)
$$

递归还需要调用栈空间，空间复杂度为：

$$
O(\log n)
$$

## 三、倍增法求快速幂

### 1．从递归到循环

递归快速幂的核心是：

```text
指数减半，底数平方
```

也可以把指数写成二进制形式，逐位处理。

例如：

$$
13=(1101)_2=8+4+1
$$

所以：

$$
a^{13}=(1 \times a^8) \times (1 \times a^4) \times (0 \times a^2) \times (1 \times a^1)
$$

程序从低位到高位观察指数的每个二进制位：

-   当前指数二进制位是 1，说明当前二进制位权对应的幂要乘进答案；
-   当前指数二进制位是 0，说明当前二进制位权对应的幂不需要乘进答案；
-   然后，底数平方，得到表示更高一个二进制位的位权；
-   指数除以 $2$，相当于二进制右移一位。

这就是**倍增法**求快速幂。

### 2．循环版普通快速幂

```cpp
//快速幂 (倍增法）： a^b % mod
long long qpow(long long a,long long b,long long mod){
	long long res = 1 % mod;
	while(b){
		// 二进制的末位
		if(b % 2 == 1) res = res * a % mod;
        // 倍增每个二进制位对应的幂
		a = a * a % p; 
		// 去掉二进制的末位
		b /= 2; 
	}
	return res; 
}
```

### 3．用二进制理解 `n`

以 $n=13$ 为例：

| 当前 `n` | 当前二进制最低位 | 是否乘入 `a` | 处理后 |
| --: | --: | --- | --- |
| 13 | 1 | `result *= a` | `n /= 2` |
| 6 | 0 | 不乘 | `n /= 2` |
| 3 | 1 | `result *= a` | `n /= 2` |
| 1 | 1 | `result *= a` | `n /= 2` |
| 0 | — | 结束 | — |

与此同时，`a` 每轮平方：

```text
a, a^2, a^4, a^8, ...
```

当指数的某一位是 `1` 时，把相应的幂乘入答案。

### 4．位运算写法

如果已经学习过位运算，可以写成：

```cpp
//快速幂 (倍增法）： a^b % mod
long long qpow(long long a,long long b,long long mod){
	long long res = 1 % mod;
	while(b){
		// 二进制的末位
		if(b & 1) res = res * a % mod;
        // 倍增每个二进制位对应的幂
		a = a * a % p; 
		// 去掉二进制的末位
		b >>= 1; 
	}
	return res; 
}
```

这里：

| 写法 | 含义 |
| --- | --- |
| `b & 1` | 判断 `b` 的最低位是否为 `1`，也就是判断奇偶 |
| `b >>= 1` | `b` 除以 `2` 并取整 |
| `a = a * a % mod` | 底数平方并取模 |

初学时使用 `% 2` 和 `/ 2` 更直观；掌握位运算后可以使用 `& 1` 和 `>>= 1`。

### 5．倍增法的复杂度

指数每轮除以 $2$，所以循环次数为：

$$
O(\log n)
$$

循环版不需要递归调用栈，额外空间复杂度为：

$$
O(1)
$$

因此，在竞赛中通常优先使用循环版模快速幂。

## 四、递归法和倍增法的对比

| 对比项目 | 递归快速幂 | 倍增法 |
| --- | --- | --- |
| 核心思想 | 指数减半，递归求小问题 | 按二进制位逐位处理 |
| 时间复杂度 | $O(\log n)$ | $O(\log n)$ |
| 额外空间 | $O(\log n)$ 调用栈 | $O(1)$ |
| 代码特点 | 接近数学递推式 | 适合竞赛和大数据 |
| 常见用途 | 理解递归关系 | 实际计算模幂 |

两种方法的数学本质相同：

```text
递归法：把大指数拆成更小的指数
倍增法：把指数拆成二进制位
```

## 五、快速乘（龟速乘）

### 1．为什么需要快速乘

快速幂中的核心操作是乘法：

```cpp
result = result * a % mod;
```

如果 `result` 和 `a` 都接近 `long long` 的上限，即使最终结果需要取模，中间的：

```cpp
result * a
```

也可能已经溢出。

例如，若模数接近 $10^{18}$，两个小于模数的数相乘可能达到 $10^{36}$，远远超过 `long long` 的范围。

这时，可以用与快速幂相同的思想计算：

$$
a\times b\bmod m
$$

不直接计算 `a * b`，而是把 $b$ 按二进制拆开，通过“加倍”和“累加”完成乘法。这种方法叫**快速乘**，也叫**龟速乘**。

### 2．乘法的二进制拆分

例如：

$$
13=(1101)_2=8+4+1
$$

所以：

$$
a\times13=( 1 \times 8a) + (1 \times 4a) + (0 \times 2a) + (1 \times a)
$$

程序维护两个量：

-   `a`：当前这一位对应的倍增值；
-   `b`：还没有处理的乘数；
-   `result`：已经累加的部分。

每一轮：

1.  如果 `b` 是奇数，把当前 `a` 加入答案；
2.  把 `a` 加倍；
3.  把 `b` 除以 `2`。

### 3．模快速乘的代码实现

真正常用的是计算：

$$
(a\times b) \bmod m
$$

```cpp
//快速乘（龟速乘） （倍增法） O(logb) 
long long qmul(long long a,long long b,long long mod){
	long long res=0;
	while(b){
		if(b & 1) res= (res + a ) % mod;
		a = (a + a) % mod;
		b >>= 1;
	}
	return res;
}
```

这里所有运算都使用加法和取模，不直接执行可能溢出的乘法。


### 6．快速乘的复杂度

乘数 `b` 每轮除以 $2$，所以时间复杂度为：

$$
O(\log b)
$$

额外空间复杂度为：

$$
O(1)
$$

直接乘法是 $O(1)$，因此在普通小整数运算中，快速乘反而更慢。它的价值在于：

-   直接乘法可能溢出；
-   需要在很大的模数下计算乘积；
-   想用加法和取模代替危险的乘法。

## 六、用快速乘改造快速幂

### 1．为什么要组合使用

模快速幂中有两种乘法：

```cpp
result = result * a % mod;
a = a * a % mod;
```

如果 `mod` 足够小，`long long` 可以安全完成这些乘法，直接写即可。

如果 `mod` 很大，可能需要把乘法替换成快速乘：

```cpp
result = multiplyMod(result, a, mod);
a = multiplyMod(a, a, mod);
```

### 2．快速乘 + 快速幂

```cpp
//快速乘（龟速乘） （倍增法） O(logb) 
long long qmul(long long a,long long b,long long mod){
	long long res=0;
	while(b){
		if(b&1) res=(res+a)%mod;
		a=(a+a)%mod;
		b>>=1;
	}
	return res;
}

//快速幂 (倍增法） O(log b)
long long qpow(long long a,long long b,long long mod){
	long long res=1%mod;
	while(b){
		if(b&1) res=qmul(res,a,mod);
		a=qmul(a,a,mod); //倍增法 
		b>>=1; 
	}
	return res; 
}
```

## 七、快速幂和快速乘的共同思想

快速幂与快速乘本质上都使用了同一个策略：

```text
观察第二个量的二进制表示；
当前最低位为 1，就把当前贡献加入答案；
贡献加倍；
第二个量右移一位。
```

对快速幂：

-   贡献是 `a、a²、a⁴、a⁸、...`；
-   加法变成乘法；
-   使用 `result *= a` 合并答案。

对快速乘：

-   贡献是 `a、2a、4a、8a、...`；
-   通过加法合并答案；
-   使用 `result += a` 累加。

| 算法 | 当前贡献 | 合并方式 | 第二个量的变化 |
| --- | --- | --- | --- |
| 快速幂 | `a、a²、a⁴、...` | 乘法 | 除以 2 |
| 快速乘 | `a、2a、4a、...` | 加法 | 除以 2 |

可以记成：

> **快速幂是“平方 + 乘入”，快速乘是“加倍 + 加入”。**
